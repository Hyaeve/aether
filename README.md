# Aether 以太

Go + Vue 的自托管存储工作空间。主服务、STRM 播放代理、只读 WebDAV 共用 **15151** 端口。

### WebDAV 用户

在 WebDAV 页面点击“添加用户”，设置独立账号、密码及可访问的目录；支持编辑、停用、删除，编辑时密码留空表示保持原密码。密码使用 bcrypt 哈希并随配置加密持久化。

管理员仍可使用管理账号访问全部启用的存储池。独立用户仅能在 `/dav/` 下看到授权目录的显示名称，例如 `/dav/Movies/`，不能访问同一存储池内的其他目录；未授权目录时根目录为空。所有用户均为只读，支持浏览及 GET/HEAD 范围读取。撤销权限对后续请求生效，已经开始的读取不会强制中断。用户授权不会赋予管理后台访问权限；请使用 HTTPS 保护 Basic Auth 凭据。

## 当前实现

### CAS 生成与目录选择

CAS 任务只生成 CAS 文件，不提供“CAS 转 STRM”选项。源存储支持本地、原生移动和天翼；旧转换任务禁止执行，需要重新选择视频源目录并保存，已有输出不会删除。本地逐块读取视频并计算 SHA256、MD5，不把整部视频载入内存。生成 `原文件名.cas`（Base64 JSON，附带 retentionHours 保留时长），保留子目录、全量/增量和排除规则，输出位置沿用任务生成目录，留空为 `/data/strm`。CAS 的直接识别需要消费端支持此格式，不是普通 URL 文本，尚未验证真实媒体库直接播放。

CAS 任务需绑定已启用的移动或天翼账号。绑定移动时源目录只允许本地或原生移动存储，输出 mobile/SHA256；绑定天翼时只允许本地或原生天翼，输出 tianyi/MD5。本地计算后按绑定类型输出对应哈希，不在 CAS 中写入账号凭据。旧云端任务可沿用源账号，旧本地任务需要编辑并选择绑定账号。

移动生成依赖目录接口提供 SHA256，天翼依赖 MD5，不将天翼 MD5 冒充 SHA256。缺少兼容哈希会明确报错，不下载完整云端视频补算；真实云盘生成仍待联调，是否秒传成功取决于云端命中与账号权限。

目录选择保存内部 ID 与显示名称、父级轨迹，重新编辑后可回上级或直接回根目录。旧任务没有保存名称时显示“已选目录”，重新选择后保存真实目录名。

- 首次启动创建管理员，无默认密码；bcrypt 密码哈希、HttpOnly 会话、同源写请求校验、登录限流。
- 存储池新增、编辑、删除、启停、连接测试。同类型可重复添加，名称唯一。凭据 AES-GCM 加密落盘。
- 已登录管理员可在编辑窗口点击眼睛查看真实 Cookie、Token 或以链凭据；仅按需读取单个字段、响应禁止缓存，列表仍脱敏。显隐不改变表单布局，请通过 HTTPS 访问后台并保护管理员会话。
- 以链管理地址为 `/links/manage`，直链缓存为 `/links/cache`；卡片支持长按拖动及 Alt 方向键排序。播放流水展示 UA、处理结果、目标、客户端 IP、缓存来源、有效期及耗时，并支持筛选、搜索和虚拟滚动。
- Audiobookshelf 的 STRM 必须在 Aether 容器中可读。默认允许 `/audiobooks`、`/media`、`/strm`、`/NetDisk`、`/mnt` 和运行数据目录；建议与上游使用相同容器路径挂载。以链编辑窗口不再显示媒体目录映射字段，已保存的旧映射继续兼容。只挂载媒体库数据库、未挂入真实 STRM 文件或缺少读取权限仍会透传，不保证302。HTTP后台复制提供兼容回退，仍建议HTTPS。
- 本机目录、WebDAV、OpenList 浏览与下载；115 Open、夸克直接接口；移动支持原生新版个人云和 OpenList 网关，天翼支持原生个人云账户登录，不再使用 OpenList 网关。
- STRM 全量/增量、五字段 Cron、手动执行/停止、排除目录/文件/后缀、API 请求间隔、输出目录约束。
- 缓存扫描任务：深度、执行间隔、缓存有效期。共享 TTL/LRU 缓存、条目与估算内存限制、磁盘快照及重启恢复。
- 聚合只读 WebDAV：`/dav/<storage-id>/`，支持 PROPFIND、GET、HEAD，复用管理员 Basic Auth。
- 中文界面、深色侧栏、固定顶栏、三态主题、移动端布局、登录轨道视觉、日志与账户设置。
- GitHub Actions 测试及 `linux/amd64` 镜像构建，推送 GHCR。
- LitePan 风格单层导航、页面内任务栏目、插件卡片；单按钮三态主题、带未读数量的最近任务通知、系统设置内的关于以太及 GHCR 镜像更新检查。
- 存储授权：夸克二维码获取、轮询及 Cookie 回填；115 Open 默认通过 LitePan 第三方 OAuth 服务打开授权页并回填令牌，可更换为可信兼容 HTTPS 代理。第三方服务可用性及是否允许 Aether 客户端仍需真实联调。

通知展示每个任务最近一次结束状态（最多 30 项），已读标记按账号保存在当前浏览器，不是完整执行历史。更新检查读取 `ghcr.io/hyaeve/aether:latest` 的 linux/amd64 镜像元数据，比对构建时写入的 Git 修订号；成功结果缓存五分钟。不再依赖 GitHub Release API，不自动拉取或重启。镜像不可匿名访问、未发布、限流及网络异常分别提示；旧镜像或本地构建缺少修订号时明确提示无法确认更新，不冒充已是最新版本。

系统设置采用横向栏目。已登录管理员可直接修改账号和密码，不再输入当前密码；保存后撤销旧会话并签发新会话。新安装会话有效期默认 15 天，可设置 1–365 天，已有自定义值保持不变。登录令牌的 SHA256 摘要加密保存于 `/config/sessions.enc`，容器重启后仍可登录，期限从登录时计算，不因重启续期。退出仅撤销当前设备，更改账号密码撤销旧会话。请持久化 `/config`，保护已登录设备并通过 HTTPS 访问。

任务源目录选择器左侧选择存储池、右侧选择目录；CAS 显示本地、原生移动与天翼存储。存储池和源目录统一提交，取消选择不改动表单。

授权接口与回填已通过模拟测试，真实网盘扫码和第三方 OAuth 代理仍待账号联调。存储删除模式默认“移到回收站”，用于原生移动、天翼 CAS 临时文件清理和文件删除。文件写操作支持本地及115、夸克、原生移动、天翼；云端写接口仍待真实账号联调。目录整理、STRM 刮削和辅助插件尚未提供执行引擎，界面明确标注待实现。

### CAS 任务

CAS 栏目只从视频生成特征文件，使用方法见上方“CAS 生成与目录选择”。以下是旧签名播放链接的兼容逻辑，不是当前 CAS 任务创建流程：

1. 添加移动云盘，选择“原生新版个人云”，填写 Authorization（支持 Basic 前缀）；或添加天翼云盘，填写账号、密码，个人云根目录 ID 默认 `-11`。
2. 在 CAS 任务选择存储池、源目录、本地生成目录，配置全量/增量、Cron、API 间隔和排除规则。
3. 旧版本曾读取 `.cas` 的 Base64 JSON 并生成 `电影.mkv.strm`；这一转换任务现已停用。已生成的签名链接保留播放兼容。
4. 播放时调用对应网盘的原生秒传接口，在网盘根目录的 `/Aether` 内创建临时文件，通过 Aether 同端口代理播放，支持 Range/HEAD。并发请求与重启后的重播复用已记录文件。
5. 新 CAS 文件记录“还原文件保留时间”，默认 12 小时，支持 1–8760 小时，消费端须支持此字段才会生效。旧签名链接仍按最后一次播放结束后计时，活跃播放期间不清理；同一还原文件复用时取已应用的最长保留时间，缺少保留字段按 12 小时处理。
6. 临时文件记录随 `/config/state.enc` 加密保存，也可在 CAS 临时文件窗口触发过期清理。默认移到回收站，选择永久删除时才彻底删除。只删除以太记录的文件 ID，不扫描删除 `/Aether` 内的其他文件。旧目录中的已记录文件仍按 ID 复用、清理，不迁移或删除整个旧目录；新还原文件才写入 `/Aether`。

支持移动新版个人云的 SHA256 CAS、天翼个人云的 MD5 CAS；不支持家庭/群组云、旧版移动个人云、仅有 SHA1 的 CAS 或 torrent CAS 扩展。两种网盘的哈希不能互换。移动 Authorization 暂不自动刷新，失效后可更新同账号令牌。秒传依赖云端源数据及账号权益，不保证所有文件可还原，也不承诺不占配额。没有媒体上传兜底。签名 STRM 内含名称、大小和哈希，不含账户令牌；全量任务重写匹配文件但不清除本地孤儿文件。临时链接失效时会标记记录，下一次播放重试还原；崩溃恰发生在云端创建与本地记录落盘之间仍可能留下未记录残留。

天翼账号密码沿用 AES-GCM 加密配置存储，向官方 HTTPS 登录接口提交时使用官方公钥 RSA PKCS#1 v1.5 加密。会话仅缓存在内存，重启或一小时后重新登录；检测到失效时清除会话，下次请求重新登录。暂不支持图形验证码及设备短信二次验证，遇到风控会明确报错，需要在官方客户端处理后重试，不能保证由此解除风控。旧天翼网关池不会继续走网关：请编辑存储池填写天翼账户、重新选择数字目录 ID，并更新关联任务的源目录。

原生协议、CAS 扫描/播放/清理通过模拟云盘测试；尚未使用真实移动、天翼账号验证。协议参考及许可见 `THIRD_PARTY_NOTICES.md`。

## 明确的边界

这是一版可运行的基础实现，**不是完整需求的全部实现**。

- 115 / 夸克未以真实账户完成端到端验证。115 使用 Go `115driver` 的 CK 驱动，填写完整 Cookie 并选择对应设备，或点击“扫码获取 CK”直接使用 115 官方二维码；不再调用 LitePan OAuth。旧 Open 存储须编辑并重新填写 CK，不能将旧 Token 当作 Cookie。
- 移动的网关模式填写 OpenList 地址、API Token、根路径；原生移动使用 Authorization，天翼直接填写账号密码。真实账号仍待联调。
- 文件管理支持本地及115、夸克、原生移动、天翼的重命名、移动、复制、删除；云端只支持当前存储池内操作，跨云端池传输、OpenList/WebDAV写操作尚未实现。115/夸克仅支持回收站删除，永久删除明确拒绝，避免误删回收站其他项目；上传仍未实现。云端批量失败可能部分完成，请刷新核对。
- 备份任务、整理、刮削与大部分辅助工具仍待开发；以太链接三种媒体反代及加密配置备份导入导出已实现，真实媒体库联调边界见末节。
- 本地挂载已接入 rclone FUSE 引擎、聚合目录和管理接口；Windows 不执行挂载。云盘和本机存储均支持通过挂载进行顺序读写，云盘写入会先暂存、上传并确认后再替换目标；随机写入、真实 Linux/Docker 挂载仍需联调。
- 元数据内存上限按 JSON 载荷及固定条目开销估算，不是 Go 进程 RSS 的硬限制。
- WebDAV 根目录使用存储池 ID。云端目录逐级解析；可能产生额外请求。当前不支持 WebDAV 写入和锁操作。
- 本版本配置与任务以加密 JSON 原子文件保存，适合单实例；不支持多实例共用数据目录。

## 本地运行

需要 Go 1.26+、Node.js 22+。

```powershell
cd web
npm ci
npm run build
cd ..
go run ./cmd/aether
```

访问 `http://localhost:15151`，创建管理员（密码非空即可，不设 12 字符下限；受 bcrypt 限制，最多 72 字节）。先在系统设置填写媒体服务器能访问的地址，例如 `http://192.168.1.10:15151`，再生成 STRM。

前端开发：在另一个终端执行 `cd web` 后运行 `npm run dev`，Vite 代理 API 至 15151。

环境变量：

| 名称                 | 默认值         | 用途                        |
| ------------------ | ----------- | ------------------------- |
| `AETHER_PORT`      | `15151`     | 管理后台、STRM、WebDAV 共用监听端口 |
| `AETHER_ADDR`      | 未设置       | 高级监听地址，设置后优先于 `AETHER_PORT` |
| `AETHER_WEB_DIR`   | `web/dist`  | 前端构建目录                    |
| `TZ`               | 由环境决定       | 定时任务时区，容器默认 Asia/Shanghai |

目录不再通过 `AETHER_DATA_DIR` / `AETHER_STRM_ROOT` 环境变量配置。容器固定使用 `/config` 保存配置、`/data` 保存运行数据；本地开发对应工作目录下的 `config/`、`data/`。独立测试可使用命令行参数 `-config-dir`、`-data-dir` 指定隔离目录。

任务目标目录留空时默认写入 `/data/strm`（本地开发为 `data/strm`）。也可填写相对路径（例如 `movies`），或 STRM 根目录内的绝对路径。源文件名保留原后缀，例如 `movie.mkv.strm`，避免同名不同格式文件覆盖。全量重写匹配文件但**不会删除已不存在源文件对应的旧 STRM**；增量只创建不存在的 STRM。

缓存有效期优先级：任务 > 存储池 > 全局；0 表示继承。缓存任务默认 60 分钟执行一次，有效期仍按此优先级决定。扫描层级 0 为全部（最多 128 层），1 仅当前目录。API 间隔默认 200ms，安全下限 200ms；同存储池一次只运行一个任务。Cron 使用五字段，本地运行跟随进程时区。

## Docker

在支持 `/dev/fuse` 的 Linux Docker 主机：

`compose.yaml`：

```yaml
services:
  aetherlink:
    image: ghcr.io/hyaeve/aether:latest
    container_name: Aether
    network_mode: host
    volumes:
      - ./config:/config
      - ./data:/data
      # 可选：将 FUSE 读缓存单独映射，建议放到更快的磁盘
      # - ./fuse_read_cache:/data/fuse_read_cache
    environment:
      - TZ=Asia/Shanghai
      - AETHER_PORT=15151
    devices:
      - /dev/fuse:/dev/fuse
    pid: "host"
    privileged: true
    restart: unless-stopped
```

启动服务：

```sh
mkdir -p config data
docker compose pull
docker compose up -d
```

默认 `host` 网络，不使用 `ports` 映射；特权与 FUSE 设备按需求启用。Docker Desktop 或非 Linux 环境不适用此默认 FUSE 配置。没有挂载需求时，建议移除 `privileged`、`devices` 并将本机目录绑定设为只读。

自定义端口：修改 `compose.yaml` 的 `environment` 中 `- AETHER_PORT=15151`，例如改为 `- AETHER_PORT=15200`，然后运行 `docker compose up -d` 重建容器。管理后台、STRM 播放代理和 WebDAV 都使用新端口，容器健康检查同步跟随。有效端口为 1–65535；不要同时设置 `AETHER_ADDR`，除非需要覆盖监听地址。

端口变更不会覆盖已保存的外部访问地址。请在「WebDAV」页面更新媒体服务器可访问的外部访问地址（例如 `http://192.168.1.10:15200`），并重新全量生成已有 STRM。反向代理使用独立公网端口时，外部访问地址应保留其实际地址。

如需本机存储，可自行在 `volumes` 下添加 `- ./storage:/mnt`，将宿主机 `./storage` 映射为容器内 `/mnt`。默认配置不包含这一挂载；它不是 STRM 输出目录。

FUSE 读缓存预留路径为 `/data/fuse_read_cache`，默认随 `/data` 映射。需要单独放置到其他磁盘时，可取消对应挂载行的注释并修改左侧宿主机路径。当前 FUSE 读缓存功能尚未实现。

容器持久化目录：

| 容器目录 | 宿主机默认目录 | 内容 |
| --- | --- | --- |
| `/config` | `./config` | `state.enc` 保存管理员、存储池、任务和系统设置；`master.key` 保存加密密钥 |
| `/config/organize/organize-rules.json` | `./config/organize/organize-rules.json` | 整理规则预留配置 |
| `/config/organize/categories.json` | `./config/organize/categories.json` | 二级分类预留配置 |
| `/config/organize/upgrade-policies.json` | `./config/organize/upgrade-policies.json` | 洗版策略预留配置 |
| `/config/organize/ai.json` | `./config/organize/ai.json` | AI 辅助识别预留配置 |
| `/config/organize/recognition-rules.json` | `./config/organize/recognition-rules.json` | 识别规则预留配置 |
| `/data` | `./data` | 目录缓存快照等运行数据 |
| `/data/strm` | `./data/strm` | 默认 STRM 输出位置，仅首次实际写入时创建 |

整理识别配置统一归入 `/config/organize/`，五个 JSON 文件在该目录中平铺，不为每项规则再建子目录。账户、密钥和系统设置仍保存在 `/config` 根目录。启动时，新位置缺失的文件优先从旧 `/config` 根目录复制，旧文件保留作为备份；新位置已有文件不会被覆盖，无旧文件时初始化为 `{}`。规则模块尚未实现，这些文件暂不参与规则执行。启动、创建任务或没有匹配视频的扫描都不会创建 `/data/strm`。更早版本的独立规则目录不自动删除或迁移其内容，以免误删已有数据。

`config/master.key` 与 `config/state.enc` 必须一起备份；丢失密钥不可恢复配置。升级时，如果 `/config` 尚无配置，自动复制旧 `/data/master.key` 与 `/data/state.enc` 至 `/config`，保留旧文件；已有 `/config` 配置不会被覆盖。迁移后以 `/config` 为准，旧文件只作备份，不会继续同步。

GitHub 构建默认发布 `ghcr.io/<owner>/<repo>:latest`、版本标签和 SHA 标签。修改 Compose 的 `image` 可指定已发布镜像版本；首次发布可能需在 GHCR 中配置包可见性。PR 只构建不推送。

## 安全与运维

- 首次初始化接口只在尚无管理员时生效；初始化前应仅在可信网络开放服务。
- 公网部署应通过 HTTPS 反向代理访问。WebDAV Basic Auth 不应在不可信网络使用明文 HTTP。
- STRM 链接携带长期 HMAC 签名，可被持有者访问；将 STRM 视为访问凭据。
- 管理员有权指定网络上游和可读取的本机根目录，因此管理员权限等同服务可访问范围。不要向不可信用户授予管理员。
- 数据密钥与密文位于同一持久化目录，加密不防御完整主机或完整数据卷失窃。
- 元数据缓存快照不含认证凭据，但包含文件名；需要保护数据卷。
- 当前配置会在保存缓存策略时清空旧缓存；源文件变动需刷新目录或等待缓存失效。

## 验证

侧栏“文件服务”包含文件管理、WebDAV、本地挂载三个栏目，默认打开文件管理。旧 `/webdav`、`/mounts` 地址自动跳转至对应栏目。

### 本地挂载

- 挂载配置包含名称、存储池/子目录、容器挂载点、只读、自动挂载及 UID/GID/权限。默认只读关闭、自动挂载开启，权限为 `0 / 0 / 0755`。源目录不选存储池直接确认表示所有启用存储池；聚合根目录使用“名称 [存储ID]”避免同名冲突。
- 保存仅保存配置，点击卡片挂载按钮立即挂载；自动挂载表示下次服务启动自动执行。编辑或删除前需先卸载。真实挂载确认依赖 Linux mountinfo，不以子进程启动成功代替挂载成功；失败可在存储与服务日志查看。
- 挂载名称、源目录、挂载点分行配置。源可选择所有存储池、整个单一存储池或子目录；本地存储目录默认留空，与挂载点共用容器目录浏览器，路径各级（含根目录）可点击跳转。
- 镜像包含 rclone/fuse3，通过仅监听回环、随机令牌保护的内部 WebDAV 桥访问存储，不依赖公开 WebDAV 开关或用户。源目录通过已有存储驱动解析；本机读写使用 `os.Root` 限制在所选目录内，云盘写入按移动、天翼、115、夸克的上传协议分片提交，WebDAV/OpenList 使用原生写接口，删除遵循回收站策略。挂载写入要求 FUSE 侧提交确定长度的完整文件；失败暂存保留，随机写入和真实云盘账号仍未联调。
- 挂载点选择已存在的父目录，实际挂载到其下的 `AetherDrive`：选择 `/挂载` 即挂载到 `/挂载/AetherDrive`。保存配置不创建目录，启动挂载时才创建该子目录；已有子目录必须为空且不是符号链接，不覆盖或删除原有数据，父目录中的其他文件保持不变。旧配置下次启动同样使用该子目录。
- 实际 `AetherDrive` 目录不能与配置、运行数据、系统目录重叠，不能与本次明确选择的本地源目录递归包含。允许将云盘或聚合存储挂到已有本地存储根下，如 `/NetDisk/AetherDrive`；聚合挂载会排除与挂载点重叠的本地池，避免无限递归，其他存储仍可访问。可先在宿主机创建目录，再显式绑定至容器，如 `- /srv/aether-mount:/mounts/media:rshared`；宿主机实际访问 `/srv/aether-mount/AetherDrive`，是否可见 FUSE 子挂载仍取决于父挂载传播设置。
- Linux 容器需要 `/dev/fuse` 和挂载权限。Windows 可保存配置但点击挂载会明确报错。本轮没有可用 Docker/WSL，已验证桥接读写及管理 API，未验证真实内核 FUSE 挂载。当前使用无磁盘 VFS 缓存模式，`/data/fuse_read_cache` 仍为预留路径。

115 CK 支持网页、安卓、iOS、电视、支付宝小程序、微信小程序和新版 Android 设备。扫码设备绑定到当前管理员的五分钟加密会话，CK 加密保存在配置中；同设备重复登录可能使旧 CK 失效。目录、下载、文件操作、上传及云下载通过 `115driver` 接入，不依赖第三方 OAuth。移动云盘添加和编辑仅提供支持 CAS 的新版个人云 Authorization；旧网关存储运行兼容保留，编辑保存为原生前需填写新授权。

系统日志通过单个图标按钮切换原始 JSON 和结构化列表，图标表示当前模式。原始日志完整换行并使用虚拟滚动；筛选在浏览器持久保存。日志位于 `/data/log/system.json`，默认同时限制15天与20000条，任一限制达到即清理，可在系统设置的日志管理中调整。旧加密状态中的日志在启动时迁入日志目录，新增事件也输出到容器标准输出。以链服务归属“以太链接”模块，审计不记录请求正文、查询参数或凭据。

新安装的外部访问地址根据本机网卡与监听端口初始化；历史默认 `http://localhost:15151` 在启动时替换，其他自定义地址保留。多网卡、桥接网络或反向代理部署请在 WebDAV 页面确认并保存实际可访问地址，修改地址后重新生成 STRM。

## 以太链接与 v0.1.1

- 支持 Audiobookshelf、Emby、飞牛影视，每个以链独占一个1024–65535端口。host网络下确保端口空闲并配置防火墙；服务地址不能指向自身反代端口。
- 以链管理使用卡片添加、编辑、删除，点击媒体图标启停；支持始终跳转、公网跳转、内网跳转、始终中继。网段从本机网卡自动识别，不信任未经配置的转发IP头。
- 配置API Key或飞牛账号密码用于媒体解析；播放器仍须持有媒体服务器自己的访问权限。每次播放在解析/缓存返回前向上游校验播放器凭据，不能用以太管理员Cookie替代媒体登录。
- Audiobookshelf的STRM文件须在以太容器中以相同路径可读；默认允许 `/data`、`/mnt` 下指针与本地目标，其他路径需映射至这些路径。Emby/飞牛直接返回HTTP媒体地址时不要求本地STRM映射。源文件不可读会回退透传。
- “直链缓存”展示最近2000条真实播放流水。解析缓存沿用AetherLink按上游/媒体/客户端身份/UA隔离的TTL/LRU：ABS和移动短效直链15分钟，Emby默认2小时，签名链接按有效期缩短，上限24小时，容量4096。缓存持久化位于 `/data/cache/link`，包含敏感媒体直链，请保护数据卷。
- ABS 公开会话音轨在播放前使用播放器原始凭据向实际音轨入口发起单字节 Range 校验，不注入以链 API Key。避免新建会话尚未落库时被 `/api/session/:id` 的 404 提前阻断；解析仍沿用活跃会话回退。上游拒绝或跳转不会被当作授权成功。该修复已模拟验证，不能替代真实播放器现场排查。
- 以链默认启用 AetherLink 的上游跳转跟随：读取 STRM 后，以播放器有效 UA 探测中间地址，HEAD 不支持时改用单字节 Range GET，跟随重定向并缓存最终地址，再按客户端内外网和跳转模式决定 302 或代理。新缓存使用 `*-direct-v2.json`，不读取旧的未探测地址缓存；旧文件保留。若 STRM 后端启用了本地代理、直接返回媒体而非重定向，无法凭该响应推导网盘直链；探测失败仍沿用 AetherLink 的原地址回退并记录警告，不能保证真实播放成功。
- 镜像加入FFmpeg。Apple/iOS客户端的STRM音频目标，以及映射到容器内的Audiobookshelf原始AAC/WMA/M4B文件，支持AAC重新封装、WMA/M4B转AAC-LC M4A，通过本地Range响应播放。缓存按书籍/变体分目录存入 `/data/cache/link/audio`；两小时未使用回收，十分钟扫描过期，每24小时清理空目录，启动也清空目录。共享缓存避免重复转换，活动读取与生成中的文件受保护。未实现通用媒体标签补全引擎。
- 文件管理支持可点击路径、列表/网格切换、按存储池保存收藏夹；这些偏好按账号保存在当前浏览器，不属于服务端配置备份。单击选中、双击进入目录、Shift 连选、F2 重命名、右键移动/复制/删除；列表支持名称、大小、类型、修改时间排序。本地删除默认移到源根目录 `.aether-trash/<随机ID>/`，永久删除须在存储池设置中显式选择。同池移动使用重命名，跨本地池复制完成后才移除源项，失败会明确报告已完成数量；不支持符号链接，目标重名不覆盖。
- 文件栏目右侧提供刷新、搜索和工具菜单。刷新或点击非功能空白区域取消选中。新建文件夹先编辑名称，回车或点击空白区后提交，空名称取消；F2/右键单项重命名保留内联编辑。工具菜单的重命名进入工作台：有选择时作用于选择项，否则作用于当前目录全部项；左侧原新名称对比、右侧顺序查找替换规则，支持大小写、首次匹配和规则排序。预览不修改文件，确认时校验预览与名称冲突，不覆盖已有项目；中途失败报告已完成数量，不承诺跨云端事务回滚。规则集保存在 `/config/organize/rename-rules.json`，可复用、删除并随配置备份导出。
- 右键查看详情自动统计文件夹大小（最多 5 分钟、128 层、100000 个项目，云端目录请求间隔 200ms），完整统计成功后写入共享 TTL/LRU 目录缓存并显示在大小栏目；缓存持久化随系统设置，文件操作清空缓存，统计失败不把部分结果当作完整大小。路径紧凑显示，过长时保留根目录和尾部目录。
- 文件列表/网格与目录选择器使用虚拟滚动，只渲染视口附近项目；系统日志和直链缓存继续使用虚拟列表。目录 API 仍会按现有驱动分页读取完整目录，不是服务端按视口分页。移动、天翼、夸克、115 补充上游修改时间字段解析，未提供时间时显示空值，不伪造时间；旧缓存可通过刷新更新。
- 上传文件及文件夹支持浏览器选择，保留文件相对目录；浏览器不提供空目录条目，因此空目录不会上传。文件先暂存于 `/data/cache/file-upload`，再提交至当前存储，结束后清理暂存；单文件上限 100 GiB，同名文件拒绝覆盖。云端提交复用现有上传协议，失败可能留下上游 `.aether-upload-*` 文件，需要核查后处理。
- 115 使用原生云下载：每批最多 50 个 HTTP/HTTPS/FTP/磁力/电驴链接，或 20 个种子（单个 8MB、请求 64MB），默认当前目录。“115 云下载”窗口直接提交到云端；公开 v1/混合种子解析为保留哈希和 tracker 的磁力链接再提交，不上传种子文件。私有种子和纯 v2 种子明确拒绝，云端能否发现元数据及下载成功取决于 115 服务，进度请在网盘查看。其他存储使用独立的“内置离线下载”窗口。
- 本地生成的天翼 CAS 参考 OpenList 的分片特征协议，流式计算 10 MiB 分片 MD5 和拼接摘要，保存在现有 `.cas` 的 `slice_md5`、`slice_size` 字段；还原时使用天翼分片秒传接口，不上传媒体内容。移动 CAS 不包含天翼分片字段；旧的仅 MD5 天翼 CAS 继续走原秒传接口。暂未导入或导出 OpenList `.cas.torrent` 容器。
- 其他存储采用与 LitePan 相同的进程内下载技术路线：HTTP/HTTPS 使用 Go `http.Client`，磁力/BT 种子使用 `anacrolix/torrent`，不需要 aria2 或独立下载进程；下载完成后上传到所选存储目录。内置下载不支持 FTP/ED2K，不冒充夸克原生离线接口。一次执行一个批次、批次内串行，单项最长 24 小时，磁力元数据等待上限 10 分钟；单项总大小上限 100 GiB，BT 最多 10000 个文件，不上传做种、不自动映射路由端口。暂存于 `/data/cache/offline`，上传成功清理，失败保留，不覆盖同名目标，结果见系统日志。HTTP 重定向有界、部分下载不会发布，BT 经分片验证后上传。重启中断的下载尚不自动恢复，保留目录需管理员处理；需自行保证磁盘空间、网络权限和下载内容合法性。回环 HTTP 和 BT WebSeed 已测试，真实网盘、公网磁力发现与 Docker 运行尚待联调。
- ED2K 任务位于 CAS 后，当前支持本地存储计算所有普通文件的 ED2K 哈希，输出同名 `.ed2k` 链接文件，支持全量/增量、Cron 和排除规则。生成目录沿用任务输出根目录；云盘哈希获取和 ED2K 下载不在本轮实现范围。
- 直链缓存展示“模式 / 链接 / 请求 IP”，模式简写为 302、透传等。IPv4/IPv6 直接请求取连接来源；同主机反代默认信任本机地址的转发头，其他反代须显式设置 `AETHER_TRUSTED_PROXIES`，例如 `172.18.0.2/32,fd00::2/128`，且反代应覆盖或追加真实客户端转发头。不要填写整个不可信网段。NAT 未保留来源且没有可信转发头时无法还原真实客户端，仍显示实际上一跳地址。
- 配置备份位于辅助工具最后一项。导出时设置非空备份密码，使用 PBKDF2-HMAC-SHA256（随机16字节盐、600000轮）派生密钥、AES-256-GCM 加密，输出 `.aether` 文件；没有密码无法恢复。备份包含管理员、存储池、以链、任务、系统设置及配置目录JSON，不含媒体、日志和数据缓存，不明文导出 master.key。旧版未加密ZIP不能直接导入。
- 导入先选文件再输入导出时设置的密码。校验后用当前安装的密钥加密暂存 `/config/import.pending`，重启容器时应用，并使用备份中的账号登录；当前运行配置不热替换。错误密码、篡改、越界路径和符号链接会拒绝。普通应用失败会回滚已写文件，但导入期间进程/磁盘故障仍需保留原备份恢复；同名JSON覆盖，不删除备份外的额外配置文件。
- `VERSION` 为发布版本源；默认每次发布末位加 1，末位逢 10 向中间位进 1，中间位逢 100 向首位进 1（`0.1.9` → `0.2.0`，`0.9.9` → `0.10.0`，`0.99.9` → `1.0.0`；`0.101.9` 归一为 `1.1.9`），同步前后端和 Docker 版本并打 `v` 标签。当前为 `v0.2.4`。检查更新气泡显示当前版本，不在关于页常驻显示。
