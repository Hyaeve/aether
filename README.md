# Aether 以太

当前版本：**v0.3.3** · [版本说明](docs/releases/v0.3.3.md)

Go + Vue 的自托管存储工作空间。主服务、STRM 播放代理、WebDAV 共用 **15151** 端口。

### WebDAV 用户

在 WebDAV 页面点击“添加用户”，设置独立账号、密码及可访问的目录；支持编辑、停用、删除，编辑时密码留空表示保持原密码。密码使用 bcrypt 哈希并随配置加密持久化。

管理员可使用管理账号访问全部启用的存储池，并在池内上传、建目录、移动及删除；聚合根和存储池入口不能写入或删除，跨池移动不支持，删除遵循存储池策略。独立用户仅能在 `/dav/` 下看到授权目录的显示名称，例如 `/dav/Movies/`，仍为只读，不能访问其他目录；未授权目录时根目录为空。支持浏览及 GET/HEAD 范围读取。撤销权限对后续请求生效，已经开始的读取不会强制中断。用户授权不会赋予管理后台访问权限；请使用 HTTPS 保护 Basic Auth 凭据。

WebDAV 列目录只读取文件元数据，不再通过下载接口探测 MIME。管理员 PUT 先暂存完整文件，再发布到目标；本地上传中断不会截断原文件，云端失败暂存保留于数据目录。支持会话内 LOCK/UNLOCK，不支持 COPY/自定义属性。云端写入仍受上游权限、配额和风控约束，不把挂载点权限等同于网盘权限。

## 当前实现

### 元数据插件与事件通知

- TMDB 配置：API 域名、图片域名、API 密钥（v3 Key 或 v4 Read Token）、匹配语言（简体中文/繁体中文/English）与请求间隔（默认250ms），窗口左下角测试连接；不展示手动搜索入口。
- AI 辅助识别：自定义 OpenAI 兼容 Chat Completions 地址、模型名称、API Key，地址默认留空。编辑窗口仅配置和测试连接，不显示待识别文件名；启停由插件卡片图标控制。保留受保护的识别接口，尚未接入自动整理/刮削流程。
- 代理配置：HTTP、HTTPS、SOCKS5/SOCKS5h，支持连接测试，当前用于上述 TMDB 与 AI 请求，不改变网盘传输及以链播放流量。
- Emby 通知：图标启停，在插件窗口复制 `POST /api/emby/webhook?token=...` 地址，使用 `application/json`，接收 Emby 中勾选的入库、播放及系统事件。保留事件名称和媒体信息，无媒体名称时使用事件标题/描述；不声称支持所有第三方通知载荷。入库事件兼容 `library.new`/`ItemAdded`，同服务器、同剧、同季十分钟内汇总，连续集数显示 `1-10集`，有间隔显示 `1、3-5、7集`。不同事件不混合去重。通知进入右上角活动弹窗及以链日志，保留最近50条；弹窗同时显示三条高度，可细滚动查看，清除按当前浏览器账号持久化，不删除任务或系统日志。默认令牌 `aether`，公网请更换难猜令牌。

TMDB、AI、代理、Emby、夸克接管和115同播复制配置加密存于 `/data/tools`，主配置仅保存快照引用；启动时自动迁移旧配置，保留最近两份已提交快照，密钥仍由 `/config/master.key` 保护。请同时持久化 `/config` 和 `/data`；配置备份包含插件实际内容，不依赖原路径。整理识别规则仍在 `/config/organize`。插件配置在当前登录会话内预取，退出时清除。

存储池启动15秒后错峰检测，之后每轮间隔一小时，单池超时30秒；直接请求根目录、不使用本地目录缓存。失败卡片显示红色描边，恢复后取消，检测不执行写入探测，也不将普通文件级错误当作账号故障。仪表盘提供存储文件管理快捷入口。

WebDAV 管理员文件属性不再标为只读，并记录失败请求；独立用户仍保持只读授权边界。FUSE兼容重复设置当前权限/属主及复制时设置时间戳，本地时间写入磁盘，云盘时间仅保留在当前挂载节点，重新挂载后以上游为准；不伪装支持云端chmod/chown。UID/GID为0且0777仍失败时，需要新日志确认上游权限或容器路径问题，不能仅凭界面值保证实际写入。

插件启停统一在卡片图标操作，编辑窗口只配置参数；代理地址明文显示给已认证管理员，API 密钥默认隐藏并按实际长度显示掩码。

### 通知与传输保留

传输任务仅展示进行中及三天内失败记录，成功条目不再展示，失败记录支持手动清除并保存于 `/data/cache/transfers.json`，重启后恢复（现有500条容量上限保留）。最近通知优先展示一天内记录，没有则回退到最近五条；任务通知包含存储/任务组合图标、名称、处理数量与结果。TMDB匹配语言支持简体中文、繁体中文和English，默认简体中文，请求间隔默认250ms且作用于API和图片请求；代理支持可选独立用户名/密码，密码加密存储、默认脱敏。

### STRM 作品识别

作品卡片左下角重置识别元数据（需确认，清除匹配与刮削状态，不删除磁盘NFO/封面/STRM），右下角识别并选择候选。优先显示作品目录内的cover、poster或folder图片，兼容jpg/jpeg/png/webp及单文件旁侧海报；封面接口须登录，只允许索引内作品关联的图片，不暴露任意容器文件。

STRM刮削以作品目录归组：季目录、特别篇归到剧集根目录，同一电影目录的多个版本合为一个作品；库根及分类目录散放的文件独立展示。目录结构和同目录分集证据优先于单文件电影判断，只扫描普通 `.strm` 文件，忽略图片、NFO、原视频和备份文件，并过滤旧索引中的非STRM条目。进入工作台自动重扫，纠正有明确剧集证据的旧自动电影匹配，保留手工匹配；没有季集证据的模糊名称仍需人工匹配。

### 115 读取诊断

115 下载按设备配置选择驱动接口（Android 使用 Android API，其余沿用驱动通用接口），异常记录接口、HTTP 状态与错误码，不输出 CK 或完整上游响应。DAV/FUSE随机读取、零字节读取及Range错误有回归测试；真实网盘风控或权限错误仍需部署后日志确认。

### 同播复制与内容替换

- **115 同播复制**：每个115存储只能配置一个复制目录，可分别启停。Aether签名播放入口十分钟内同一文件首次客户端使用原文件，后续不同客户端复制并加 ` (1)` 等数字后缀；核验副本ID、大小和SHA1后再获取直链。同一客户端复用副本，以IP+UA识别，不无条件信任转发头，同出口同UA设备无法区分。普通标记下载、DAV/FUSE以及不经过此入口的外部直链不触发。副本不自动删除，重启清空会话；未知复制结果不在窗口内自动重试，目标已有同名原文件时拒绝复制。没有真实115账号联调。
- **STRM 替换**：选择容器目录、匹配字段与替换字段，二次确认后后台递归替换 `.strm` 内容，不修改文件名。字面、大小写敏感替换，最多10000目录项、32层、每文件1MiB、执行30分钟；跳过符号链接。活动窗口显示进度及修改文件数，最多保留16条运行期记录，重启不续跑。逐文件原子发布并复核外部修改，失败前已修改的文件不会回滚，请先备份；无法完全排除外部写入与最后rename之间的极短竞态。

### ED2K 播放任务

新建ED2K任务必须绑定启用的115存储，源为本地存储。按媒体扩展名计算ED2K，输出保持目录结构的 `.strm`，内容为绑定任务及115存储的签名播放URL。媒体库请求该URL后，Aether将ED2K提交到绑定115的 `/Aether/ed2k`，等待确认任务完成且文件ID/名称/大小匹配，再返回针对播放器UA获取的真实直链。单次最多等待90秒，未完成返回错误，稍后重试只查询，不重复提交；不能保证无资源文件即时离线成功。

提交意图加密保存在 `/data/ed2k-playback`，不自动删除云端文件。任务停用、解绑或相关配置变化会撤销旧播放链接，需要重新生成；未知提交状态不自动重放。旧无绑定任务仍保留原ED2K文本生成兼容，新建和编辑必须绑定115。

STRM/CAS/ED2K的“保留扩展名”界面默认 `iso`，英文分号分隔且不区分大小写；例如 `disc.iso.strm`，未列入的扩展名则生成 `movie.strm`。CAS保持CAS文件内容与后缀，如 `disc.iso.cas`；旧未设置该字段的任务保留旧命名方式。命名冲突报错，不覆盖另一个同名媒体。源目录与容器生成目录选择器均可新建文件夹。

### 存储下载模式

115、移动、天翼、OpenList、WebDAV 可选“302 重定向”或“本机代理”，缺省302；夸克普通下载只走本机代理，TV接管仅用于播放，不接管文件下载、FUSE或WebDAV字节读取。下载模式作用于 Aether 签名播放/下载入口，不改写已经生成的 OpenList `/d/` 文件内容。

302不会将存储Cookie或Basic Auth凭据交给浏览器，WebDAV要求认证时应选择本机代理；115使用实际客户端UA取链，仍受上游IP/权益限制。OpenList可选择透传UA给下载接口，以及列目录时刷新上游（仅实际请求上游时生效，Aether本地目录缓存仍按缓存设置管理）。WebDAV超时用于目录请求和代理响应头等待，不截断正在传输的大文件。

存储启停只在卡片操作；删除模式仅在四种原生云盘表单显示，其他存储保留已有后台删除策略。115单文件夹详情显示目录CID。夸克TV修正HTTP400携带的失效令牌刷新、二维码等待状态和同时间戳签名；画质别名兼容，智能模式无兼容非HLS档位时会记录原因并回退本机代理。真实扫码/会员播放仍需账号联调。

### 天翼账号与令牌接入

天翼支持账号密码或 Token 接入：访问令牌与刷新令牌可手工填写，也可点击编辑窗口左下角“扫码获取 Token”回填。参考 OpenList 189CloudPC 请求官方扫码与会话接口；令牌失效时尝试刷新，并加密保存轮换后的凭据。账号风控、短信或设备验证仍可能要求重新授权，未绕过官方验证。

目录接口明确请求 JSON，同时支持 XML 目录与时间字段；响应缺少目录结构时报错，不再误报空目录。升级后如仍显示此前缓存的空目录，请在文件管理点击刷新。Token 模式存在 CAS 临时文件时禁止手动更换令牌，避免清理跨账号文件；自动续期不受影响。真实天翼账号、扫码及写入尚待实际环境联调。

### CAS 生成与目录选择

文件管理的列表/网格视图作为当前浏览器的客户端偏好保存，刷新或再次打开后恢复；不同浏览器独立，清除站点数据后重置。收藏夹仍按账号保存。工具菜单与存储池选择器共用展开/收起动效，并遵循减少动态效果设置。

CAS 任务只生成 CAS 文件，不提供“CAS 转 STRM”选项。源存储支持本地、原生移动和天翼；旧转换任务禁止执行，需要重新选择视频源目录并保存，已有输出不会删除。本地逐块读取视频并计算 SHA256、MD5，不把整部视频载入内存。生成 `原文件名.cas`（Base64 JSON，附带 retentionHours 保留时长），保留子目录、全量/增量和排除规则，输出位置沿用任务生成目录，留空为 `/data/strm`。CAS 的直接识别需要消费端支持此格式，不是普通 URL 文本，尚未验证真实媒体库直接播放。

CAS 任务需绑定已启用的移动或天翼存储。绑定移动时源目录只允许本地或原生移动存储；绑定天翼时只允许本地或原生天翼。本地来源同时保留 SHA256、MD5 与天翼分片摘要，可用于两种网盘的秒传；绑定只决定默认播放目标，不再删除另一种哈希。CAS 不包含账号凭据。旧云端任务可沿用源账号，旧本地任务需要编辑并选择绑定存储。

新生成的 CAS 内含 `playback_url`：访问该签名地址时由 Aether 秒传至绑定存储 `/Aether`，复用临时文件并返回 302 直链；默认保留12小时，从最后一次请求结束计时。客户端收到302后直接播放，Aether 无法观察直连播放结束时刻，需将保留时间设得足够长。以太链接能读取已被媒体库报告为本地 `.cas` 的文件并提取播放地址；**这不使媒体库自动支持扫描 `.cas`**，仍须媒体库或插件识别该扩展名，未验证真实入库。旧 CAS 缺少播放地址需重新生成。签名地址可触发账号内秒传，应视为播放凭证，不公开分享。

移动、天翼存储的离线下载窗口新增 CAS 秒传，选择一至二十个 `.cas` 文件直接还原到当前或所选网盘目录；同名不覆盖、哈希不兼容或未命中明确失败，不下载原视频兜底。成功导入的文件属于普通用户文件，不参与播放临时清理。

OpenList 默认 API令牌接入，也可选账号密码；账号登录取得令牌供浏览、下载、写操作使用，内存缓存30分钟，读写JSON接口返回401时重登一次。启用双重验证的账号请使用 API令牌。界面不再提供目录访问密码，已有令牌模式的旧目录密码保留兼容；账号密码不会作为目录密码发送。上传401不自动重放文件。新增和编辑存储池均禁止名称重复（忽略大小写与首尾空格）。

移动生成依赖目录接口提供 SHA256，天翼依赖 MD5，不将天翼 MD5 冒充 SHA256。缺少兼容哈希会明确报错，不下载完整云端视频补算；真实云盘生成仍待联调，是否秒传成功取决于云端命中与账号权限。

目录选择保存内部 ID 与显示名称、父级轨迹，重新编辑后可回上级或直接回根目录。旧任务没有保存名称时显示“已选目录”，重新选择后保存真实目录名。

通知展示每个任务最近一次结束状态（最多 30 项），已读标记按账号保存在当前浏览器，不是完整执行历史。更新检查读取 `ghcr.io/hyaeve/aether:latest` 的 linux/amd64 镜像元数据，比对构建时写入的 Git 修订号；成功结果缓存五分钟。不再依赖 GitHub Release API，不自动拉取或重启。镜像不可匿名访问、未发布、限流及网络异常分别提示；旧镜像或本地构建缺少修订号时明确提示无法确认更新，不冒充已是最新版本。

系统设置采用横向栏目。已登录管理员可直接修改账号和密码，不再输入当前密码；保存后撤销旧会话并签发新会话。新安装会话有效期默认 15 天，可设置 1–365 天，已有自定义值保持不变。登录令牌的 SHA256 摘要加密保存于 `/config/sessions.enc`，容器重启后仍可登录，期限从登录时计算，不因重启续期。退出仅撤销当前设备，更改账号密码撤销旧会话。请持久化 `/config`，保护已登录设备并通过 HTTPS 访问。

任务源目录选择器左侧选择存储池、右侧选择目录；CAS 显示本地、原生移动与天翼存储。存储池和源目录统一提交，取消选择不改动表单。

授权接口与回填已通过模拟测试，真实网盘扫码和第三方 OAuth 代理仍待账号联调。存储删除模式默认“移到回收站”，用于原生移动、天翼 CAS 临时文件清理和文件删除。文件写操作支持本地及115、夸克、原生移动、天翼；云端写接口仍待真实账号联调。目录整理及部分辅助插件尚未提供执行引擎，界面明确标注待实现；STRM 刮削的实现范围见下文。

### CAS 任务

CAS 栏目只从视频生成特征文件，使用方法见上方“CAS 生成与目录选择”。以下是旧签名播放链接的兼容逻辑，不是当前 CAS 任务创建流程：

1. 添加移动云盘，选择“原生新版个人云”，填写 Authorization（支持 Basic 前缀）；或添加天翼云盘，填写账号、密码，个人云根目录 ID 默认 `-11`。
2. 在 CAS 任务选择存储池、源目录、本地生成目录，配置全量/增量、Cron、API 间隔和排除规则。
3. 旧版本曾读取 `.cas` 的 Base64 JSON 并生成 `电影.mkv.strm`；这一转换任务现已停用。已生成的签名链接保留播放兼容。
4. 播放时调用对应网盘的原生秒传接口，在网盘根目录的 `/Aether` 内创建临时文件，通过 Aether 同端口代理播放，支持 Range/HEAD。并发请求与重启后的重播复用已记录文件。
5. 新 CAS 文件记录“还原文件保留时间”，默认 12 小时，支持 1–8760 小时，消费端须支持此字段才会生效。旧签名链接仍按最后一次播放结束后计时，活跃播放期间不清理；同一还原文件复用时取已应用的最长保留时间，缺少保留字段按 12 小时处理。
6. 临时文件记录随 `/config/state.enc` 加密保存，也可在 CAS 临时文件窗口触发过期清理。默认移到回收站，选择永久删除时才彻底删除。只删除以太记录的文件 ID，不扫描删除 `/Aether` 内的其他文件。旧目录中的已记录文件仍按 ID 复用、清理，不迁移或删除整个旧目录；新还原文件才写入 `/Aether`。

支持移动新版个人云的 SHA256 CAS、天翼个人云的 MD5 CAS；不支持家庭/群组云、旧版移动个人云、仅有 SHA1 的 CAS 或 torrent CAS 扩展。两种网盘的哈希不能互换。移动 Authorization 暂不自动刷新，失效后可更新同账号令牌。秒传依赖云端源数据及账号权益，不保证所有文件可还原，也不承诺不占配额。没有媒体上传兜底。签名 STRM 内含名称、大小和哈希，不含账户令牌；全量任务重写匹配文件但不清除本地孤儿文件。临时链接失效时会标记记录，下一次播放重试还原；崩溃恰发生在云端创建与本地记录落盘之间仍可能留下未记录残留。

天翼账号密码沿用 AES-GCM 加密配置存储，向官方 HTTPS 登录接口提交时使用官方公钥 RSA PKCS#1 v1.5 加密。会话仅缓存在内存，重启或一小时后重新登录；检测到失效时清除会话，下次请求重新登录。暂不支持图形验证码及设备短信二次验证，遇到风控会明确报错，需要在官方客户端处理后重试，不能保证由此解除风控。旧天翼网关池不会继续走网关：请编辑存储池填写天翼账户、重新选择数字目录 ID，并更新关联任务的源目录。

原生协议、CAS 扫描/播放/清理通过模拟云盘测试；尚未使用真实移动、天翼账号验证。协议参考及许可见 `THIRD_PARTY_NOTICES.md`。

## 明确的边界

这是一版可运行的基础实现，**不是完整需求的全部实现**。

- 115 / 夸克未以真实账户完成端到端验证。115 使用 Go `115driver` 的 CK 驱动，填写完整 Cookie 并选择对应设备，或点击“扫码获取 CK”直接使用 115 官方二维码；不再调用 LitePan OAuth。旧 Open 存储须编辑并重新填写 CK，不能将旧 Token 当作 Cookie。
- 移动的网关模式填写 OpenList 地址、API Token、根路径；原生移动使用 Authorization，天翼直接填写账号密码。真实账号仍待联调。
- 文件管理支持本地及115、夸克、原生移动、天翼的重命名、移动、复制、删除；云端只支持当前存储池内操作，跨云端池传输、OpenList/WebDAV写操作尚未实现。115/夸克仅支持回收站删除，永久删除明确拒绝，避免误删回收站其他项目；上传仍未实现。云端批量失败可能部分完成，请刷新核对。
- 备份任务、目录整理与部分辅助工具仍待开发；STRM 刮削核心流程、以太链接三种媒体反代及加密配置备份导入导出已实现，真实媒体库联调边界见末节。
- 本地挂载使用编译进 Go 二进制的 `hanwen/go-fuse/v2`，不使用 rclone 或内部 HTTP 桥；Windows 不执行挂载。支持聚合目录、读取、本机写入及云端暂存写入，Flush/fsync 等待上传确认。真实 Linux/Docker 挂载和网盘读写仍需联调。
- 元数据内存上限按 JSON 载荷及固定条目开销估算，不是 Go 进程 RSS 的硬限制。
- 管理员 WebDAV 根目录使用存储池名称；重名或与其他池 ID 冲突时附加 ID 区分，空名称或含路径分隔符等非法字符时回退为 ID。修改存储池名称会改变名称路径，旧 ID 路径保持兼容。独立用户仍使用授权目录名称。云端目录逐级解析；可能产生额外请求。
- 本版本配置与任务以加密 JSON 原子文件保存，适合单实例；不支持多实例共用数据目录。

## 本地运行

需要 Go 1.26+、Node.js 22+。

```powershell
cd web
npm ci
npm run build
cd ..
go run ./cmd/aether
```

访问 `http://localhost:15151`，创建管理员（密码非空即可，不设 12 字符下限；受 bcrypt 限制，最多 72 字节）。先在系统设置填写媒体服务器能访问的地址，例如 `http://192.168.1.10:15151`，再生成 STRM。

前端开发：在另一个终端执行 `cd web` 后运行 `npm run dev`，Vite 代理 API 至 15151。

环境变量：

| 名称                 | 默认值         | 用途                        |
| ------------------ | ----------- | ------------------------- |
| `AETHER_PORT`      | `15151`     | 管理后台、STRM、WebDAV 共用监听端口 |
| `AETHER_ADDR`      | 未设置       | 高级监听地址，设置后优先于 `AETHER_PORT` |
| `AETHER_WEB_DIR`   | `web/dist`  | 前端构建目录                    |
| `TZ`               | 由环境决定       | 定时任务时区，容器默认 Asia/Shanghai |

目录不再通过 `AETHER_DATA_DIR` / `AETHER_STRM_ROOT` 环境变量配置。容器固定使用 `/config` 保存配置、`/data` 保存运行数据；本地开发对应工作目录下的 `config/`、`data/`。独立测试可使用命令行参数 `-config-dir`、`-data-dir` 指定隔离目录。

任务目标目录留空时默认写入 `/data/strm`（本地开发为 `data/strm`）。也可填写相对路径（例如 `movies`，相对于默认目录），或任意容器内可写绝对路径；输入框内的文件夹按钮可浏览选择容器目录，不限制在 `/data/strm` 下。宿主机目录须先映射进容器。创建任务需要手动选择存储与源目录。选择源 `/B`、生成目录 `C`，实际写入 `C/B/...`；选择存储根目录时不额外添加存储名称。普通来源保留原扩展名，例如 `movie.mkv.strm`，避免同名不同格式文件覆盖；OpenList 来源使用 `movie.strm`，检测重名并报错。全量重写匹配文件但**不会删除已不存在源文件对应的旧 STRM**；增量只创建不存在的 STRM。

OpenList 来源生成服务地址下的 `/d/原文件路径`，包含存储配置的根路径；“编码路径”默认关闭，关闭时保留中文与空格，但仍保护 `%?#` 等 URL 分隔字符；开启后逐段编码。不会把管理令牌写入 STRM，暂不支持需要 OpenList 下载签名的受保护路径。Cron 留空仅手动执行；填写后才在编辑窗口显示定时调度开关，用于暂停或恢复 Cron。

115 来源生成 `http://主机:端口/d/pickcode.扩展名?/原文件名`，例如 `/d/cq391yoe47hu5dd6u.ts?/爱的迫降.S01E01.ts`。只有生成时注册的映射能访问，不接受任意 pickcode 查询；映射加密保存在 `/data/strm-index`，重启后恢复，需同时保留 `/config/master.key`。跨存储相同 pickcode 冲突会明确报错，不静默切换账号。该链接本身是长期访问凭据，不应公开传播；停用或删除对应存储后不可访问。302 模式最终是否下载由网盘响应和浏览器决定；需要 Aether 强制附件响应时使用本机代理模式。

夸克来源参考 LitePan 的存储/文件/令牌/文件名路径，生成 `/api/strm/play/存储ID/编码文件ID/t/播放令牌/n/文件名`；使用 Aether 自己的 HMAC 令牌，不是夸克 CK，也不接受 LitePan 的令牌。普通夸克通过本机代理并保留 Range/HEAD；启用 TV 接管且满足条件时返回 TV 302。复制 STRM 内完整地址到浏览器无需后台登录。旧 `/stream/...` 链接继续有效；要更新已有文件里的链接格式，请对对应任务执行一次全量生成，增量不会改写已有 STRM。

### 分享转存

115 分享预览使用当前 115driver 的 `115cdn.com/webapi/share/snap` 地址及分享 Referer；转存仍为单次 POST，HTTP 错误会标明预览/转存阶段，不自动重放写入，也不携带 CK 跟随重定向。上游风控或账号限制仍可能拒绝请求。

文件服务的“工具 → 分享转存”仅针对当前存储，支持115、夸克及原生移动个人云。分享链接一行一条（最多50条），链接附带的提取码自动解析，无单独提取码字段。转存目录按浏览器账号及存储记忆；关闭窗口后仍继续提交，消息气泡显示进度。115/夸克每批最多100个顶层项目；移动逐层展开目录（最多32层、5000项），每批至多1000个实际文件，保留目录结构。文件由网盘服务端转存，不经本机下载上传。拒绝跨网盘、同名项目及重复批次；目标预检不是上游原子操作，外部并发写入仍受上游规则影响。

预览仅在服务端内存保存10分钟，绑定管理员会话与存储配置，不向浏览器返回分享令牌。夸克轮询任务结果，115和移动只显示“已提交”，不冒称已完成。超时或响应丢失时请先检查网盘，避免重复转存；不自动重放写请求。真实账号仍待联调，不支持付费/风控验证分享，也不包含115生活事件监控或转存后自动触发STRM任务。

### 传输中心与任务扩展名

传输中心分为传输任务、备份规则，复制/下载/上传分栏显示浏览器代理读写、WebDAV和FUSE实际请求记录，最多保留500条记录；只展示进行中和三天内失败记录，失败记录可手动清除且重启恢复，成功记录不展示。云端复制仅记录提交请求，302直连后的下载不经过本机，无法获取真实字节进度；未知总量不显示虚构百分比。备份规则保留原页面的未实现状态，不冒称已有调度引擎。

STRM/CAS/ED2K可分别指定媒体和元数据扩展名，英文分号分隔、大小写不敏感。媒体留空使用视频+音频预设，元数据留空不复制额外文件；选中的元数据原样复制，单文件上限64MiB，不转换成STRM/CAS/ED2K。预设按钮可增删组，手工扩展名保留。重命名工作台支持忽略、单文件改名及底部命名规则集；刮削作品墙使用页面滚动和虚拟列表。

### STRM 刮削工作台

当前浏览器按账号保存选中的 STRM 库，已删除的库自动回退。识别参考 LitePan 的目录与季集证据流程独立实现：支持 Season/SNN/中文季目录、特别篇、SxxExx、1x02、EP02、中文集数及同作品目录下的多项纯数字分集；电视剧跨季聚合，未匹配的旧索引会重新解析。保留手工匹配，不以文件数量直接判断所有目录为电视剧；复杂别名和无季集线索仍可能需要手工确认，并非 LitePan 全量识别能力。

任务条支持拖拽、菜单上移/下移及 Alt+方向键排序，顺序保存到服务器。时间显示月日时分秒，悬浮或键盘聚焦时切换为任务结果。

新建 STRM、CAS、ED2K 任务时，Cron 留空则按服务端创建时所在小时保存每日整点计划，例如 14:05 或 14:59 创建均填入 `0 14 * * *`。按服务时区执行（镜像默认 Asia/Shanghai），首次执行为下一个匹配时刻；手填表达式、已有任务及编辑时清空不受影响。缓存任务继续使用执行间隔。

任务管理的 STRM 刮削栏目默认选择首个 STRM 任务，进入或切换任务时自动扫描实际生成目录（含非根源目录的子目录），生成的作品无需手动刷新索引即可显示为待匹配；当前任务生成结束也会刷新。自动发现不依赖 TMDB，不修改 STRM 指针、不写 NFO，并保留已有匹配；刮削运行期间读取已保存索引，结束后再刷新。支持状态/名称筛选、虚拟海报墙、开始/停止、整组重新匹配和重新刮削。识别和刮削使用已启用的 TMDB 与代理配置；按名称和年份查找唯一匹配，歧义/未命中由用户选择候选或填写 TMDB ID 确认，也可从文件名 `{tmdb-123}` 读取 ID。

电影写入同名 NFO 与海报，剧集支持 tvshow.nfo、SxxExx 分集 NFO 和预览图，可选背景图和演员信息。默认仅补缺，也可覆盖已有元数据；配置位于 `/config/organize/strm-scrape.json`，索引位于 `/data/cache/scrape`。单次最多扫描 10000 个 STRM，跳过符号链接，输出使用受限目录和原子发布。电视剧请按每部作品单独目录组织，支持 Season 或 Sxx 季目录。

当前是核心刮削流程，不是 LitePan 完整复刻：暂未实现作品级海报墙、剧集完结标记、季海报/season.nfo、clearlogo、AI 自动匹配及调度；索引状态在单次执行结束后更新，重启中断不自动续跑。真实 TMDB 网络和媒体库入库效果仍需联调。

缓存有效期优先级：任务 > 存储池 > 全局；0 表示继承。缓存任务默认 60 分钟执行一次，有效期仍按此优先级决定。扫描层级 0 为全部（最多 128 层），1 仅当前目录。API 间隔默认 200ms，安全下限 200ms；同存储池一次只运行一个任务。Cron 使用五字段，本地运行跟随进程时区。

缓存任务页展示命中率、估算大小、条目数、命中/未命中、LRU 淘汰、过期计数，以及执行中的已扫描目录数。统计为进程生命周期累计，重启后计数重置；扫描总量未知，不显示虚构百分比。文件浏览、任务遍历、STRM/CAS 云端元数据读取与挂载目录读取共用 TTL/LRU 缓存；命中不等待 API 间隔，同一目录的等价并发请求合并。刷新绕过本地缓存，文件写操作清空缓存，清空前的在途结果不会重新填入。整理引擎尚未实现；本地哈希仍读取文件计算，秒传是否成功仍由云端确认，不能用旧缓存代替。

聚合挂载目录使用存储池名称，例如 `Quark`，不再带内部 ID。同名存储使用稳定按 ID 排序的数字后缀（如 `Quark (2)`），并避开已有同名目录；修改名称后路径会变化。

### 夸克 STRM 接管

绑定窗口沿用 LitePan 的左右工作区结构：左侧账号列表和添加绑定，右侧选中账号、解绑、清晰度、杜比及接管模式，底部保存。策略分流使用直连名单/代理名单切换，客户端关键词以分号分隔；每个绑定分别保存，解绑需确认。

STRM任务“更多选项”中的“STRM 刮削”默认参与，设为不参与后不再出现在刮削工作台的库选择器，后端也拒绝将该任务作为刮削库；不影响STRM生成，不删除既有索引或元数据。旧任务默认参与。

辅助工具中的夸克接管通过“添加绑定 → 选择存储 → 扫码”分别绑定多个夸克存储，已绑定存储不再出现在可选列表，接口也拒绝重复绑定。插件图标控制整体启停，各绑定可设置智能变轨/强制直连/策略分流、最高画质与杜比选项。只接管 Aether 签名 STRM 播放，不改 WebDAV/FUSE 读写；智能变轨遇到仅 HLS 片源、授权失败或无可用画质时退回原网页 Cookie 播放通道。TV 直链在内存缓存五分钟，上限 1000 项；更换网页 Cookie 后须解除旧绑定后重新扫码。

扫码采用参考项目所用 extscreen 服务的 HTTPS `/quarkdrive/token` 接口，需要明确同意向第三方发送授权码/刷新凭据；网页 Cookie 不发送给该第三方。凭据加密保存在 `/data/tools` 快照并纳入加密配置备份，普通状态接口不返回令牌。保存前参考 LitePan 比对 TV 与网页账号昵称，缺失或不一致即拒绝；两端 UID 命名空间不同，昵称可重名，因此该校验不是严格唯一身份认证，仍须使用同一账号扫码。真实扫码、权益、风控与播放器兼容性尚待账号联调。

直链缓存中的“适配”表示音频兼容处理：M4B/WMA 转为 AAC-LC M4A，或 AAC 重新封装为 M4A；它不是内外网跳转策略。以链卡片随初始化状态一同返回（凭据脱敏），在本次登录的内存中复用并后台刷新，退出登录时清空，不写浏览器本地存储。

## Docker

在支持 `/dev/fuse` 的 Linux Docker 主机：

`compose.yaml`：

```yaml
services:
  aetherlink:
    image: ghcr.io/hyaeve/aether:latest
    container_name: Aether
    network_mode: host
    volumes:
      - ./config:/config
      - ./data:/data
      # 可选：将 FUSE 读缓存单独映射，建议放到更快的磁盘
      # - ./fuse_read_cache:/data/fuse_read_cache
    environment:
      - TZ=Asia/Shanghai
      - AETHER_PORT=15151
    devices:
      - /dev/fuse:/dev/fuse
    pid: "host"
    privileged: true
    restart: unless-stopped
```

启动服务：

```sh
mkdir -p config data
docker compose pull
docker compose up -d
```

默认 `host` 网络，不使用 `ports` 映射；特权与 FUSE 设备按需求启用。Docker Desktop 或非 Linux 环境不适用此默认 FUSE 配置。没有挂载需求时，建议移除 `privileged`、`devices` 并将本机目录绑定设为只读。

自定义端口：修改 `compose.yaml` 的 `environment` 中 `- AETHER_PORT=15151`，例如改为 `- AETHER_PORT=15200`，然后运行 `docker compose up -d` 重建容器。管理后台、STRM 播放代理和 WebDAV 都使用新端口，容器健康检查同步跟随。有效端口为 1–65535；不要同时设置 `AETHER_ADDR`，除非需要覆盖监听地址。

端口变更不会覆盖已保存的外部访问地址。请在「WebDAV」页面更新媒体服务器可访问的外部访问地址（例如 `http://192.168.1.10:15200`），并重新全量生成已有 STRM。反向代理使用独立公网端口时，外部访问地址应保留其实际地址。

如需本机存储，可自行在 `volumes` 下添加 `- ./storage:/mnt`，将宿主机 `./storage` 映射为容器内 `/mnt`。默认配置不包含这一挂载；它不是 STRM 输出目录。

FUSE 读缓存已接入原生 go-fuse，云端只读文件按需缓存4 MiB块到 `/data/fuse_read_cache`，默认随 `/data` 映射，已有单独映射现在会实际存放缓存。固定上限10 GiB、65536块，按LRU淘汰，闲置7天的块下次访问或写入缓存时清理；本地文件、目录与写句柄不缓存。缓存盘不可用时直接读取上游，不依赖rclone；未完整获取或校验失败的块不作为命中。当前未提供容量设置界面。

缓存键隔离存储配置、路径、大小、修改时间和目录缓存代次；Aether写入/删除/改名及文件管理手动刷新会使旧块失效。每次进程启动后的首次缓存读取会清理上一进程块，暂不跨重启复用；网盘外部同大小且未更新修改时间的修改需手动刷新，不承诺远端强一致。缓存为明文媒体字节，请保护挂载目录权限，缓存不是备份。命中不会计为上游下载流量；缺失块读取会包含预读字节。

容器持久化目录：

| 容器目录 | 宿主机默认目录 | 内容 |
| --- | --- | --- |
| `/config` | `./config` | `state.enc` 保存管理员、存储池、任务和系统设置；`master.key` 保存加密密钥 |
| `/config/organize/organize-rules.json` | `./config/organize/organize-rules.json` | 整理规则预留配置 |
| `/config/organize/categories.json` | `./config/organize/categories.json` | 二级分类预留配置 |
| `/config/organize/upgrade-policies.json` | `./config/organize/upgrade-policies.json` | 洗版策略预留配置 |
| `/config/organize/ai.json` | `./config/organize/ai.json` | AI 辅助识别预留配置 |
| `/config/organize/recognition-rules.json` | `./config/organize/recognition-rules.json` | 识别规则预留配置 |
| `/data` | `./data` | 目录缓存快照等运行数据 |
| `/data/strm` | `./data/strm` | 默认 STRM 输出位置，仅首次实际写入时创建 |

整理识别配置统一归入 `/config/organize/`，五个 JSON 文件在该目录中平铺，不为每项规则再建子目录。账户、密钥和系统设置仍保存在 `/config` 根目录。启动时，新位置缺失的文件优先从旧 `/config` 根目录复制，旧文件保留作为备份；新位置已有文件不会被覆盖，无旧文件时初始化为 `{}`。规则模块尚未实现，这些文件暂不参与规则执行。启动、创建任务或没有匹配视频的扫描都不会创建 `/data/strm`。更早版本的独立规则目录不自动删除或迁移其内容，以免误删已有数据。

`config/master.key` 与 `config/state.enc` 必须一起备份；丢失密钥不可恢复配置。升级时，如果 `/config` 尚无配置，自动复制旧 `/data/master.key` 与 `/data/state.enc` 至 `/config`，保留旧文件；已有 `/config` 配置不会被覆盖。迁移后以 `/config` 为准，旧文件只作备份，不会继续同步。

GitHub 构建默认发布 `ghcr.io/<owner>/<repo>:latest`、版本标签和 SHA 标签。修改 Compose 的 `image` 可指定已发布镜像版本；首次发布可能需在 GHCR 中配置包可见性。PR 只构建不推送。

## 安全与运维

- 首次初始化接口只在尚无管理员时生效；初始化前应仅在可信网络开放服务。
- 公网部署应通过 HTTPS 反向代理访问。WebDAV Basic Auth 不应在不可信网络使用明文 HTTP。
- STRM 链接携带长期 HMAC 签名，可被持有者访问；将 STRM 视为访问凭据。
- 管理员有权指定网络上游和可读取的本机根目录，因此管理员权限等同服务可访问范围。不要向不可信用户授予管理员。
- 数据密钥与密文位于同一持久化目录，加密不防御完整主机或完整数据卷失窃。
- 元数据缓存快照不含认证凭据，但包含文件名；需要保护数据卷。
- 当前配置会在保存缓存策略时清空旧缓存；源文件变动需刷新目录或等待缓存失效。

## 验证

侧栏“文件服务”包含文件管理、WebDAV、本地挂载三个栏目，默认打开文件管理。旧 `/webdav`、`/mounts` 地址自动跳转至对应栏目。

### 本地挂载

- 挂载配置包含名称、存储池/子目录、容器挂载点、只读、自动挂载及 UID/GID/权限。新建默认只读关闭、自动挂载开启，权限为 `0 / 0 / 0777`（文件移除执行位）；已有配置不自动改写。共享给所有本机用户不符合部署需求时应收紧权限。源目录不选存储池直接确认表示所有启用存储池；聚合根目录重名时附加数字后缀。
- 保存仅保存配置，点击卡片挂载按钮立即挂载；自动挂载表示下次服务启动自动执行。编辑或删除前需先卸载。真实挂载确认依赖 Linux mountinfo，不以子进程启动成功代替挂载成功；失败可在存储与服务日志查看。
- 挂载名称、源目录、挂载点分行配置。源可选择所有存储池、整个单一存储池或子目录；本地存储目录默认留空，与挂载点共用容器目录浏览器，路径各级（含根目录）可点击跳转。
- 镜像仅保留 fuse3 系统卸载辅助程序，挂载引擎 `hanwen/go-fuse/v2` 编译进主程序，直接调用存储操作，不依赖公开 WebDAV 服务。本机读写用 `os.Root` 限制在所选目录内；云盘随机写入先暂存于 `/data/cache/mount-upload`，Flush/fsync 上传并确认后发布，失败保留暂存。修改已有云端文件会先下载完整内容，适合文件复制，不适合数据库等高频随机更新；单文件写句柄互斥，写入期间改名/删除返回忙，非空目录不能直接 rmdir，覆盖改名和修改挂载权限不支持。删除遵循存储回收站策略。真实 Linux 内核挂载与各网盘仍需联调。
- FUSE 容量查询返回本地池的底层磁盘容量，云盘及聚合入口返回本机暂存数据盘容量，不再返回零容量，也不冒称这是云盘剩余配额。虚拟文件权限由挂载配置的 UID/GID/Mode 控制，宿主父目录0777不覆盖容器内配置、底层文件权限或网盘权益；修改挂载配置后需重新挂载。
- FUSE 使用内核 `default_permissions` 检查虚拟权限与附加用户组，不将后台管理员身份当成 Linux 用户身份。既有0755挂载允许其他用户读取，但不允许其上传；需要写入时调整挂载自身权限或UID/GID并重新挂载。真正的内核挂载和外部账号仍需现场验证。
- 挂载点选择已存在的父目录，实际挂载到其下的 `AetherDrive`：选择 `/挂载` 即挂载到 `/挂载/AetherDrive`。保存配置不创建目录，启动挂载时才创建该子目录；已有子目录必须为空且不是符号链接，不覆盖或删除原有数据，父目录中的其他文件保持不变。旧配置下次启动同样使用该子目录。
- 实际 `AetherDrive` 目录不能与配置、运行数据、系统目录重叠，不能与本次明确选择的本地源目录递归包含。允许将云盘或聚合存储挂到已有本地存储根下，如 `/NetDisk/AetherDrive`；聚合挂载会排除与挂载点重叠的本地池，避免无限递归，其他存储仍可访问。可先在宿主机创建目录，再显式绑定至容器，如 `- /srv/aether-mount:/mounts/media:rshared`；宿主机实际访问 `/srv/aether-mount/AetherDrive`，是否可见 FUSE 子挂载仍取决于父挂载传播设置。
- Linux 容器需要 `/dev/fuse` 和挂载权限。Windows 可保存配置但点击挂载会明确报错。已实现独立磁盘分块读缓存，未验证真实Linux内核 FUSE 挂载或真实网盘账户，不把交叉编译通过等同于现场联调成功。

115 CK 支持网页、安卓、iOS、电视、支付宝小程序、微信小程序和新版 Android 设备。扫码设备绑定到当前管理员的五分钟加密会话，CK 加密保存在配置中；同设备重复登录可能使旧 CK 失效。目录、下载、文件操作、上传及云下载通过 `115driver` 接入，不依赖第三方 OAuth。移动云盘添加和编辑仅提供支持 CAS 的新版个人云 Authorization；旧网关存储运行兼容保留，编辑保存为原生前需填写新授权。

## 以太链接与 v0.1.1

- 支持 Audiobookshelf、Emby、飞牛影视，每个以链独占一个1024–65535端口。host网络下确保端口空闲并配置防火墙；服务地址不能指向自身反代端口。
- 以链管理使用卡片添加、编辑、删除，点击媒体图标启停；支持始终跳转、公网跳转、内网跳转、始终中继。网段从本机网卡自动识别，不信任未经配置的转发IP头。
- 配置API Key或飞牛账号密码用于媒体解析；播放器仍须持有媒体服务器自己的访问权限。每次播放在解析/缓存返回前向上游校验播放器凭据，不能用以太管理员Cookie替代媒体登录。
- Audiobookshelf的STRM文件须在以太容器中以相同路径可读；默认允许 `/data`、`/mnt` 下指针与本地目标，其他路径需映射至这些路径。Emby/飞牛直接返回HTTP媒体地址时不要求本地STRM映射。源文件不可读会回退透传。
- “直链缓存”展示最近2000条真实播放流水。解析缓存沿用AetherLink按上游/媒体/客户端身份/UA隔离的TTL/LRU：ABS和移动短效直链15分钟，Emby默认2小时，签名链接按有效期缩短，上限24小时，容量4096。缓存持久化位于 `/data/cache/link`，包含敏感媒体直链，请保护数据卷。
- ABS 公开会话音轨在播放前使用播放器原始凭据向实际音轨入口发起单字节 Range 校验，不注入以链 API Key。避免新建会话尚未落库时被 `/api/session/:id` 的 404 提前阻断；解析仍沿用活跃会话回退。上游拒绝或跳转不会被当作授权成功。该修复已模拟验证，不能替代真实播放器现场排查。
- 以链默认启用 AetherLink 的上游跳转跟随：读取 STRM 后，以播放器有效 UA 探测中间地址，HEAD 不支持时改用单字节 Range GET，跟随重定向并缓存最终地址，再按客户端内外网和跳转模式决定 302 或代理。新缓存使用 `*-direct-v2.json`，不读取旧的未探测地址缓存；旧文件保留。若 STRM 后端启用了本地代理、直接返回媒体而非重定向，无法凭该响应推导网盘直链；探测失败仍沿用 AetherLink 的原地址回退并记录警告，不能保证真实播放成功。
- 镜像加入FFmpeg。Apple/iOS客户端的STRM音频目标，以及映射到容器内的Audiobookshelf原始AAC/WMA/M4B文件，支持AAC重新封装、WMA/M4B转AAC-LC M4A，通过本地Range响应播放。缓存按书籍/变体分目录存入 `/data/cache/link/audio`；两小时未使用回收，十分钟扫描过期，每24小时清理空目录，启动也清空目录。共享缓存避免重复转换，活动读取与生成中的文件受保护。未实现通用媒体标签补全引擎。
- 文件管理支持可点击路径、列表/网格切换、按存储池保存收藏夹；这些偏好按账号保存在当前浏览器，不属于服务端配置备份。单击选中、双击进入目录、Shift 连选、F2 重命名、右键移动/复制/删除；列表支持名称、大小、类型、修改时间排序。本地删除默认移到源根目录 `.aether-trash/<随机ID>/`，永久删除须在存储池设置中显式选择。同池移动使用重命名，跨本地池复制完成后才移除源项，失败会明确报告已完成数量；不支持符号链接，目标重名不覆盖。
- 文件栏目右侧提供刷新、搜索和工具菜单。刷新或点击非功能空白区域取消选中。新建文件夹先编辑名称，回车或点击空白区后提交，空名称取消；F2/右键单项重命名保留内联编辑。工具菜单的重命名进入工作台：有选择时作用于选择项，否则作用于当前目录全部项；左侧原新名称对比、右侧顺序查找替换规则，支持大小写、首次匹配和规则排序。预览不修改文件，确认时校验预览与名称冲突，不覆盖已有项目；中途失败报告已完成数量，不承诺跨云端事务回滚。规则集保存在 `/config/organize/rename-rules.json`，可复用、删除并随配置备份导出。
- 右键查看详情自动统计文件夹大小（最多 5 分钟、128 层、100000 个项目，云端目录请求间隔 200ms），完整统计成功后写入共享 TTL/LRU 目录缓存并显示在大小栏目；缓存持久化随系统设置，文件操作清空缓存，统计失败不把部分结果当作完整大小。路径紧凑显示，过长时保留根目录和尾部目录。
- 文件列表/网格与目录选择器使用虚拟滚动，只渲染视口附近项目；系统日志和直链缓存继续使用虚拟列表。目录 API 仍会按现有驱动分页读取完整目录，不是服务端按视口分页。移动、天翼、夸克、115 补充上游修改时间字段解析，未提供时间时显示空值，不伪造时间；旧缓存可通过刷新更新。
- 上传文件及文件夹支持浏览器选择，保留文件相对目录；浏览器不提供空目录条目，因此空目录不会上传。文件先暂存于 `/data/cache/file-upload`，再提交至当前存储，结束后清理暂存；单文件上限 100 GiB，同名文件拒绝覆盖。云端提交复用现有上传协议，失败可能留下上游 `.aether-upload-*` 文件，需要核查后处理。
- 115 使用原生云下载：每批最多 50 个 HTTP/HTTPS/FTP/磁力/电驴链接，或 20 个种子（单个 8MB、请求 64MB），默认当前目录。“115 云下载”窗口直接提交到云端；公开 v1/混合种子解析为保留哈希和 tracker 的磁力链接再提交，不上传种子文件。私有种子和纯 v2 种子明确拒绝，云端能否发现元数据及下载成功取决于 115 服务，进度请在网盘查看。其他存储使用独立的“内置离线下载”窗口。
- 本地 CAS 参考 OpenList 的分片特征协议，流式计算 10 MiB 分片 MD5 和拼接摘要，保存在 `.cas` 的 `slice_md5`、`slice_size` 字段，同时保留 MD5 和 SHA256；天翼还原时使用分片秒传接口，不上传媒体内容。旧的仅 MD5 天翼 CAS 继续走原秒传接口。暂未导入或导出 OpenList `.cas.torrent` 容器。
- 其他存储采用与 LitePan 相同的进程内下载技术路线：HTTP/HTTPS 使用 Go `http.Client`，磁力/BT 种子使用 `anacrolix/torrent`，不需要 aria2 或独立下载进程；下载完成后上传到所选存储目录。内置下载不支持 FTP/ED2K，不冒充夸克原生离线接口。一次执行一个批次、批次内串行，单项最长 24 小时，磁力元数据等待上限 10 分钟；单项总大小上限 100 GiB，BT 最多 10000 个文件，不上传做种、不自动映射路由端口。暂存于 `/data/cache/offline`，上传成功清理，失败保留，不覆盖同名目标，结果见系统日志。HTTP 重定向有界、部分下载不会发布，BT 经分片验证后上传。重启中断的下载尚不自动恢复，保留目录需管理员处理；需自行保证磁盘空间、网络权限和下载内容合法性。回环 HTTP 和 BT WebSeed 已测试，真实网盘、公网磁力发现与 Docker 运行尚待联调。
- ED2K 任务位于 CAS 后，支持本地存储按媒体扩展名计算哈希，以及全量/增量、Cron 和排除规则。新任务绑定115并输出签名STRM，播放时通过115原生离线服务还原后取链；旧无绑定任务保留 `.ed2k` 输出兼容。详见“ED2K 播放任务”，不使用内置下载器下载ED2K。
- 直链缓存展示“模式 / 链接 / 请求 IP”，模式简写为 302、透传等。IPv4/IPv6 直接请求取连接来源；同主机反代默认信任本机地址的转发头，其他反代须显式设置 `AETHER_TRUSTED_PROXIES`，例如 `172.18.0.2/32,fd00::2/128`，且反代应覆盖或追加真实客户端转发头。不要填写整个不可信网段。NAT 未保留来源且没有可信转发头时无法还原真实客户端，仍显示实际上一跳地址。
- 配置备份位于辅助工具最后一项。导出时设置非空备份密码，使用 PBKDF2-HMAC-SHA256（随机16字节盐、600000轮）派生密钥、AES-256-GCM 加密，输出 `.aether` 文件；没有密码无法恢复。备份包含管理员、存储池、以链、任务、系统设置及配置目录JSON，不含媒体、日志和数据缓存，不明文导出 master.key。旧版未加密ZIP不能直接导入。
- 导入先选文件再输入导出时设置的密码。校验后用当前安装的密钥加密暂存 `/config/import.pending`，重启容器时应用，并使用备份中的账号登录；当前运行配置不热替换。错误密码、篡改、越界路径和符号链接会拒绝。普通应用失败会回滚已写文件，但导入期间进程/磁盘故障仍需保留原备份恢复；同名JSON覆盖，不删除备份外的额外配置文件。
- `VERSION` 为发布版本源；默认每次发布末位加 1，末位逢 10 向中间位进 1，中间位逢 100 向首位进 1（`0.1.9` → `0.2.0`，`0.9.9` → `0.10.0`，`0.99.9` → `1.0.0`；`0.101.9` 归一为 `1.1.9`），同步前后端和 Docker 版本并打 `v` 标签。当前为 `v0.2.8`。检查更新气泡显示当前版本，不在关于页常驻显示。

## v0.2.8 文件浏览与媒体识别

- 当前浏览器按账号保存存储池选择、排序字段和正倒序；失效或停用的存储池自动回退，URL 显式选择优先。列表/网格偏好继续沿用客户端设置。
- 单个文件夹可通过右键下载，确认后由以太流式输出 ZIP，保留空文件夹，不创建临时压缩包。最多 100000 项、128 层、24 小时；经过以太代理传输，不是文件夹 302。校验失败或读取中断不会生成完整 ZIP；上游要求额外重定向或权益时可能失败，需重试或逐文件下载。
- 详情增加递归文件/目录计数并随大小缓存；115 文件夹 CID 位于位置上方，可点击复制。创建时间只显示上游提供的真实值，未提供时显示“未提供”，不会冒用修改时间。
- OpenList 透传 UA 与列目录刷新改为是/否选择器。任务条仅保留存储图标、任务名、存储名和三点操作菜单；点击图标控制启停，定时执行仍由 Cron 或缓存间隔决定。
- 夸克 TV 授权按 LitePan 协议直接显示 JPEG/PNG Base64 图片，不再把整张图片编码成另一个二维码；兼容 HTTPS 授权链接，保留第三方换取凭据确认、同账号绑定和过期处理。二维码窗口有等待状态和倒计时，真实账号扫码与播放仍需现场联调。
- STRM 刮削按作品展示虚拟海报墙。同目录同名电影归组，电视剧跨 `Season N` / `SNN` 季目录归组，保留分集季集；同名但不同库目录不会合并。先“识别 STRM 库”获取海报与候选状态，不写 NFO；待匹配作品可按名称、媒体类型搜索 TMDB 海报候选或手工填写 ID，整组确认后再刮削。识别没有唯一结果时不自动确认。
- 不宣称已完整复刻 LitePan：中文季集目录、复杂别名和混合结构仍可能需手动匹配；缺少 TMDB 配置或上游海报时显示占位图。识别/刮削进度与现有任务一样仅运行期维护，不支持重启续跑。

本轮以模拟媒体服务器验证三种协议、独立端口、授权与302缓存；以本机FFmpeg实际生成M4B并转为M4A验证缓存复用。尚未在真实媒体库、真实iOS播放器和Docker容器内联调。
