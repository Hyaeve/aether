# 视频预览

文件管理视频预览保留当前目录、当前显示排序的视频列表，上一集和下一集不循环，不含文件夹或其他类型文件。切换后尝试播放新视频，是否自动播放仍受浏览器策略限制；媒体格式支持由浏览器决定。

空格切换播放/暂停，上下键每次调整5%音量。全屏时Esc先回到窗口，窗口时Esc关闭；点击窗口外不会关闭。标题叉始终可以关闭。进度条在控制按钮上方，音量支持静音、滑轨及滚轮。视频与音乐共用竖向填充音量条，数字在顶部、不显示百分号和圆点；音量弹层使用深色不透明哑光表面，不使用背景玻璃模糊。

字幕按钮悬浮/聚焦展开轨道菜单。常规窗口显示四行，无可见滚动条；更多轨道仍可滚动或通过键盘访问，小屏高度随视频窗口收紧，避免越出视频边界。浏览器已暴露的字幕轨道直接使用；否则认证接口通过已有存储读取器和仅回环临时源交给FFprobe探测。内置SRT/ASS/SSA/WebVTT/mov_text/text轨道转换成WebVTT；ASS排版样式不保留，图片字幕不做OCR。服务端需安装FFmpeg和FFprobe（Docker镜像包含）。

字幕按播放时间每300秒窗口转换，切换时间窗或跳转后重新加载；时间线按窗口起点平移。每请求60秒、源正文最多256MiB、源HTTP请求128次、输出4MiB、轨道64条，复用媒体探测并发门。源只在127.0.0.1临时监听、随机路径、只读，FFmpeg不可接收客户端传入的地址/任意路径；远程凭据仍由原存储读取器管理，不传给子进程或日志。取消/关闭释放进程和监听。长码率或不支持随机读取的来源可能超过限额而无法提取字幕，不会自动下载整部影片。
