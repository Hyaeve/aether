# 视频预览

文件管理视频预览保留当前目录、当前显示排序的视频列表，上一集和下一集不循环，不含文件夹或其他类型文件。切换后尝试播放新视频，是否自动播放仍受浏览器策略限制；媒体格式支持由浏览器决定。

空格切换播放/暂停，上下键每次调整5%音量并显示短暂数字提示，左右键每次前进/后退10秒。全屏时Esc先回到窗口，窗口时Esc关闭；点击窗口外不会关闭。窗口标题叉可关闭播放器，全屏时原位置改为视频信息按钮。进度条在控制按钮上方，音量支持静音、竖向填充滑轨及滚轮，控件与音乐播放器复用。

字幕右侧提供音轨菜单。浏览器暴露 `audioTracks` 时可切换并显示当前音轨；没有该能力时只展示服务端读取到的音轨，明确提示不能切换，不以按钮状态假装切换成功。信息面板由右上角叉显式关闭，展示实际可读取的容器、大小、编码、尺寸、帧率、HDR、音频采样率与码率；缺失指标显示未知，实时网速暂不伪造，缓冲时长取自浏览器缓冲区。

字幕按钮悬浮/聚焦展开轨道菜单。浏览器已暴露的字幕轨道直接使用；否则认证接口通过已有存储读取器和仅回环临时源交给FFprobe探测。内置SRT/ASS/SSA/WebVTT/mov_text/text轨道转换成WebVTT；ASS排版样式不保留，图片字幕不做OCR。服务端需安装FFmpeg和FFprobe（Docker镜像包含）。

字幕加载时会暂时禁用轨道选择；若浏览器因此移除按钮焦点，鼠标仍在菜单内则继续保持菜单打开，“关闭字幕”仍可操作。焦点在菜单内部移动也不触发关闭，鼠标离开保留短暂移入容错。

文件网格的首次视频缩略图等待浏览器的视频帧回调后再绘制，不仅依赖`loadeddata`或`seeked`事件；旧浏览器采用播放就绪后的绘制降级。捕获完成即暂停并卸载临时视频源，离开网格取消未完成捕获，沿用既有20秒总限额、320px最长边和512KiB图片上限。真实黑色视频帧不会被颜色判定规则丢弃。

字幕按播放时间每300秒窗口转换，切换时间窗或跳转后重新加载；时间线按窗口起点平移。每请求60秒、源正文最多256MiB、源HTTP请求128次、输出4MiB、轨道64条，复用媒体探测并发门。源只在127.0.0.1临时监听、随机路径、只读，FFmpeg不可接收客户端传入的地址/任意路径；远程凭据仍由原存储读取器管理，不传给子进程或日志。取消/关闭释放进程和监听。长码率或不支持随机读取的来源可能超过限额而无法提取字幕，不会自动下载整部影片。

视频信息认证接口复用同一有界源和并发门，只允许当前目录中已授权的视频条目；响应只包含白名单技术字段，不返回原始文件地址、任意容器标签或凭据。
