# 存储会员信息

存储卡片支持115年费VIP、永久VIP、普通VIP，移动白银/黄金/钻石、天翼黄金/铂金，以及夸克VIP、SVIP、SVIP+、88VIP和迷你VIP的紧凑徽章。徽章位于卡片右上角、横向三点菜单上方，会员名称和小图标同行，卡片背景保持日夜主题的统一底色。仅展示上游明确返回的当前会员，不按容量、PC客户端、用户名或套餐价格推测；徽章本身不修改授权或账号权益。CAS新建秒传另按实际会员和客户端预检单文件额度，移动及天翼规则见[CAS绑定池](cas-pool.md)，仍以上游实际命中为准。

## 只读来源

- 115：官方网页使用的`https://passportapi.115.com/app/1.0/web/26.0/user/base_info`，匹配当前账号ID后读取`vip_info.level_name`中的明确年费/永久名称。未能明确识别时，复用115driver的只读`GetUser()`，仅在`forever > 0`时显示永久VIP，或`vip > 0`且`expire`未过期时显示普通VIP；不把普通VIP猜成年费，不把“长期VIP”擅自等同永久VIP。
- 移动：原生个人云只读`/orchestration/group-rebuild/member/v1.0/queryUserBenefits`，请求`isNeedBenefit:0`。按`userSubMemberList`的`memberLvName`或`chargingPolicyList.prodName`中的明确名称选最高已识别等级，不猜未确认数字编码。非原生移动接入不查询。
- 天翼：官方网页只读`/order/queryUserLogo.action`，读取`data.vipInfoList`或顶层`vipInfoList`，等级兼容数字及数字字符串，仅将未过期的`memberLevel:1000/2000`分别显示为黄金/铂金。到期时间兼容日期字符串、秒和毫秒时间戳；未知等级、缺失或无法解析到期时间不显示。
- 夸克：PC只读`https://drive-pc.quark.cn/1/clouddrive/member`，复用同一响应中的容量和`member_type`，不重复查询。对照本地LitePan源码快照`drivers/Quark/profile.go`与`transport.go`：`VIP/SUPER_VIP/Z_VIP/EXP_SVIP/MINI_VIP`分别为VIP/SVIP/SVIP+/88VIP/迷你VIP；未知或非成功响应不显示，不能根据大容量推断88VIP或SVIP。

接口与字段核对自2026年10月28日官方公开网页代码：移动`/w/static/js/app.56b4a805.js`、天翼`https://cloud.dlife.cn/web/main/js/chunk-common.8e0669c6.js`、115`https://115.com/_next/static/chunks/52645-2a86b028e3c4f89c.js`。同时检查OpenList固定提交`6aeaf1dafd66fd1ac2b7ca7104b41a69e0070749`的139/189驱动；没有据此猜测不存在的通用会员接口。

## 缓存与边界

- 四种网盘共用受保护的`GET /api/storages/{id}/membership`，不等待容量查询返回；夸克仍与容量读取共享同一个PC会员缓存。界面先展示最近成功读取的徽章，再在5分钟新鲜期外独立刷新，最多3个会员读取与容量读取并行。页面切换、旧状态快照或容量晚回不清掉较新的徽章。
- 会员与容量内使用的会员查询共享受凭据修订隔离的单飞缓存，会员自身最多12秒，成功等级5分钟、空结果1分钟；不在`/api/state`轮询时额外发云盘请求，也不被容量的最近查询时间阻止重试。独立结果持久到既有Usage运行态，保容量/用户名/容量检查时间；凭据或账号变化、停用及迟到响应均不回填旧徽章。所有云请求仍共用账号API节流。无法查询不等同普通用户，未核实真实账号之前不承诺必定显示。
- 徽章展示可保留最近24小时的明确成功结果，悬浮显示最近读取时间；明确到期立即隐藏，超过24小时也不显示。刷新失败或未知不代表非会员，不抹掉仍在展示期限内的历史结果。没有读到过明确等级时不编造徽章。CAS额度等能力判断仍只信任5分钟内的有效结果，24小时展示缓存绝不授予秒传权限。
- 浏览器缓存仅含规范等级、检查/到期时间，按当前账号及服务端`viewRevision`隔离，停用、移除、退出登录和凭据变更即失效，不写localStorage。服务端查询由应用生命周期下的12秒上下文管理，离开页面不取消其他等待者的同一次查询；凭据修订仍阻止迟到旧结果落盘。容量和会员分别持久，过期展示值不进入`freshMembership`或CAS判定。
- 管理接口只返回规范等级、名称、检查时间及可取得的到期时间，不返回会员接口原始正文、账号凭据或任意上游图标URL。
- 徽章使用本项目Lucide皇冠、盾牌、钻石和徽章线条，分别搭配银、黑金、青、淡紫等小面积底色。参考的本地LitePan会员组件使用文字徽章，没有独立的会员图片资源；本项目独立实现紧凑样式。会员名称、容量与菜单分别占位，长存储名称继续省略。
- 协议模拟和页面截图不等于真实账号会员查询已验收。官方接口、授权设备及网络出口仍可能影响可用性，不绕过会员权益。
