# 夸克文件下载

连接测试只请求目录 API，不代表下载 API 或文件 CDN 一定可用。文件管理的下载、WebDAV 和本地挂载均通过服务器读取夸克文件，不改为浏览器 302。

普通下载请求使用完整的夸克 PC 客户端 User-Agent、Referer 和 Cookie。下载 API 返回新的 `__pus` / `__puus` 时，本次读取使用新 Cookie，并通过现有字段加密机制保存到存储配置；不保存其他响应 Cookie，不把跨源重定向的 Cookie 写回账号，迟到响应不覆盖已修改的配置。

取链接失败会注明“夸克取下载链接失败”，并区分 DNS、超时、TLS 证书或提前断开连接。日志不输出 CK、代理密码或签名 URL。接口业务拒绝单独显示状态与错误码，不自动重试 POST，不绕过 TLS，也不改变代理插件的作用范围。

这些修正已用模拟 API 和文件服务器验证。没有真实账号联调，不能仅凭旧版的“上游连接失败”确认现场网络原因；更新后若仍失败，请提供新的完整错误文字。
