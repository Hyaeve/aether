# 夸克文件下载

连接测试只请求目录 API，不代表下载 API 或文件 CDN 一定可用。文件管理的下载、WebDAV 和本地挂载均通过服务器读取夸克文件，不改为浏览器 302。

辅助工具中的“夸克 STRM 接管”作用于本项目生成的夸克 STRM 播放地址。客户端请求该 STRM 后，服务端在总开关和对应存储绑定有效时按播放策略选取 TV 版地址并返回 302；读取目录、普通下载、WebDAV 和本地挂载不因此改走 TV 版。上游画质、字幕和客户端兼容性仍有限制，未满足接管条件时保留既有下载/中继路径。

清晰度偏好统一为流畅、高清、超清、4K，默认 4K；超清覆盖 1080p 和 2K 候选，与 LitePan 的四档分组一致。后台继续识别上游标清、2K、杜比及其别名，档位缺失或无权限时只从符合策略的可访问候选中回退，不保证原画或 302。杜比视界由独立开关控制，不再作为清晰度选项；开启后可尝试可访问的杜比档位，不可用时按普通偏好选取。旧配置读取及播放时兼容归一：normal/480p 归流畅，2k 归超清，dolby_vision 归 4K 且保持原杜比开关状态；读取不会改写磁盘，保存设置后持久化为四档之一，不清除 TV 绑定。

普通下载请求使用完整的夸克 PC 客户端 User-Agent、Referer 和 Cookie。下载 API 返回新的 `__pus` / `__puus` 时，本次读取使用新 Cookie，并通过现有字段加密机制保存到存储配置；不保存其他响应 Cookie，不把跨源重定向的 Cookie 写回账号，迟到响应不覆盖已修改的配置。

可信的自动 Cookie 续期会同步更新原本有效的 TV 绑定校验值，保留 TV 凭据、接管模式和启停设置，并与 TV 授权、配置修改及凭据续期串行保存。手动更换存储 Cookie、已经失效的绑定或已解除的绑定不会因此自动恢复。若旧版本已经显示“凭据已变更”，需在接管插件中解除该绑定，再使用同一账号重新扫码绑定；不要只切换接管模式。播放时遇到绑定校验不一致会记录脱敏日志并回退代理，不复用旧缓存。

取链接失败会注明“夸克取下载链接失败”，并区分 DNS、超时、TLS 证书或提前断开连接。日志不输出 CK、代理密码或签名 URL。接口业务拒绝单独显示状态与错误码，不自动重试 POST，不绕过 TLS，也不改变代理插件的作用范围。

这些修正已用模拟 API 和文件服务器验证。没有真实账号联调，不能仅凭旧版的“上游连接失败”确认现场网络原因；更新后若仍失败，请提供新的完整错误文字。
