# CAS 导出

文件管理的工具菜单提供“导出CAS”，仅支持本地存储。移动和天翼的目录接口不能提供完整可用的三项特征，因此不显示导出入口。只读计算所选媒体的 SHA256、MD5 和分片 MD5，分片大小按 OpenList 天翼PC规则根据文件大小动态选择（见[CAS规范](cas-pool.md)），不删除、移动或改名源文件，也不执行秒传。

已有文件或文件夹选择时直接进入参数窗口；没有选择时进入可展开、默认全选的范围树，确认范围后再配置媒体扩展名及导出目录。扩展名留空使用项目默认媒体扩展名，仍遵循全局忽略文件扩展名。视频与音频快捷按钮与任务编辑器共用。

单独选择一个符合条件的媒体文件时输出完整媒体名加`.cas`；目录或多文件选择输出ZIP，保留相对当前目录的层级，同层多文件平铺。ZIP条目使用正斜线，并按最终条目路径排序，不依赖存储返回或选择顺序。CAS为JSON，始终包含名称、大小、`sha256`、`md5`、`slice_md5` 和 `slice_size` 字段，缺失值使用空字符串或0占位。不会写入播放链接或账号凭据，可用于现有CAS解析生成及离线导入。

导出目录可以输入或选择容器内已有绝对目录。通过管理员配置`/config/state.json`的`casExportDirectory`记忆上次目录，所有客户端共享；留空交给浏览器下载，实际保存位置和是否询问由浏览器决定，网页不能强制设置本机下载路径。

导出须二次确认，接受后关闭窗口，并以持续消息气泡显示排队及逐文件进度。多个导出按接受顺序串行执行，最多16个待执行任务；成功或失败均写入系统日志。切换页面不取消已接受任务，退出登录只移除当前浏览器的进度展示。队列保存在当前服务进程内，不跨服务重启自动重放；重启后状态查询明确提示任务失效，需要检查日志与导出目录后再决定是否重新提交。

逐项获取全部有效特征后才发布；获取失败不输出不完整包。容器输出以临时文件加无覆盖链接原子发布，已有同名文件不会改写；不允许配置及运行目录、符号链接路径作为输出。扫描最多10000项、深度64，输出包最多64MiB，每项任务限时10min，计算遵循全局预处理并发。服务关闭取消处理中任务并清理暂存，不承诺容器已发布文件回滚。排队期间源存储凭据发生变化会停止任务。

浏览器下载产物暂存于`/data/cache/cas-export-results`，仅认证下载接口可以读取，24h到期后按小时清理；重启后的过期残留也会清理。留空目录的导出完成后触发浏览器下载，实际下载成功与否由浏览器控制。

本地完整特征计算及模拟秒传回归不能替代真实移动、天翼账号的命中验证。
