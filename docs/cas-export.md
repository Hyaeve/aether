# CAS 导出

文件管理的工具菜单提供“导出CAS”，支持本地存储及原生移动、天翼个人云。只读获取或计算所选媒体的特征，不删除、移动或改名源文件，也不执行秒传。

已有文件或文件夹选择时直接进入参数窗口；没有选择时进入可展开、默认全选的范围树，确认范围后再配置媒体扩展名及导出目录。扩展名留空使用项目默认媒体扩展名，仍遵循全局忽略文件扩展名。视频与音频快捷按钮与任务编辑器共用。

单独选择一个符合条件的媒体文件时输出完整媒体名加`.cas`；目录或多文件选择输出ZIP，保留相对当前目录的层级，同层多文件平铺。CAS为JSON，包含名称、大小、SHA256与MD5，云端缺项保留空值；本地媒体还计算切片MD5。不会写入播放链接或账号凭据，可用于现有CAS解析生成及离线导入。

导出目录可以输入或选择容器内已有绝对目录。通过管理员配置`/config/state.json`的`casExportDirectory`记忆上次目录，所有客户端共享；留空交给浏览器下载，实际保存位置和是否询问由浏览器决定，网页不能强制设置本机下载路径。

导出须二次确认，逐项获取全部有效特征后才发布；获取失败不输出不完整包。容器输出以临时文件加无覆盖链接原子发布，已有同名文件不会改写；不允许配置及运行目录、符号链接路径作为输出。扫描最多10000项、深度64，输出包最多64MiB，单次请求10min，计算遵循全局预处理并发；关闭窗口取消请求并清理暂存。设置和存储变化后可重新发起，已有导出不会自动刷新。

移动、天翼是否返回可用哈希依赖上游；本地及模拟回归不能替代真实云盘账号验证。
