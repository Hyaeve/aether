# 阿里云盘秒传

辅助工具 → 我的插件 → **阿里云盘秒传**，位于五个115插件之后。图标使用阿里云盘原图，并在右下角叠加秒传标识。

## 账号配置

第二个栏目支持阿里云盘App扫码登录，或粘贴refresh token后连接。轮换后的refresh token立即加密保存，设备密钥也加密保存并复用；接口不会返回这些凭据。

秒传文件扩展名默认如下，回车或离开输入框自动保存：

```text
mp4;mkv;avi;mov;wmv;flv;webm;m4v;ts;m2ts;mkvb;rm;3gp;iso;ass;srt;ssa;sub
```

## 接收目录与执行

第一个栏目底部添加115接收目录，允许多个存储池、多个目录，同一存储池的同一目录不能重复添加。保存时从115读取真实目录路径。每条目录提供秒传、记录、删除配置三个操作。

秒传窗口接收一条 `alipan.com` 或 `aliyundrive.com` 分享链接，支持提取码及指定分享子目录。读取完整分享树并筛选扩展名后，保留原目录结构生成115文件。已有同名、同大小、同SHA1文件跳过，其他同名冲突停止，不覆盖目标文件。

文件先复制到登录账号资源盘的 `/Aether/rapid-任务ID/` 私有子目录。读取副本的SHA1交给115秒传；仅在115要求片段校验时读取相应字节，最多1MiB，不转普通上传。115返回新文件凭据后，继续读回核对名称、大小、SHA1和父目录，再删除已登记的阿里副本及空的私有目录。共享的 `/Aether`、原分享及既有用户文件均保留。

写入结果未确认、身份变化或115未命中秒传时停止，记录保留具体结果与临时目录位置，不自动重放。服务重启也不会重放在途写入。需要核对的临时副本会保留，避免把未确认的文件当作成功结果清理。

## TG Bot

向已授权TG Bot直接发送阿里分享链接：仅一个接收目录时直接执行；多个接收目录时每页五个，选择后再次确认。网页和TG使用同一执行、清理及目录记录流程，记录标明来源。账号、目录或TG授权变化会使旧交互失效。`/share` 是虚拟链库命令，阿里秒传请直接发送链接。

当前企业微信、QQ和飞书没有同等转存选择交互，本插件未扩展这些通道。

同一时间执行一项阿里秒传，运行中账号和接收配置只读。分享扫描最多20000项、64层；任务总时限2小时，单次API请求30秒。记录按目录展示、每页20条；运行回执独立持久化，不进入配置导出，配置导入保留本机回执和未确认标记。当前最多1000条任务记录、累计20000条文件结果。
