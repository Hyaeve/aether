# Cron 计划下限

所有五字段Cron计划相邻触发至少间隔15分钟，包括普通STRM/CAS/ED2K任务、备份、联动、移动/夸克链库、115签到/回收站/文件夹清理及监控秒传。`*/15 * * * *`可用；`*/14`不可用，`*/16`同样不可用，因为每小时48分到下一小时0分只有12分钟。空的可选Cron仍表示不设计划。

115监控选择重试传输或重试删除时仍要求严格大于120分钟，不被15分钟通用下限放宽。检查使用既有robfig解析器的实际日期和时区，覆盖日内、跨午夜、日期条件及夏令时，结果有界缓存。无可执行日期或无效格式也拒绝。

编辑框稳定输入250ms后只读校验，红色感叹号静止300ms显示原因，控件保持可编辑。保存和配置导入仍由后端再次校验，不能仅绕过前端警告保存不合规计划。旧持久配置可启动载入，但不再执行过短计划；需编辑后保存为合规值，不自动改写用户表达式。

此约束不改变非Cron的缓存监控、文件系统稳定等待、备份自动扫描间隔或手动触发机制。

STRM删除数量超过任务“删除阈值”且源存储健康检查失败后，任务保持删除保护，普通任务等下次Cron先重查健康再执行；生活事件且Cron为空时改为次日同一时分重查，不进入5秒事件轮询。无Cron的普通任务等待手动检查。停用任务不会因到期自动检查或执行，后台存储健康恢复也不会提前清除任务保护。

115普通STRM选择“生活事件”时，Cron留空表示约5秒一轮的事件读取，非空仍至少间隔15分钟；选择“目录树”时Cron必填，同样至少15分钟。手动执行、全量同步与重置不改变已保存表达式。活动链接的非空Cron仍采用更严格的至少12小时，不被通用15分钟下限放宽。
