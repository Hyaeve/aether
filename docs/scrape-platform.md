# 刮削平台

手动识别或重新识别会覆盖用户所选作品已有的 NFO 与海报，范围仍严格限制在点选的文件、目录或链库分享目录；自动任务继续遵循任务写入策略和外改保护。刮削请求与探索推荐共用 TMDB 缓存，连续 7 天无请求的缓存会清理。

“以太工坊”侧栏在虚拟链库之后提供独立的刮削平台，栏目依次为STRM刮削、链库刮削、目录刮削、刮削设置。`/tasks/scrape`重定向到`/scrape/strm`；任务中心不再重复显示该栏目。档案中心位于刮削平台与以太链接之间。

## 刮削设置

`/scrape/settings`是最后一个独立栏目，统一管理三个刮削工作台共用的写入策略、分集NFO与预览图、背景图、演员信息和排除目录。原工作台上的设置按钮及弹窗移除，既有`/strm-scrape/settings`读取与保存接口不变。读取完成前禁用保存，读取失败可重试；保存失败保留当前输入，成功后留在栏目内，重新进入或刷新从已保存配置读取。设置栏目不读取媒体索引或轮询刮削进度，切回对应工作台后沿用原执行流程。

## STRM与链库

STRM刮削只选择现有参与刮削的STRM、CAS或ED2K任务，沿用海报墙、文件夹列表、目录范围、手动匹配队列和已有识别/刮削设置。

链库刮削先选择115、移动、夸克或CAS链库；根视图把每张参与刮削且有生成位置的卡片显示为一个分享目录，点击后进入该分享的海报或文件列表，上方“链库”路径可返回。一个分享按一个作品分组，分享根目录内的剧集文件也不会平铺成多部作品；底层媒体路径和播放授权保持原值。普通分享库只扫描`.share.strm`，CAS链库只扫描`.cas.strm`；不混入普通STRM或旧命名文件。生成、编辑与刮削共用各提供方互斥，执行前和逐文件处理时复核卡片版本。刮削只向本地生成库写入元数据，不改STRM正文、不转存媒体、不替换目录归属。

STRM文件列表的任意层级目录，以及最内层STRM文件，均在悬浮或键盘聚焦时显示重置/识别按钮，触屏直接显示。目录按其子树范围处理，单文件只处理该文件，不扩大到同作品的其他集。重置仅清识别记录，保留磁盘文件；手动识别确认后按原设置刮削，可在已有任务执行时排队。

四类链库设置提供“链库刮削”，默认为不参与。它只作为新卡片的默认值，网页新建与Bot新建都会继承；编辑已有卡片或重发已有分享链接时，保留该卡片自己的选择。各卡片更多选项可独立更改参与状态。设置页的两个配置区使用圆角边框和表面背景，中宽及手机视口纵向排列。

## 目录刮削

`/scrape/directory`接入已启用且健康的存储池，采用STRM刮削的文件夹列表样式、虚拟加载和关键词搜索。移除整行识别/刮削操作栏，数量圆角标记位于右上刷新按钮左侧；上方根目录和各级路径均可点击跳转。目录与媒体文件逐行悬浮/聚焦显示重置、识别，触屏直接显示；浏览与刷新只读内容，用户点击“识别并刮削”才向选定文件或目录内媒体写入NFO、海报及已启用的分集、背景图。重置仅清该范围的识别缓存，保留媒体和已写元数据，不要求TMDB授权。

支持视频和以`.strm`结尾的指针文件。行操作明确传入所选文件/目录ID，后端重新核验选择存在，目录识别需显式group标记；普通单文件请求不能借目录ID扩大范围。既有API空选择仍支持当前目录及子目录。沿用现有TMDB、代理、请求节流及补缺/覆盖设置，最多扫描100000项、128层，单次刮削最多10000个媒体。不会下载或上传完整媒体。

写入前重新核对源存储修订、健康状态、媒体ID/名称/大小/修改时间和任务冲突；目录来自本次实际扫描，不能由任意返回路径创建额外目录。本地写入沿用根目录约束和原子发布。云端元数据经现有暂存额度、上传控制及确认发布流程；结果不明不重放上传。临时NFO和图片完成后释放并清理；原媒体不变。目录任务与其他刮削共用执行互斥及停止入口，运行期间保护相关源目录，取消后释放保护。

目录刮削结果进入刮削档案。该类档案的再次识别从目录刮削列表重新选择文件，不复用仅适用于本地STRM内容指纹的旧档案重试入口。模拟本地/WebDAV验证不代替真实115、移动、夸克、天翼及NAS部署验收。

目录识别缓存按存储及其配置修订隔离，多次选择和切换子目录时合并保留结果；再次读取以ID、原名称、父目录、大小和修改时间匹配，文件变化即不展示旧身份。有效手动TMDB选择在同一文件后续刮削时复用。显式目录识别将指定TMDB应用到本次核验子树中的媒体，其他目录不变；未声明目录范围的单文件匹配仍拒绝目录。缓存有64MiB读入及100000条保留上限，写入按本轮合并一次，不逐文件重写整份缓存。
