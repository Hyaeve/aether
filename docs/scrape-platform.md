# 刮削平台

“以太工坊”侧栏在虚拟链库之后提供独立的刮削平台，栏目依次为STRM刮削、链库刮削、目录刮削。`/tasks/scrape`重定向到`/scrape/strm`；任务中心不再重复显示该栏目。档案中心位于刮削平台与以太链接之间。

## STRM与链库

STRM刮削只选择现有参与刮削的STRM、CAS或ED2K任务，沿用海报墙、文件夹列表、目录范围、手动匹配队列和已有识别/刮削设置。

链库刮削先选择115、移动、夸克或CAS链库，再选择其中启用且参与刮削、有生成位置的卡片。普通分享库只扫描`.share.strm`，CAS链库只扫描`.cas.strm`；不混入普通STRM或旧命名文件。生成、编辑与刮削共用各提供方互斥，执行前和逐文件处理时复核卡片版本。刮削只向本地生成库写入元数据，不改STRM正文、不转存媒体、不替换目录归属。

四类链库设置提供“链库刮削”，默认为不参与。它只作为新卡片的默认值，网页新建与Bot新建都会继承；编辑已有卡片或重发已有分享链接时，保留该卡片自己的选择。各卡片更多选项可独立更改参与状态。设置页的两个配置区使用圆角边框和表面背景，中宽及手机视口纵向排列。

## 目录刮削

`/scrape/directory`接入已启用且健康的存储池，提供目录导航、虚拟文件列表、关键词搜索和多选，仅列表模式。浏览与刷新只读存储内容。识别仅请求TMDB并保存识别结果；用户确认“刮削”或点击“识别并刮削”后，才向媒体所在目录写入NFO、海报及已启用的分集、背景图等文件。

支持视频和以`.strm`结尾的指针文件。未选择条目时处理当前目录及子目录；选择文件/目录时只处理选择范围。沿用现有TMDB、代理、请求节流及补缺/覆盖设置，最多扫描100000项、128层，单次刮削最多10000个媒体。不会下载或上传完整媒体。

写入前重新核对源存储修订、健康状态、媒体ID/名称/大小/修改时间和任务冲突；目录来自本次实际扫描，不能由任意返回路径创建额外目录。本地写入沿用根目录约束和原子发布。云端元数据经现有暂存额度、上传控制及确认发布流程；结果不明不重放上传。临时NFO和图片完成后释放并清理；原媒体不变。目录任务与其他刮削共用执行互斥及停止入口，运行期间保护相关源目录，取消后释放保护。

目录刮削结果进入刮削档案。该类档案的再次识别从目录刮削列表重新选择文件，不复用仅适用于本地STRM内容指纹的旧档案重试入口。模拟本地/WebDAV验证不代替真实115、移动、夸克、天翼及NAS部署验收。

目录识别缓存按存储及其配置修订隔离，多次选择和切换子目录时合并保留结果；再次读取以ID、原名称、父目录、大小和修改时间匹配，文件变化即不展示旧身份。有效手动TMDB选择在同一文件后续刮削时复用。只选择一个目录不能冒充单文件手动匹配。缓存有64MiB读入及100000条保留上限，写入按本轮合并一次，不逐文件重写整份缓存。
