# 重命名工作台历史记录

仅工作台的批量或单项重命名进入历史，文件管理普通重命名不记录。按存储池和操作目录保留最近五个目录，每目录最多20000项；同一文件仅保留最新一次操作，恢复的是该次操作前的名称。

历史数据写入 `/data/runtime/state.json`，不写模块配置，也不随配置备份导出。迁移时应同时保留配置主密钥和数据目录。历史页使用页面虚拟列表，支持右键开始选择、单击、分段 Shift 多选、全选切换、Esc 或外部点击退出。目录选择器优先显示最深目录，选定路径展开，悬浮后收窄。

恢复需要二次确认。当前名称、类型或存储配置变化、已移动/删除、原名称被占用时拒绝操作；不会覆盖同名项目。本地检查卷/文件身份、大小和修改时间。使用稳定文件 ID 的云盘校验目录内 ID；WebDAV/OpenList 文件额外核验内容和元数据。上游没有可核验身份的目录不强行恢复，显示失败原因。校验与上游执行不是跨服务事务，外部同时修改仍需要协调。

结果留在当前历史页面，以绿色或红色描边表示成功或失败；退出后再次进入会移除已处理条目。异常中断可能已改名但未写入最终记录，重新操作会根据实际名称重新核验，不自动覆盖。
