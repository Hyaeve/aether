# 云盘空间显示

存储卡片异步获取已使用和总空间，不阻塞卡片或 `/api/state`。115 使用 115driver 的空间接口，夸克使用会员容量接口，天翼使用个人云容量接口。获取不到有效容量时尝试显示账号昵称或登录名；两者都不可用时保留存储类型，不虚构容量或用户名。

移动原生存储通过个人云容量接口获取空间，需要账号域 ID（Cookie 中的 `ud_id`）。新扫码授权会自动保存接口返回的账号域 ID；已有存储可在编辑窗口补填。只有 Authorization 而没有账号域 ID 时仍显示对应账号，不猜测 ID 或虚构容量。

空间查询与后台健康巡检同轮执行，成功连接后更新容量。最近一次有效结果保存在 `/data/runtime/state.json`，不写入 `/config`；切换页面或重启后直接显示已保存结果，不等待上游。暂时无法获取容量时保留上次成功值，存储配置变更后旧结果失效。

查询仅限登录后的管理接口，响应不包含凭据或凭据指纹。首次没有保存结果时才查询上游，内存合并并发请求，成功缓存五分钟，失败一分钟；巡检主动刷新不受该短缓存限制。单次容量查询最长十二秒，前端最多并行三个请求，退出页面取消请求。具体巡检与退避规则见 [存储健康巡检](storage-health.md)。

受控接口测试已覆盖容量、用户名回退、缓存、凭据变更和取消；真实云盘账号仍需部署验证。
