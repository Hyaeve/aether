# 云盘空间显示

存储卡片异步获取已使用和总空间，不阻塞卡片或 `/api/state`。115 使用 115driver 的空间接口，夸克使用会员容量接口，天翼使用个人云容量接口。获取不到有效容量时尝试显示账号昵称或登录名；两者都不可用时保留存储类型，不虚构容量或用户名。

移动原生存储目前显示 Authorization 对应的账号，没有接入未经确认的容量接口。

查询仅限登录后的管理接口，响应不包含凭据。成功容量在内存缓存五分钟，失败或仅账号信息缓存一分钟；存储配置变更后旧缓存失效。单次查询最长十二秒，前端最多同时查询三个存储池。退出页面取消未完成查询，不把容量写入配置文件。

受控接口测试已覆盖容量、用户名回退、缓存、凭据变更和取消；真实云盘账号仍需部署验证。
