# 文件缩略图缓存

文件管理网格使用浏览器生成的真实图片缩略图或视频帧，最大边长 320 像素；不使用原文件作为长期网格封面。浏览器不支持的格式保留文件图标，不伪造封面。打开预览仍读取原文件。

缩略图经管理员接口校验、重新编码后保存于 `/data/thumbnails`。缓存键包含存储配置版本、文件标识、大小和修改时间，磁盘文件不包含云盘链接或凭据。更换存储配置或文件版本不会复用旧封面。该目录属于可重建缓存，不属于 `/config` 配置信息。

每次读取更新最后使用时间；连续 72 小时没有读取的缓存不再返回，并在启动及每小时清理。总容量最多 256 MiB、最多 10000 张，达到上限时仍可展示本次浏览器生成的封面，不无限写入。服务重启后可继续使用有效缓存。

第一次生成通过受保护的同源媒体接口读取，不受存储浏览器下载的 302 模式和上游 CORS 限制影响，支持 Range；不会长期保存原图或原视频。浏览器仍须支持对应解码器。该功能不绕过云盘权限、网络错误或浏览器格式限制，也不要求容器安装 FFmpeg。
