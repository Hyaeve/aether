# 探索发现与媒体订阅

探索发现已补充[追剧日历与我的媒体](my-media.md)：按订阅读取播出安排，复用以链展示媒体面板、真实排行、Emby缺集核对及媒体库范围配置；资源来源和自动搜索转存仍为后续接入。

侧栏在“以太视界”之后增加“探索发现”，包含资源推荐与媒体订阅。沿用Aether的图标页签、日夜主题和手机抽屉导航。

## 资源推荐

`/discover`默认进入全部，其他栏目为剧集、电影、动漫、榜单，不提供音乐栏目。推荐数据来自以太识律 → 辅助配置中的TMDB；需要配置并启用TMDB，沿用原API地址、语言、凭据、代理与请求间隔。

全部展示流行趋势、正在热映和正在播出；剧集和电影有各自热门、高分或即将上映栏目；动漫限定动画类型；榜单展示TMDB高分电影与剧集。支持媒体搜索、横向浏览、更多分页及正整数页码回正。海报按需加载，媒体详情显示背景、海报、简介、演员和基本资料，可从详情添加订阅。

服务端只访问固定的TMDB接口，不接收任意目标地址；影视结果排除人物。元数据缓存15分钟，最多32份、单份不超过1MiB，按TMDB与代理配置隔离。未配置或请求失败显示可重试的错误状态。侧栏记忆推荐栏目，媒体详情保留直接访问和浏览器前进后退，不作为侧栏恢复的独立页面。

## 媒体订阅

`/subscriptions`默认进入剧集订阅，另有电影订阅、资源来源。订阅卡片使用真实媒体海报和背景，支持搜索、编辑、确认取消；每页20项，只有超过一页才显示翻页和跳转。剧集按作品及季号去重，电影按作品去重；同一TMDB数字在电影和剧集之间相互独立。重复点击详情订阅会打开既有订阅，不再新建同季卡片。

订阅编辑分基础与进阶：

- 基础：搜索关键词、剧集总集数与开始集数、质量、分辨率、特效、订阅站点、搜索周期、转存目录。
- 进阶：包含、排除、剧集季号、媒体分类、自定义识别词；不提供优先规则组、指定剧集组、洗版或IMDb搜索开关。

搜索周期可跟随系统或保存1至8760小时的自定义值。转存目录来自通知服务 → 链接转存中已配置、仍可用的原生移动、夸克或115目录；115可保留离线用途。可先不指定目录，原目录失效后编辑会要求重新选择。该关联为未来资源站点匹配保留目标云盘、分享转存/离线能力信息，未新增PT下载器配置。

创建时由服务端重新获取规范媒体信息，编辑只能更新订阅选项；客户端不能把既有订阅改成另一部作品。配置保存使用现有持久化事务，失败保留编辑内容；订阅随配置备份与恢复，旧配置无订阅时无需迁移。最多保存500项。

## 当前边界

按本次需求，资源来源仅占位，订阅站点选择禁用。当前完成真实TMDB推荐、详情、订阅配置及持久化，不运行资源站点爬取、定时搜索或云盘转存，不伪造完成集数。卡片明确显示“待接入资源来源”；取消订阅只移除订阅配置，不删除已转存文件。以后接入资源来源时，再依据目标云盘匹配分享链接，115目录可按能力接入ED2K或磁力。
