# CAS 特征与存储绑定池

CAS 任务只生成可复用的 `.cas.strm`，不绑定播放账号。内容是指向本项目的签名播放地址，始终包含原始媒体名称、大小、`sha256`、`md5`、`slice_md5` 和 `slice_size` 字段；缺少值使用空字符串或0占位。生成要求是有 SHA256，或同时有 MD5 与分片 MD5；只有单独 MD5、单独分片 MD5或三项都缺失时跳过并记录日志。不会在新链接中写入存储池 ID、账号或凭据。

CAS 任务按编辑窗口“媒体扩展名”输入框筛选，不限定为内置音视频类型；例如填写 `pdf;zip;pkg_7-z` 时，只处理这些自定义扩展名及对应的 CAS 特征文件，仍受排除规则约束。留空时沿用默认音视频扩展名，不表示处理所有文件。输入仍需满足既有扩展名格式校验。导入和播放取链不再额外套用音视频白名单，文件名、大小、哈希、签名与存储兼容校验保持不变；客户端能否打开对应文件另由其格式支持决定。

新生成的通用 CAS STRM 使用 `/cas/签名负载?sign=签名`，负载仅包含 `redirect:true` 和六字段 `cas`，不再写入外层 `s/f/p` 或内层 `provider`。不再接受旧 `/stream/` CAS 地址，导入 `.cas.strm` 也拒绝该旧格式；普通存储和ED2K的 `/stream/` 不变。已有文件不自动重写，建议自行移除旧CAS产物后重新生成，不删除源媒体。独立导出的 `.cas` 使用缩进 JSON，按 `name/size/sha256/md5/slice_md5/slice_size` 顺序一行一字段，不存 provider；文件管理支持只读阅读，仍支持 JSON/Base64 CAS。

天翼 CAS 秒传与 OpenList PC 一样依次执行 `initMultiUpload → checkTransSecond → commitMultiUploadFile`，只传特征，不在未命中时上传媒体。请求保留 PC 客户端参数及签名，并补齐随机查询参数。真实账号命中与 HTTP 601 的现场表现仍需部署验收。

天翼黄金会员新建秒传文件的单文件上限为200 GB（200,000,000,000字节，包含边界），铂金会员不另设会员大小上限。播放和手动离线导入在提交前检查，超过200 GB只接受当前凭据下五分钟内有效、尚未到期的明确铂金权益，必要时只读查询；未知、过期或查询失败不猜测铂金。黄金超限不创建临时目录、不提交秒传；已确认存活副本取链不重新创建文件。200 GB以内沿用上游实际权益及命中判断，不由此推断普通账号额度。通用CAS解析原有最大1 TiB的资源保护仍保留，与铂金会员额度是两个独立边界。

目录CAS任务固定增量生成，不再提供生成方式或全量重置。同一相对位置已有对应完整文件名 `.cas.strm` 时直接跳过，不重新计算、不覆盖，也不会因此删除源媒体；目标是目录或异常节点则报告冲突。系统普通STRM覆盖设置不影响CAS。

STRM、CAS、ED2K和目录缓存任务运行期间，文件管理按实际目录保护，不再因任务类型而锁住整个存储池。保护所选源目录及其内容，也拒绝会影响源目录的上级目录复制、移动、改名或删除；不会因为它们在同一存储池或同一父目录下，就禁止独立兄弟目录的新建、上传、编辑、重命名、复制移动、解压或任务执行。生成任务同时保护实际输出目录，缓存任务只保护源目录。跨池操作同时核对来源和实际写入位置，上传文件夹按完整子路径核对。拒绝操作的消息明确列出运行任务的类型和名称，目录关系无法核实时则说明核验失败，不冒充已确认冲突。运行卡片仍可点击或通过菜单查看配置，主表单和更多选项均只读，不能保存；查看期间任务结束不会自动解锁，关闭后重新编辑即可。

同存储池的独立目录任务可并行，但源目录、实际生成目录及另一任务的来源/输出不能交叉覆盖；共享API间隔采用活动任务中较大的值。跨盘复制、文本发布和解压在操作期间保留仅当前进程有效的目录占用，避免检查后新启动的任一目录任务进入相同范围，不写配置或运行态文件。此规则不改变备份、刮削、夸克链库等各自独立的执行互斥，也不允许运行中修改或删除其存储配置。

本地目录核对实际根路径及符号链接别名；路径型存储按完整路径边界比较。原生云盘的目录ID不能当路径前缀使用，也不信任浏览器面包屑或展示缓存：通过新鲜只读列表核验实际层级，核验最多12秒、10000个目录、100000项及128层。目录变化、重名歧义、查询失败或超过核验范围时明确拒绝本次操作，不猜测为无关目录。外部客户端并发改动与云端写入仍不构成跨服务事务。

目录CAS任务与普通STRM使用相同的输出层级：生成位置下先保留所选源目录的最深目录名，再保留其内部相对结构。例如源目录 `/139/剧集`、生成位置 `/家庭影音`，实际输出为 `/家庭影音/剧集/原文件名.cas.strm`，子目录与元数据也放在这一层级内，不带入上层的 `139`。选择整个存储池根目录时不另加根目录包装。云盘使用选目录时保存的真实名称，不把目录ID当作文件夹名；名称缺失或无效需重新选择源目录。增量跳过和生成后清理均核对这一实际输出位置，异常特征日志仍显示源路径，不重复追加目录名。旧的平铺产物不自动移动、覆盖或删除，也不用于跳过新位置的生成。

“CAS 信息”默认智能计算，另可选择全计算、移动CAS或天翼CAS。智能计算对本地媒体计算SHA256、整文件MD5和分片MD5；原生移动媒体直接复用目录接口返回的有效SHA256，缺失则跳过并记录，不假造特征或偷偷下载补算；其他远程媒体（含天翼、网关）下载暂存后计算全部特征，不以天翼现成的整文件MD5冒充分片MD5。切换源目录不改写明确选择，智能计算则在执行时按实际来源判断。

显式全计算写入三种哈希；移动CAS仅保留SHA256，MD5和分片MD5为空串、分片大小为0；天翼CAS仅保留MD5和分片MD5，SHA256为空串。配置字段为 `task.casInfoMode`，支持 `auto/all/mobile/tianyi`。旧任务未设置时按智能计算执行，已明确保存的其他三种选择保留，不批量重写旧配置。

本地媒体按所选模式计算；原生移动的智能计算或移动CAS直接复用上游有效SHA256，手动选择全计算或天翼CAS则读取媒体计算所需特征。原生天翼与其他远程来源按所选模式下载暂存后计算。分片MD5同样需要覆盖整个文件：逐片计算MD5再按规则汇总，生成所需的三种特征可在同一遍顺序读取中计算；暂存完整性和删除前复核可能另有读取，不能据此承诺全流程只读一遍。

任何存储的源目录已有 JSON/Base64 `.cas` 或新格式 `.cas.strm` 时，强制以文件内容为准，保留其中真实有效的特征，不受智能计算、全计算、移动CAS或天翼CAS选择裁剪。例如移动盘上的CAS同时包含三种哈希时三种全部保留，只有MD5及分片MD5的有效CAS也可生成。不会下载对应原媒体补算缺失字段，只有单独MD5等不完整结果仍跳过。兼容 `sliceMd5/sliceSize` 与 `slice_md5/slice_size` 字段；有分片MD5但省略或使用0分片大小时，按下述规则补齐，显式正数大小始终保留，不改写已有哈希，保留原文件基名与相对目录结构。特征文件上限 1 MiB，仍须满足名称、大小、特征格式、媒体扩展名及排除规则。没有有效哈希或特征损坏的文件跳过并批量记入日志，不中止后续文件；生成计数和异常计数属于运行数据。文件管理的独立CAS导出仍保持其原有来源范围，不等同目录任务新增计算选项。

新计算的分片大小和缺少分片大小的导入遵循 [OpenList 天翼PC partSize](https://github.com/OpenListTeam/OpenList/blob/482464c2affc5eeba5d4a25bb272aeb352ec5918/drivers/189pc/help.go#L217)：文件大小不超过9990 MiB使用10 MiB，超过9990 MiB且不超过19980 MiB使用20 MiB，更大文件使用 `max(5, ceil(文件字节数 / (1999 * 10 MiB))) * 10 MiB`。这是MiB（1024进制）而非十进制MB；有明确分片大小的旧CAS/STRM不重算，已生成文件不自动迁移。缺省补齐是OpenList兼容规则，不证明任意外部工具的分片方式相同；非此规则的来源应保留其实际分片大小。

CAS 与 ED2K 任务统一保留完整文件名，再追加 `.cas.strm` 或 `.ed2k.strm`，例如 `film.mkv.cas.strm`、`song.flac.ed2k.strm`；不再提供“保留扩展名”选项，旧配置中的该项也不影响生成。CAS 特征文件先去掉 `.cas` / `.cas.strm` 包装后缀，保留基名已有的扩展名（包括自定义后缀），仅基名没有扩展名时从特征中的文件名称补齐，例如 `film.cas` 内记录 `film.mkv` 时生成 `film.mkv.cas.strm`；`report.pdf.cas` 不重复追加 `.pdf`。普通 STRM 任务保持原有扩展名选项。已有旧名称的生成文件不会自动改名或删除。

更多选项首项“完成动作”默认保留源文件。选择删除后，只在本轮成功生成和校验产物后清理媒体，元数据按相对结构复制且校验后清理；本轮扫描到的其他非媒体、非元数据文件也会清理。排除规则、失败/损坏特征、增量模式仅跳过的已有产物、新出现文件均保留，源或生成文件发生变化、取消、配置变化时停止后续清理。不支持存储池根目录清理，也不允许本地生成目录与源目录重叠；按存储池已有删除策略进入回收站或永久删除。

本地子目录仅用非递归删除清理已空目录，保留所选源目录及仍有文件的目录结构。云盘、OpenList、WebDAV缺少原子的“仅在仍为空时删除”能力，远程空目录保留，避免晚到文件被目录级删除。外部客户端并发改写与云端删除仍不是跨服务事务，不能保证检查与请求之间完全原子。

需要读取远程媒体时，下载到传输设置指定的临时位置后计算所选特征，每次最多两个文件，服务内跨任务共享硬上限2，不受预处理并发调大影响；成功、失败和取消后清理本次暂存。暂存SHA256完整性验证不因输出只选天翼CAS而关闭，内部校验值不会写入该模式的SHA256占位。ED2K的115远程读取计算也共享此上限。本地计算不受远程槽限制。云端读取或磁盘暂存失败不产生可供清理的成功记录。

在 CAS 任务页点击左向箭头进入独立的“存储绑定池”页面（`/tasks/cas/pool`），分别选择 SHA256 对应的原生移动云盘、MD5 对应的原生天翼云盘，可多选。两组按存储管理顺序显示三行固定列表，超过三个使用两列，超过六个滚动；点击存储图标切换绑定，名称下显示账号。高级设置直接显示，默认优先移动、12 h 轮换、每组保留 12 h；轮换在接口中仍以 `rotationMinutes` 保存，兼容旧的分钟设置。

CAS 播放新建秒传文件统一保存在对应移动/天翼个人云根目录的 `/Aether/CAS`：逐级复用或创建 `Aether`、`CAS` 文件夹，不因存储配置中的浏览根目录而改成其他位置。同名普通文件会阻止目录准备，不覆盖或删除；创建结果不明时不自动重放。已有 `/Aether` 下的追踪临时文件仍按原 ID 复用和到期处理，不自动搬迁或清空。手动 CAS 离线导入仍写入用户明确选择的目录；移动分享生成 STRM 使用的独立 `/Aether/cas-import-…` 回执路径不随播放目录调整。

每组第一个已启用的原生账号必须参与绑定，不可关闭；GET、保存和播放选择均补齐该成员，其他账号保留显式选择。仍需点击“保存设置”完成首次配置。只有匹配哈希、已启用且未处于认证冷却的池成员参与秒传，不自动把所有账号加入绑定池；只有一个成员时一直由该成员处理。

请求播放时，优先复用池内同一特征尚未到期的秒传文件，否则从时间窗口轮换选定的账号开始。移动账号秒传或取链失败后，按池顺序尝试其余可用移动账号，取得直链即停止；同一实际移动账号的多个存储配置只尝试一次。仅显式绑定的健康成员参与，不自动加入未绑定账号。不会上传媒体内容；所有兼容账号都失败才返回失败。保留期按最近使用时间计算，播放中的代理响应通过租约保护，过期清理只删除项目追踪的临时文件，不扫描删除整个网盘目录。

新建移动 CAS 播放文件前，按 CAS 内的真实字节大小预检会员额度，单位为十进制 GB：

| 移动账号 | 单文件秒传上限 |
| --- | --- |
| 普通用户 | 5 GB |
| 白银会员 | 8 GB |
| 黄金会员 | 20 GB |
| 钻石会员，PC 类型 | 500 GB |
| 钻石会员，Web 类型 | 50 GB |

缺失客户端类型按现有 PC 默认值处理。超过该账号额度直接跳过，不准备目录、不提交秒传；没有合格账号则直接失败。5 GB 以内不为预检额外查询会员；更大的文件仅采用当前凭据下五分钟内有效的明确会员等级，必要时只读查询。上游会员列表缺失、格式异常或查询失败时不猜测高等级权益；有效空列表按普通用户处理。已确认存活副本的取链不新增秒传，故不重复套用新建文件额度。预检合格不等于一定命中，仍以实际秒传和取链结果为准；手动 CAS 离线导入的独立流程不因此改变。

通用 `.cas.strm` 同时包含 SHA256、MD5 和分片 MD5 时，默认优先移动；移动候选均未取得直链后，仍可转交天翼绑定池中的一个可用账号。设置为优先天翼时，天翼失败后转交移动候选。已有存活临时文件仍优先复用以减少起播时间；失败转交后再播放可复用成功文件。上游准备请求共享90 s期限，多候选按剩余时间分配单次预算、每次最多45 s，为后续账号留出时间；超出总期限或用户取消不再尝试后续候选。失败后的补偿清理另有独立限时。只有单类特征时仅尝试兼容类型；旧账号绑定链接不静默切换账号或网盘。

移动播放秒传写前持久记录账号与特征的提交意图。失败但返回了文件 ID 的临时项仍保留追踪记录用于清理，记录成功后解除该次意图；没有取得明确文件 ID、网络中断或结果不明时保留意图，后续播放及重启不重提同账号同特征，但可尝试其他绑定账号。未确认项需要核对云端临时目录，不通过反复播放盲目重放写请求。

绑定池设置保存在 `/config/task/cas-pool.json`，配置标记随文件持久化，计数、临时文件及 `casPlaybackAttempts` 未确认提交意图保存在 `/data/runtime/state.json`。配置导出不携带这些意图，导入保留现有意图。统计条展示秒传尝试的成功率、成功/失败及移动/天翼尝试次数；会员预检跳过、已阻止的未知提交及复用存活文件不重复计数。临时文件弹窗展示名称、大小、存储和到期时间，支持单击、Shift、全选和二次确认清理所选项目；播放中项目跳过，未知或重复选择拒绝。无选择正文的旧清理 API 仍仅清理过期项。显式绑定负载仍按原固定账号核验，但CAS播放地址统一只接受 `/cas/`；新的通用链接需先保存绑定池才能播放。链接仍依赖本项目签名密钥，迁移服务需保留密钥并调整服务地址，不是任意服务器可直接播放的公共链接。

模拟接口和本地测试不代表真实移动、天翼账号的秒传权益、数据可用性或 CDN 已通过联调。

CAS 播放和离线导入逐项记录系统日志，包含原始文件名、目标存储类型、存储池名称及 ID。秒传成功、未命中或提交失败、直链获取成功或失败、存活文件复用、跨网盘转交分别记录；复用不作为新的秒传成功，也不增加秒传统计。取消为警告，超时和失败为错误，成功为信息。失败日志只记录发生阶段，不写入上游错误正文、账号凭据、哈希或完整直链；日志遵循系统保留设置，持久化在 `/data/log/system.json`。
