# CAS 特征与存储绑定池

CAS 任务只生成可复用的 `.cas.strm`，不绑定播放账号。内容是指向本项目的签名播放地址，包含原始媒体名称、大小和 `sha256`、`md5` 两个字段；缺少的哈希保留空字符串，不影响另一项。不会在新链接中写入存储池 ID、账号或凭据。

本地媒体计算 SHA256 和 MD5；移动与天翼媒体使用上游提供的有效哈希，其他远程来源下载暂存后计算。源目录已有 JSON/Base64 `.cas` 或本项目 `.cas.strm` 时，提取其中的特征重新生成，保留原文件基名与相对目录结构。特征文件上限 1 MiB。没有有效哈希或特征损坏的文件跳过并批量记入日志，不中止后续文件；生成计数和异常计数属于运行数据。

CAS 与 ED2K 任务统一保留完整媒体文件名，再追加 `.cas.strm` 或 `.ed2k.strm`，例如 `film.mkv.cas.strm`、`song.flac.ed2k.strm`；不再提供“保留扩展名”选项，旧配置中的该项也不影响生成。CAS 特征文件先去掉 `.cas` / `.cas.strm` 包装后缀，若基名缺少媒体扩展名，则从特征中的媒体名称补齐，例如 `film.cas` 内记录 `film.mkv` 时生成 `film.mkv.cas.strm`。普通 STRM 任务保持原有扩展名选项。已有旧名称的生成文件不会自动改名或删除。

更多选项首项“完成动作”默认保留源文件。选择删除后，只在本轮成功生成和校验产物后清理媒体，元数据按相对结构复制且校验后清理；本轮扫描到的其他非媒体、非元数据文件也会清理。排除规则、失败/损坏特征、增量模式仅跳过的已有产物、新出现文件均保留，源或生成文件发生变化、取消、配置变化时停止后续清理。不支持存储池根目录清理，也不允许本地生成目录与源目录重叠；按存储池已有删除策略进入回收站或永久删除。

本地子目录仅用非递归删除清理已空目录，保留所选源目录及仍有文件的目录结构。云盘、OpenList、WebDAV缺少原子的“仅在仍为空时删除”能力，远程空目录保留，避免晚到文件被目录级删除。外部客户端并发改写与云端删除仍不是跨服务事务，不能保证检查与请求之间完全原子。

移动与天翼仍使用上游有效哈希；其他远程来源下载到传输设置指定的临时位置后计算SHA256、MD5及切片特征，每次最多两个文件，服务内跨任务共享硬上限2，不受预处理并发调大影响；成功、失败和取消后清理本次暂存。ED2K的115远程读取计算也共享此上限。本地计算不受远程槽限制。云端读取或磁盘暂存失败不产生可供清理的成功记录。

在 CAS 任务页点击左向箭头进入独立的“存储绑定池”页面（`/tasks/cas/pool`），分别选择 SHA256 对应的原生移动云盘、MD5 对应的原生天翼云盘，可多选。两组按存储管理顺序显示三行固定列表，超过三个使用两列，超过六个滚动；点击存储图标切换绑定，名称下显示账号。高级设置直接显示，默认优先移动、12 h 轮换、每组保留 12 h；轮换在接口中仍以 `rotationMinutes` 保存，兼容旧的分钟设置。

每组第一个已启用的原生账号必须参与绑定，不可关闭；GET、保存和播放选择均补齐该成员，其他账号保留显式选择。仍需点击“保存设置”完成首次配置。只有匹配哈希、已启用且未处于认证冷却的池成员参与秒传，不自动把所有账号加入绑定池；只有一个成员时一直由该成员处理。

请求播放时，优先复用池内同一特征尚未到期的秒传文件，否则按时间窗口轮换选定账号并秒传，再获取直链。不会上传媒体内容；上游不支持秒传时明确失败。保留期按最近使用时间计算，播放中的代理响应通过租约保护，过期清理只删除项目追踪的临时文件，不扫描删除整个网盘目录。

绑定池设置保存在 `/config/task/cas-pool.json`，配置标记随文件持久化，计数与临时文件记录保存在 `/data/runtime/state.json`。统计条展示实际秒传尝试的成功率、成功/失败及移动/天翼尝试次数；复用存活文件不重复计数。临时文件弹窗展示名称、大小、存储和到期时间，支持单击、Shift、全选和二次确认清理所选项目；播放中项目跳过，未知或重复选择拒绝。无选择正文的旧清理 API 仍仅清理过期项。旧已绑定的签名链接继续兼容；新的通用链接需先保存绑定池才能播放。链接仍依赖本项目签名密钥，迁移服务需保留密钥并调整服务地址，不是任意服务器可直接播放的公共链接。

模拟接口和本地测试不代表真实移动、天翼账号的秒传权益、数据可用性或 CDN 已通过联调。
