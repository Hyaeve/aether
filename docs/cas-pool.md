# CAS 特征与存储绑定池

CAS 任务只生成可复用的 `.cas.strm`，不绑定播放账号。内容是指向本项目的签名播放地址，包含原始媒体名称、大小和 `sha256`、`md5` 两个字段；缺少的哈希保留空字符串，不影响另一项。不会在新链接中写入存储池 ID、账号或凭据。

本地媒体计算 SHA256 和 MD5；云盘媒体使用上游提供的哈希。源目录已有 JSON/Base64 `.cas` 或本项目 `.cas.strm` 时，提取其中的特征重新生成，保留原文件基名与相对目录结构。特征文件上限 1 MiB。没有有效哈希或特征损坏的文件跳过并批量记入日志，不中止后续文件；生成计数和异常计数属于运行数据。

在 CAS 任务页点击左向箭头进入独立的“存储绑定池”页面（`/tasks/cas/pool`），分别选择 SHA256 对应的原生移动云盘、MD5 对应的原生天翼云盘，可多选。两组按存储管理顺序显示五行固定列表，超过五个滚动；点击存储图标切换绑定。高级设置直接显示，默认优先移动、12 h 轮换、每组保留 12 h；轮换在接口中仍以 `rotationMinutes` 保存，兼容旧的分钟设置。

尚未配置的池由 `configured:false` 标记，页面草稿只选每组第一个已启用原生账号，必须点击“保存绑定池”后才能用于播放秒传。保存后标记为 `true`，特意停用所有绑定后不会自动重选；没有标记但已有字段的旧配置也视为已配置并保留原选择。只有匹配哈希、已启用且未处于认证冷却的池成员参与秒传，不自动把所有账号加入绑定池。

请求播放时，优先复用池内同一特征尚未到期的秒传文件，否则按时间窗口轮换选定账号并秒传，再获取直链。不会上传媒体内容；上游不支持秒传时明确失败。保留期按最近使用时间计算，播放中的代理响应通过租约保护，过期清理只删除项目追踪的临时文件，不扫描删除整个网盘目录。

绑定池设置保存在 `/config/task/cas-pool.json`，配置标记随文件持久化，计数与临时文件记录保存在 `/data/runtime/state.json`。页面顶栏下方显示临时文件、播放中与过期数量，支持刷新及通过原清理 API 删除过期项。旧配置自动补建空池，旧已绑定的签名链接继续兼容；新的通用链接需先保存绑定池才能播放。链接仍依赖本项目签名密钥，迁移服务需保留密钥并调整服务地址，不是任意服务器可直接播放的公共链接。

模拟接口和本地测试不代表真实移动、天翼账号的秒传权益、数据可用性或 CDN 已通过联调。
