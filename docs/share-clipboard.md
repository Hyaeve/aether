# 分享链接与剪贴板识别

支持 115、移动云盘、夸克官方 HTTPS 分享链接。可以直接复制网盘给出的分享文本：

```text
链接: https://yun.139.com/shareweb/#/w/i/2ygb7gk5b1gfy
提取码: x2ol
```

同行、下一行的“提取码”“访问码”“密码”均归属于其前面的链接，遇到下一条 URL 时结束归属。URL 查询参数中的 password、pwd、passwd、passcode、receive_code 也会保留，密码不改变大小写。输入框内以蓝紫色标识提取码，仍可编辑；同一链接存在不同提取码时须先修正冲突。

混合复制内容按 **115 → 移动 → 夸克** 分组，每批最多 50 条，超过时继续同网盘的下一批。每次确认开始转存、取消、关闭或 Esc 后打开下一批；不会自动提交。未配置对应存储时可关闭该批继续。批次队列仅保存在当前登录会话内存中，退出登录清空，不存储剪贴板内容。

转存目标按云盘类型记住最近选择的存储池，并按存储池分别记住目录和路径层级。配置保存于服务端 `/config/state.json` 的 `shareTransferPreferences`，管理员更换浏览器或重启容器后仍可恢复；不保存分享链接或提取码。目录选择窗口可切换与分享链接同类型的所有已启用、支持分享转存的存储池，不支持跨网盘转存。记住的池已停用、移除或不再支持时回退到当前可用池；打开弹窗本身不会执行转存。既有浏览器目录记忆仅作为尚无服务端目录记录时的兼容来源。

### 保存目录

转存目录同行右侧为“保存目录”。仅单条分享可编辑：单个文件夹分享自动使用该文件夹名，文件分享或多根项目分享默认留空。修改文件夹名只替换原最外层目录，不重复包裹原文件夹；例如 `原目录/子目录/影片.mkv` 改为“新目录”后保存为 `转存目录/新目录/子目录/影片.mkv`。文件分享填写名称后保存为 `转存目录/自定义目录/文件名`，留空则直接保存文件；文件夹分享清空后，其内容直接放进转存目录。多条链接时该字段清空且禁用，各分享保留原目录结构，不支持批量统一自定义名称。

保存目录只接受单个合法名称，最多255个字符，不接受路径、`.`/`..`、控制字符及斜杠等特殊字符。名称只属于当前分享草稿，不持久记忆为下一条分享的默认名。单链接稳定输入350ms后调用受认证保护的 `/api/files/share/info`，仅读取根目录以补齐默认名称，不创建转存预览、不递归、不创建云盘目录或提交转存；已输入的自定义值不会被迟到响应覆盖，修改链接、多链接及关闭窗口会隔离旧响应。读取或校验失败使用消息气泡，默认名未能确认时不会悄悄按空目录提交。

真正点击转存后，`/api/files/share/preview` 使用可选的 `saveDirectory` 固定目录映射；未提供此字段的旧客户端保留旧行为。先在原分享路径上应用勾选范围，再调整目标最外层，来源ID、令牌和子目录结构不变；每批上限仍为499项。目标同名目录可复用，同名文件冲突则停止，不覆盖；创建或转存结果不明时不重放已消费批次。返回的目标目录ID用于成功气泡与页面跳转，直达自定义后的保存目录。未进行真实云盘写入联调时，模拟回归不代表部署验收。

系统设置的“账号与安全”页面提供“剪贴板监听”开关，与会话有效期同一窗口。默认关闭，开启时须阅读隐私说明并点击“我已阅读并同意”，然后请求浏览器权限。说明窗口采用标准 640px 宽度，无滑动条；打开满 10 秒且正文已全部显示或滚到底后才允许同意，取消后重新打开会重新计时。此前没有同意记录的旧开关不会自动开启；每次从关闭改为开启都需确认。开关和同意记录按浏览器和账号记忆，关闭立即停止监听并清除未处理批次。开启后可用的钥匙按钮用于重新申请授权；关闭或环境不支持时只是无交互标识。授权本身由浏览器管理，不是服务端配置。

剪贴板识别发生在当前浏览器内，不向开发者、广告或统计服务上传原始剪贴板内容，也不将原始内容持久化。分享窗口中的单条链接会在稳定输入后发送必要的链接和提取码到自行部署的 Aether 与对应网盘，只读获取默认保存目录；点击解析会继续读取分享树，点击转存才创建目标目录和提交写操作。执行结果可能出现在本项目的日志和通知中，但不记录提取码和凭据。不会自动提交转存，也不会绕过浏览器权限。

授权后，前台页面定期读取剪贴板；从其他应用或标签页返回时立即补读，在后台复制后不必再次复制。后台页面不会直接读取或抢占焦点。浏览器要求 HTTPS 或 localhost 及剪贴板读取权限，拒绝授权、非安全上下文或浏览器必须有用户手势时无法绕过。普通编辑和其他弹窗不会被轮询打断。

普通局域网 IP 的 HTTP 页面仍支持用户主动 Ctrl+V 粘贴识别，不支持标准自动读取授权，因为浏览器不会向非安全上下文暴露该接口。建议通过受信任证书的 HTTPS 反向代理访问，不需要浏览器插件。受控测试环境也可在 Chrome/Edge 的 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 或 `edge://flags/#unsafely-treat-insecure-origin-as-secure` 中仅添加自己的完整来源（例如 `http://192.168.1.10:15151`），启用后重启浏览器；这是浏览器端临时例外，不加密 HTTP 流量，不建议公网或生产使用，项目不会自动更改浏览器安全配置。

相同整批内容处理完后不会重复弹窗；任一网盘批次的链接或提取码变化后会重新识别。手动在分享输入框中粘贴多行“链接＋提取码”，提交时也会合并为每条分享一项。
