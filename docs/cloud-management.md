# 云盘管理

存储管理提供存储池、分享栏、云下载与回收站栏目。列表仅选择已接入对应能力的启用云盘；分页虚拟列表随页面滚动，数量只计已加载条目，支持右键进入选择、Shift范围选择、Esc或点击窗口外退出。全选是持续状态，新加载条目自动选中，手动修改单项后解除全选。批量操作逐项核对最新列表标识，超过499项时按原顺序分批，每次提交最多499项；失败后停止后续批次，提示已确认数量并要求刷新核对，不允许从旧确认窗口直接重放。写请求不自动重试，结果不明确时先核对官方客户端。

## 已实现能力

- 115：从文件管理创建分享，设置有效期、随机或固定4位访问码、接收次数及自动填充访问码；分享列表修改与撤回；离线任务查询、重新提交非成功任务、删除记录但不删除已下载文件；回收站还原、彻底删除与清空。
- 夸克：创建公开或加密分享，有效期长期、1天、7天或30天，查询分享列表与撤回。访问次数限制及修改现有分享没有已验证协议，未开放。
- 移动、天翼：云下载栏目展示本项目提交的持久CAS离线秒传记录，支持失败重试及删除终态记录。不是官方客户端完整离线历史，也不包含播放绑定池的临时秒传；播放秒传仍使用绑定池临时记录及系统日志。分享创建、分享管理及回收站暂不支持。

115离线及回收站按目录 ID 读取真实祖先路径，同页目录去重；上游无法确认完整路径时明确标注不可用，不补造已删除目录的路径。分享状态从明确的到期时间、自动续期、受限等字段显示，未知状态不误判为有效。回收站当前仅开放115；云下载选择器提供115及统一的CAS秒传，CAS目标显示真实云盘类型和存储池名称。

云下载“清理”先只读查询成功、失败或中断记录，二次确认实际候选数量，再按明确 ID 清理。提交时再次验证状态，执行中和排队记录拒绝清理；云端文件始终保留。分享撤回及回收站破坏性操作也需二次确认。

分享选项按云盘类型保存在`/config/state.json`的`cloudShareOptions`，管理员跨客户端共享。自己在当前浏览器创建或复制的分享会登记到该管理员的浏览器记录，从剪贴板监听中排除；换浏览器后先从分享列表复制一次可登记，不代表自动识别账号全部历史分享。CAS离线记录保存在`/data/runtime/state.json`的`cloudCASRecords`，不随配置备份导出；服务重启将执行中记录标为中断，绝不自动重放。

## 115回收站计划清理

辅助工具名称为“115回收站清理”，位于115同播复制后，图标控制总启停；同播复制图标也提供总控开关。每个115存储池最多一条规则，使用五字段Cron及6位数字回收站密码，保留天数默认10、支持1至3650天，10不是上限。任务可经二次确认立即执行一次，结果气泡显示存储池和清理数量。

计划只清理删除时间明确且超过保留期的项目，未知时间项目保留。先完整读取最多10000项，再按499项批次提交明确ID，绝不使用空ID调用全量删除。列表缺失、重复标识、读取不完整、存储停用或认证异常、配置变化时停止；成功和失败均记录系统日志。Cron按服务所在时区执行，当前进程同一分钟不重复调度，重启不会补跑错过的周期。

规则保存在`/config/state.json`的`recycleCleanup`，密码按现有配置密钥加密，读取编辑窗口不返回旧密码；编辑时留空保留已有密码。删除存储同步移除对应规则。手动回收站删除与清空每次都要求重新输入密码，不复用计划密码。

旧版本保存的4位密码可在启动时载入，但会标记需要重新填写，不能执行清理；不会自动补零或猜测密码，也不会因此让容器启动失败。新填写或更改的密码严格校验6位数字。确认窗口使用六格明文输入，每次打开重新输入，前导0保留。

以上协议有模拟回归验证，没有真实云盘账号联调；移动、天翼及夸克未验证功能不会通过猜测接口执行写操作。
