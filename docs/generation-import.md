# CAS、ED2K 解析与 STRM 配置

任务页的虚线卡片创建目录扫描任务；CAS 与 ED2K 页右上角“添加任务”打开文本/文件解析向导。一行一个 JSON/Base64 CAS 或 ED2K 链接，先预览，再选择加入生成队列。返回上一步会保留文本、目录和未过期的解析结果，修改内容后重新解析。无效条目或重复生成路径会阻止提交。

文件解析支持批量 TXT、CAS（CAS 页）、ED2K（ED2K 页）及 ZIP、RAR、7z 压缩包。独立文件平铺到生成目录，压缩包保留相对目录；只合并连续相同的顶层目录，例如 `A/A/Season 1` 转为 `A/Season 1`，不删除不同名称的目录。生成名称取自原信息的文件名，使用 `.cas.strm` 或 `.ed2k.strm` 后缀。现有输出不会被覆盖；遇到冲突或写入错误停止该批，已完成输出保留，进度按实际处理数显示。

单次上传合计最多 32 MiB、100 个文件、10000 个解析条目；压缩包成员最多 1 MiB、单包展开最多 64 MiB，不接受越界路径或符号链接。文本请求最多 1 MiB。有效预览以认证加密格式暂存于 `/data/generation-preview`，30 分钟后不可提交，新解析时清理过期文件；最多 64 份、合计 256 MiB。最多 8 个活动生成批次按入队顺序执行，保留最近 100 个结果。服务重启后未结束批次标记为中断，不自动重放。

新生成的 CAS/ED2K STRM 是签名播放地址，不携带账号凭据或单个绑定账号。CAS 始终保留 SHA256 与 MD5 字段，缺少的一种留空。播放时由各自绑定池选择当前有效账号，优先复用保活文件，否则按时间窗口轮换。ED2K 默认 24 h 轮换、24 h 保活，首个启用的 115 账号始终参与，额外账号可选择。默认保存目录 `/最近接收/Aether`，自定义绝对路径在保存时补齐 `/Aether`。文件位于独立特征子目录，清理前校验账号配置、文件 ID、名称与大小，不删除其他文件。

115 ED2K 接收依赖其离线任务接口，资源是否立即完成取决于网盘；只有确认完成且校验文件身份后返回真实直链。提交结果不明时保留写前记录，后续仅查询，不自动重复提交。界面和模拟测试通过不代表真实账号所有资源都能立即秒传。

绑定池配置位于 `/config/task/ed2k-pool.json`，统计、临时文件和生成队列结果存放 `/data`，配置备份不包含这些执行结果。

系统设置新增 STRM 配置，地址默认沿用主机服务地址，可填写完整 `http://主机:端口` 或 HTTPS 来源，Enter/失焦保存；115 可选 `pickcode_name`（默认）或 `pickcode`。只影响后续生成的云盘 STRM 及便携 CAS/ED2K 播放地址，不重写旧文件、不改变普通下载地址。本机来源生成物理路径，OpenList 保留其规则，WebDAV 使用该存储配置的服务地址；需要凭据的 WebDAV 由播放客户端自行认证，不将账号密码写进 STRM。
