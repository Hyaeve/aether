# 移动云盘读取

原生移动云盘的WebDAV、本地挂载及需要服务器读取正文的任务，共用已接入的下载地址解析。`getDownloadUrl`返回`url`、`cdnUrl`和`cdnSwitch`时，仅在`cdnSwitch=true`且有CDN地址时使用`cdnUrl`，其余使用`url`；没有可用地址时明确报错，不擅自启用上游未开放的CDN。

此规则对照OpenList提交`331f575`（PR2379，2026-09-13）的原始实现核验。此前始终优先`cdnUrl`可能选错通道，本次只修正地址选择，不新增猜测接口、请求头或并发下载。

本地回归覆盖开关启停、缺少CDN地址和缺少源地址，既有CAS播放模拟保持。未实际测试用户NAS、移动账号、运营商出口、WebDAV客户端或FUSE/NFS性能，不能据模拟测试承诺下载速率。实际仍慢时应分别测服务器直读和局域网共享，结合脱敏传输日志区分上游通道、服务器缓存和共享协议瓶颈。
