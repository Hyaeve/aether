# 虚拟链库与分享解析

## 115 链库

侧栏“虚拟链库”依次为“115链库”“移动链库”“夸克链库”“CAS链库”，开放 115 与夸克。天翼链库栏目已移除，旧地址 `/virtual/tianyi` 返回 `/virtual/115`；移动、CAS栏目暂未开放。选择已启用的 115 存储，输入官方分享链接及访问码，解析后选择容器内已有目录生成。音视频文件保留分享目录结构，名称为原文件名加 `.strm`，已有用户文件不覆盖。

内容格式：`http://主机:端口/115-share/分享码-提取码/原文件名称.mkv`，无提取码时省略连字符和提取码，即 `/115-share/分享码/原文件名称.mkv`。主机地址使用系统 STRM 配置；分享标识和文件名分别进行 URL 转义，不附加相对目录、文件 ID 或查询参数。目录层级只体现在本地生成文件夹结构中。相同分享的不同目录存在完全同名文件时，HTTP 请求无法携带本地 STRM 所在目录，这种短地址不能唯一定位，返回 HTTP 409，不随机选择或转存，也不擅自加目录或参数。

本机生成过的资源在 `/data/virtual-library` 保存加密的最小资源授权，在 `/data/virtual-library-names` 保存每份分享完整生成后的加密文件名索引。文件 ID、真实父目录、名称、大小及 SHA1 保留在服务端；播放按唯一登记名称定位并重新核对源文件，只读取该父目录，避免递归整个分享。源资源变化、未登记、缺少授权或包含子目录的请求不可播放，索引认证失败不回退。重新生成成功后替换该分享的完整名称快照，失败不发布部分索引；旧名不永久累积。索引不是模块配置，须与配置主密钥共同备份恢复。

重跑时，已存在资源授权且正文仍完整匹配本项目旧 `/s/分享码_访问码_文件ID.扩展名?/原名称` 格式的 STRM 会安全更新为新格式，并计入生成数量；其他已有内容保持不变。旧 `/s/` 播放入口保留，未登记旧便携 URL 仍仅可尝试受限只读分享直链；新的 `/115-share/` 必须在本部署完成登记，不会因知道分享码就授权转存任意文件。不要公开包含提取码的 STRM 或服务地址。

临时接收共用 ED2K 的 115 存储绑定池、轮换时间、保活和“临时目录”。每个资源使用独立子目录，验证名称、大小、SHA1 和云端文件 ID 后才返回下载票据，UA 使用播放器请求值；存活临时文件优先复用。HEAD 不创建文件。写请求先记提交意图，响应不明确时只查询，不自动再次接收。清理共用临时文件列表，仅删除身份及 SHA1 仍匹配的文件，不删除整个目录。有效分享、账号权限和网盘可用容量仍是播放前提。

单次最多扫描 5000 项、32 层；预览 10 分钟有效，本机资源授权和临时提交记录各最多 10000 项，文件名索引最多 10000 份分享，每份最多 5000 条和 8MiB 明文。不宣称绕过网盘会员权益或分享失效限制。

## 夸克链库

`/virtual/quark` 以一条分享对应一张持久卡片，桌面三列，窄屏两列或单列。编辑窗口第一行为分享链接与分享名称，第二行为五段 Cron 与“级联清理”选择器（默认开启，可关闭），第三行为容器生成位置与目录名称，其后为媒体及元数据扩展名。链接失焦时只读取得分享名称；留空名称和目录名称按保存时再次核验的分享名称填充。媒体和元数据字段留空时分别继承链库设置，非空以卡片为准；媒体匹配优先，允许使用合法的自定义扩展名，不限于音视频。快捷扩展名、格式校验及输入框复用任务编辑规范。

保存启用卡片或点击立即生成后，接口返回 HTTP 202，任务由应用后台执行；刷新、关闭页面或切换栏目不会取消已接受的任务，重新打开可读取真实运行状态。同一时刻仍只执行一个链库生成，不无限排队；服务退出会取消，重启标记中断，不自动重放云端写入。单次执行仍有 2min 上限。手动同步和编辑启用卡片保存时会确认同步清理范围，Cron 按已保存的设置执行。

单个共享根文件夹由目录名称替换，不重复套层；其余相对层级仅保留在本地生成目录及服务端登记索引中，不写入 STRM 正文。媒体生成 `原文件名.strm`，内容为本部署 STRM 地址下的 `/quark-share/分享码-提取码/原文件名.扩展名`，无提取码时省略连字符和提取码，例如 `http://主机:端口/quark-share/aa10bff58886/aa.mkv`。分享标识和文件名分别进行 URL 转义，不附加目录、文件 ID 或查询参数。播放按唯一的登记文件名取得真实分享父目录及文件 ID，仍须匹配本部署登记、发布且启用的媒体授权，知道分享码不能请求任意未登记文件。客户端 HTTP 请求不包含本地 STRM 所在目录，同一分享内多个不同子目录有完全同名的文件时，这个短地址无法唯一定位，返回 HTTP 409 名称冲突，不随机选择、不转存，也不擅自添加目录或参数。链接有提取码时会包含该码，STRM 应作为敏感链接保护；不包含 Cookie。已有 `/q/授权键/名称` 保留登记校验，重跑会将未被外部修改的旧正文（包括开发阶段含目录的正文）安全更新为仅文件名格式；带子目录的 `/quark-share/` 请求返回404。元数据通过单文件临时转存及下载取得，每个文件最多 64MiB，不下载媒体正文来生成 STRM。

完整读取分享成功且本次生成成功后进行同步：已有未变产物跳过，新项生成，消失或不再满足当前扩展名设置的登记产物删除并撤销授权。网络、读取或生成失败不进入同步清理。外部同名文件及外部修改过的文件不覆盖或删除，过时授权仍撤销。卡片显示真实新增 STRM、元数据、跳过及清理数；统计取持久生成记录，不冒充全盘扫描。

级联清理开启时，移除过时 STRM 的同名 `.nfo`、图片、字幕及常见 `-poster`、`-fanart` 等刮削伴随文件；仍被其他保留媒体使用的同名伴随文件不删。无 STRM 的子目录清理这些刮削文件并只删除空目录，未知类型文件保留；根目录不因本轮没有媒体而删除。不生成仅含元数据且没有所选媒体的子目录。关闭级联后，过时的登记 STRM/源元数据仍同步，额外刮削伴随文件和目录保留。

清理依赖 `/data/runtime/state.json` 中的目录归属与生成根内的 `.aether-library-owner` 标记；完整预扫最多 20000 项、32 层，拒绝符号链接、异常文件和越界，删除前再次核对卡片、目录身份和文件摘要。初次生成不会接管含未登记文件的已有目录；旧登记目录只能在产物和相关伴随文件均可核验时建立归属。不要在专用生成目录内存放其他原始图片或资料，勿删除归属标记。修改生成位置或目录名称仍逐项核验登记产物、复制后提交配置，再清理未改变的旧登记文件；迁移冲突、源变化、重叠或符号链接时停止。进程中断可能留下未引用副本，须人工核对，不能覆盖重试。

统计横条位于栏目导航下方、分享卡片上方，沿用 CAS 任务的环图、执行状态、右侧成功/异常两行及高竖形设置入口，进入 `/virtual/quark/settings`。成功率按每张卡片最近一次有有效时间的已结束执行统计，执行中和未执行不计入；链接、已登记 STRM、元数据及失效链接数量仍独立展示。生成总量未知时只显示实际阶段，不伪造百分比或使用往返动画。添加/编辑窗口遵循标准宽度，不显示窗口滚动条，极小视口仍保留滚动和键盘访问能力，不裁切字段。只绑定已启用的夸克存储；其中第一个强制绑定、不可在链库中取消，其他账号可自行切换，无可用账号显示“暂无夸克存储”。读取和保存设置都会规范化首个账号，读取本身不写配置。

设置新增默认容器生成位置，可输入或通过公共目录选择器选择，保存须为存在、可访问且无符号链接的绝对路径。新卡片及TG `/share`、`虚拟链库`命令使用此默认值，已有卡片自己的生成位置不自动迁移。未设置默认位置时，新建卡片默认未启用；没有生成位置不能启用或执行，但可保存未启用草稿。多个无输出位置的草稿不互相占用生成目录；补齐位置后编辑原卡片启用，保留原ID。已有登记产物的卡片不能直接清空位置，需按原迁移机制处理。没有可用账号时允许保存/编辑未启用草稿，但不能启用。机器人批次和默认设置变更保护详见通知服务说明。

分享确认失效后标红，默认连续 15 天未修复才再次核验失效并清理卡片对应的生成目录及授权，然后移除卡片；到期目录清理不受级联开关限制。仅明确分享不存在/取消的协议错误计为失效，网络、HTTP403、账号授权和分享令牌错误不能据此删除。无法确认失效、归属标记缺失、登记文件被修改、存在未知文件或清理失败时保留卡片并记录原因，不能在目录遗留时报告已完整移除。手动“移除卡片”仍按原确认说明保留本地文件，与失效到期清理不同。

播放时重新读取登记资源所在的分享目录，核验资源 ID、名称、大小，再按需转存一个文件到固定的云根 `/Aether/Share` 下的私有随机子目录。HEAD 探测不写云盘。提交前持久化一次性意图；请求结果不明或重启只查询，不自动重放。已转存文件优先复用；可用的夸克 STRM 接管绑定会直接使用现有 TV 302 通道，不可用则回到带必要请求头的 Aether 中继，Range 沿用公共读取实现。

临时路径属于所绑定夸克账号的云盘根目录，与账号文件浏览根目录和容器生成位置无关，不需要用户再填写或确认路径。缺少 `Aether`、`Share` 时按层创建，已有目录复用；创建回执与目录列表的名称、类型及 ID 核验一致后才使用。新目录可能延迟可见，每次创建只提交一次，随后最多六次只读查询、间隔 500ms，并保留原 API 间隔和取消检查。转存任务完成后文件列表暂为空时同样最多六次只读确认，不重新提交创建或转存。目录和文件列表、提交及任务查询都接续可信会话 Cookie，自动轮换后同步临时记录修订及仍有效的 TV 绑定；手动更换凭据不冒认旧绑定。同名文件、身份不符、取消、账号配置变化或结果始终未确认时停止，保留原数据及写入意图。元数据生成复用固定目录机制，不能将目录确认失败当作媒体 STRM 必须下载正文。

临时转存默认连续 12h 无调用后清理，调用成功会续期，中继中的文件不清理。自动清理仅将身份仍匹配的已确认文件移入夸克回收站，不递归删除目录、不清空回收站；用户移动或改名后的文件保留。结果不明的写意图不会因保活期届满而丢弃，应到网盘核对，不盲目重试。单次扫描最多 5000 项、32 层和 2min；最多 200 张卡片、20000 条生成记录、10000 条临时记录。

链库设置及含加密 `secret` 的卡片位于 `/config/state.json`，运行结果、生成授权/摘要和临时写意图位于 `/data/runtime/state.json`。两处连同主密钥共同备份；缺少运行态时不能恢复既有播放授权或判断过去的临时写入结果。系统日志模块 `virtual` 记录生成、迁移、转存、播放及清理结果，不输出凭据、分享密码和签名直链。真实账号权限、容量、TV 授权及上游限制仍需部署验证。

## 分享转存解析

“解析”展示每条分享的目录树，默认全选。展开后可勾选目录或文件，“应用”保存勾选并返回；“返回”、关闭或 Esc 放弃本次草稿。修改链接或切换目标存储清除原选择。转存前重新读取分享并验证选择路径，消失的项目会报错，不静默扩展为全选。

115、移动云盘和夸克转存统一按目录分批提交，每批严格少于 500 个文件，即最多 499 个；500 个文件分为 499＋1 两批。分享目录读取分页不变，完整读取后再合并提交，避免漏掉后续分页；提交批次调整不等于提升会员权益。成功与失败仍按原通知流程报告。

移动分享不再受原有整份 5000 项或单目录 50 页限制，超过 5000 个文件仍可按上述批次提交。移动目录每页请求100项，整页结尾继续读下一页直至确认结束，保留原文件夹层级；单次解析保留文件与目录合计200000项、32层、2分钟及单响应4MiB的资源保护，不是上游单批额度。取消选择也支持超过5000项，仍核验所有路径属于本次解析树；失败或结果不明停止后续批次，已消费批次不重放。移动只拿到任务编号时仍显示“转存已提交”，不冒充云端已完成。115、夸克和115链库原有扫描边界，以及CAS链接生成的独立扫描规则不变。

移动分享目录读取和转存提交现复用CAS链接解析已有的分享页加密正文、Mcloud-Sign及客户端头，读取加密响应并核验resultCode，不再向分享页接口发送旧明文JSON。TG和网页转存共用这一实现，不改账号权限、目标目录、批次内容或自动重试策略。连接错误区分DNS、TLS、超时、被关闭/拒绝和不可达，信息不含提取码、凭据或完整请求URL；读取失败且已提交0项时，尚未发起云盘转存，不能据此判定目标目录或账号无效。

夸克同一次预览的根目录、子目录和转存共用同一分享令牌，并在会话内接续使用上游轮换的 Cookie，不改写保存的账号配置。HTTP 错误会区分获取令牌、读取目录、提交转存和查询结果；403 本身不能证明 Cookie 失效，也可能与分享权限或服务器出口有关。写请求失败仍不自动重试，应先检查目标网盘，避免重复提交。

## STRM 替换

常规替换按原文匹配；正则替换采用 Go RE2，替换值支持 `$1`、`${name}` 捕获组。预览只读统计实际变化的文件，并显示最多四个样例；执行前二次确认数量。目录最多 10000 项、32 层，单文件及替换后最多 1 MiB；符号链接和外部修改不覆盖。确认数量属于预览时刻，执行前或执行中外部修改可能使最终数量不同。
