# 虚拟链库与分享解析

## 115 链库

侧栏“虚拟链库”依次为“115链库”“移动链库”“夸克链库”“CAS链库”，当前仅开放 115。天翼链库栏目已移除，旧地址 `/virtual/tianyi` 返回 `/virtual/115`；CAS栏目使用与CAS任务一致的线条图标，暂未开放，不代表已经新增解析或生成能力。选择已启用的 115 存储，输入官方分享链接及访问码，解析后选择容器内已有目录生成。音视频文件保留分享目录结构，名称为原文件名加 `.strm`，已有文件不覆盖。

内容格式：`http://主机:端口/s/分享码_访问码_文件ID.mkv?/原文件名称.mkv`。没有访问码时保留两个下划线。主机地址使用系统 STRM 配置；分享码、访问码、文件 ID 不绑定特定账号。

本机生成过的资源在 `/data/virtual-library` 保存加密的最小授权索引，包括分享所在目录 ID，播放只读取该目录，避免每次递归整个分享。授权索引不是模块配置。公开请求不能任意要求账号接收新分享：未登记的可携式 URL 使用 115 的只读分享直链接口；如果该接口拒绝读取，需要先在本机链库生成，才能授权临时接收。不要公开包含访问码的 STRM 或服务地址。

临时接收共用 ED2K 的 115 存储绑定池、轮换时间、保活和“临时目录”。每个资源使用独立子目录，验证名称、大小、SHA1 和云端文件 ID 后才返回下载票据，UA 使用播放器请求值；存活临时文件优先复用。HEAD 不创建文件。写请求先记提交意图，响应不明确时只查询，不自动再次接收。清理共用临时文件列表，仅删除身份及 SHA1 仍匹配的文件，不删除整个目录。有效分享、账号权限和网盘可用容量仍是播放前提。

单次最多扫描 5000 项、32 层；预览 10 分钟有效，本机授权和临时提交记录各最多 10000 项。其他三个链库暂未开放。不宣称绕过网盘会员权益或分享失效限制。

## 分享转存解析

“解析”展示每条分享的目录树，默认全选。展开后可勾选目录或文件，“应用”保存勾选并返回；“返回”、关闭或 Esc 放弃本次草稿。修改链接或切换目标存储清除原选择。转存前重新读取分享并验证选择路径，消失的项目会报错，不静默扩展为全选。

115、移动云盘和夸克转存统一按目录分批提交，每批严格少于 500 个文件，即最多 499 个；500 个文件分为 499＋1 两批。分享目录读取分页不变，完整读取后再合并提交，避免漏掉后续分页；提交批次调整不等于提升会员权益。成功与失败仍按原通知流程报告。

移动分享不再受原有整份 5000 项或单目录 50 页限制，超过 5000 个文件仍可按上述批次提交。移动目录每页请求100项，整页结尾继续读下一页直至确认结束，保留原文件夹层级；单次解析保留文件与目录合计200000项、32层、2分钟及单响应4MiB的资源保护，不是上游单批额度。取消选择也支持超过5000项，仍核验所有路径属于本次解析树；失败或结果不明停止后续批次，已消费批次不重放。移动只拿到任务编号时仍显示“转存已提交”，不冒充云端已完成。115、夸克和115链库原有扫描边界，以及CAS链接生成的独立扫描规则不变。

移动分享目录读取和转存提交现复用CAS链接解析已有的分享页加密正文、Mcloud-Sign及客户端头，读取加密响应并核验resultCode，不再向分享页接口发送旧明文JSON。TG和网页转存共用这一实现，不改账号权限、目标目录、批次内容或自动重试策略。连接错误区分DNS、TLS、超时、被关闭/拒绝和不可达，信息不含提取码、凭据或完整请求URL；读取失败且已提交0项时，尚未发起云盘转存，不能据此判定目标目录或账号无效。

夸克同一次预览的根目录、子目录和转存共用同一分享令牌，并在会话内接续使用上游轮换的 Cookie，不改写保存的账号配置。HTTP 错误会区分获取令牌、读取目录、提交转存和查询结果；403 本身不能证明 Cookie 失效，也可能与分享权限或服务器出口有关。写请求失败仍不自动重试，应先检查目标网盘，避免重复提交。

## STRM 替换

常规替换按原文匹配；正则替换采用 Go RE2，替换值支持 `$1`、`${name}` 捕获组。预览只读统计实际变化的文件，并显示最多四个样例；执行前二次确认数量。目录最多 10000 项、32 层，单文件及替换后最多 1 MiB；符号链接和外部修改不覆盖。确认数量属于预览时刻，执行前或执行中外部修改可能使最终数量不同。
