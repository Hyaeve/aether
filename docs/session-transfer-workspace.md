# 会话与传输视图

- 主导航的原“仪表盘”改为“以太视界”，原`/dashboard`路由及入口功能不变。顶栏显示当前侧栏模块及其栏目，例如“文件服务 → 文件管理”“存储管理 → 云下载”；设置和绑定子页继续显示所在栏目与子页名称。窄屏隐藏品牌前缀，路径单行收缩，不遮住右侧操作。
- 原“系统日志”统一改名“运行日志”，保留`/logs`路由、日志文件和筛选能力。全部11个侧栏入口连续排列，运行日志和系统设置不再固定贴底；侧栏220px、品牌底部间距收紧，放不下时在导航区滚动并隐藏滚动条，不裁掉末尾入口。760px及以下收起侧栏，无悬浮的触屏设备在高度500px及以下同样收起；内容与顶栏使用相同条件取消左侧偏移，其他尺寸为侧栏保留220px，不能让侧栏覆盖内容。手机与短横屏保留既有展开导航和安全区。
- 刮削海报墙保留宽屏最多七列和2:3海报比例，虚拟行距使用实际首行卡片高度及12px间隔；窗口或列数变化后重新测量，避免小数列宽舍入在大量行中累积成空隙或末行不可达。
- 音频侧栏可通过Esc或叉关闭并停止播放、清空本次队列；折叠仍只缩为胶囊继续播放。叉位于折叠按钮朝页面内侧的一边，左右停靠同步镜像。焦点在普通页面或胶囊时Esc同样可关闭，其他活动模态框保留自己的Esc优先级。
- 当前浏览器会话恢复各模块最近的栏目、文件管理的存储池和完整目录。新会话仅恢复长期保存的存储池及排序、视图偏好，不恢复目录。会话信息按管理账号隔离，不写服务端配置。
- 侧栏不记忆独立跳转页：缓存设置返回缓存任务，CAS/ED2K存储绑定池返回对应任务，115秒传中心返回辅助工具，夸克链库设置返回夸克链库，备份设置返回备份规则。已有会话中保存的这些子页同样按返回栏目恢复；直接打开、刷新和浏览器前进后退仍可访问子页，不影响普通栏目或文件目录记忆。
- 收藏夹目录与最近访问历史属于管理账号的跨客户端记录，服务端持久保存到 `/data/runtime/state.json` 的 `fileFavorites` 和 `fileVisits` 字段，不写 `/config`，配置备份不包含它们，导入配置不覆盖现有记录。保留 `/data` 持久化映射即可在容器重启、换浏览器后恢复；账号改名仍保留。添加/取消逐条合并，其他已打开客户端随约5秒状态轮询更新。旧 `/config/state.json` 收藏在启动时迁移；旧浏览器localStorage收藏和访问历史在进入文件管理时自动合并，成功后移除本地旧字段，失败保留以便重试。已取消收藏不会被旧浏览器迁移重新加入，旧访问记录不会覆盖新的共享顺序。展开状态、视图和排序仍是浏览器偏好。
- 历史访问仅记录根目录下至少两级的目录，同存储池同分支保留最深位置，兄弟目录分别保留，最多五条。无记录时按钮仍可点击展示空记录菜单；悬浮超过0.6秒展开，移向菜单的间隙保留关闭容错。
- 重命名工作台最近五个目录的操作记录保存到 `/data/runtime/state.json`，最新操作目录在前；重启后恢复记录和顺序。保留原 `/config` 和 `/data` 持久化映射，勿删除数据卷；只有配置备份不包含这些运行历史。历史命名记录的目录选择器占满标题至全选按钮之间的固定区域，下拉菜单同宽，不随悬浮伸缩，路径不足时以 `/../` 明示省略父目录。
- 传输记录按实际传输字节显示进度与最近两秒平均速度。已知总大小显示百分比，未知总大小显示已传输字节，不使用虚假流动进度。成功记录从完成时保留一分钟，失败记录保留三天，支持手动清除失败记录。
- 文件管理复制和移动允许选择不同类型的已启用存储池。跨池且涉及非本地存储时，完整预扫最多100000项/128层，复用正文暂存、上传发布和SHA256校验；不是把某一云盘的文件ID交给另一账号。目标同名不覆盖、符号链接不传输。移动在目标和源内容全部校验后才清理源文件，远程空目录保留，本地空目录只做非递归安全删除；失败和结果不明不自动重提。
- 跨类型复制/移动及实际上传下载在传输中心显示来源、目标和进度，并写系统日志。跨池总条目随源内容实际写入本机暂存的字节更新，不再等整份文件校验后才累计；不把后续目标写入再次累加。已读完100%但尚在发布或校验时仍为执行中，成功只在目标校验通过后确认。原同池原生操作、本地间操作和上传入口保持；云端内部复制无法提供的字节进度不伪造。大文件正文经过服务器及临时目录，真实云盘性能、配额和权限仍需现场验收。
- 跨池复制或移动失败时，运行日志和失败条目保留失败阶段，已知时附所选项目的相对路径；两端位置及已处理字节沿用实际任务记录。阶段包括来源/目标读取、选区核对、同名检查、扫描、路径准备和目录创建；文件正文进一步区分下载取链、本机暂存、来源完整性、本地目标创建/写入/同步/发布、云端上传和目标校验，整批源清理单独报告，不把最后处理的文件误标成清理失败文件。移动云盘到本地存储经服务器暂存后落盘，不使用云端内部复制。
- 已知校验错误可明确说明，空间不足、只读、权限、授权、同名冲突、路径非目录、取消、超时、DNS及连接失败等按安全类别反馈。移动目录/取链、WebDAV目录和上游正文的HTTP错误保留本地产生的状态说明，未知上游错误不回显原文、凭据、签名链接或本机绝对路径。失败记录重启后仍保留安全说明，旧日志中缺失的信息无法事后补回。`0/0`本身不能定位网络错误；总量在完整预扫后建立，后续按实际暂存字节累计，失败时保留已处理部分。
- 备份扫描、缓存/CAS扫描及STRM替换不使用往返或原生不定进度动画。已知总量时按实际处理数更新；未知总量时显示真实计数、当前阶段和静止轨道，不把扫描中显示成虚假的百分比。云下载进度条宽度随上方时间文本，不占满整个状态列。
- 任务卡片和通知时间统一为`26/10/24 18:59`，缺失时间保留原空态含义，不虚构执行时间。
- 最近通知中每条通知的时间与标题同一行靠右，保持完整单行和原灰色，字号13px；长标题单行省略，可通过共享全文提示查看，通知详情独立保留在下方。通知84px行高、三行可视区、清除及点击进入日志的行为不变。
- 联动任务的上次结果写入 `/data/runtime/state.json`，不会混入 `/config/task/automation.json`。下一次执行由服务端 Cron 计划提供，手动联动显示 `--`。
- 文件夹大小由查看详情计算并缓存；刷新当前目录清除其直接子目录的计算结果，不自动遍历重算。原始文件大小不受影响。

## 滚动行为

- 文件管理和直链缓存存在超出一页的条目时，窗口内外的滚轮使用相同顺序：下滑先滚动页面，到窗口顶部距面包屑下方 8px 时再滚动条目；上滑先滚动条目，条目到顶后再上移页面。连续滚轮按实际步长平滑过渡，并遵循减少动态效果偏好。
- STRM 刮削和系统日志按整页正常滚动，筛选栏随页面移出，不再固定在面包屑下方。面包屑始终固定，海报、文件和日志仍使用虚拟列表，底部显示总数。
- 任务栏目及设置跳转页、CAS绑定池、日志和历史命名记录的页面滚动条从面包屑以下开始，统一5物理像素并适配主题。绑定池账号窗口和通知等内层保持3物理像素；联动列表不再独立滚动。
