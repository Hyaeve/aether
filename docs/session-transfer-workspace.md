# 会话与传输视图

STRM刮削工作台手动匹配可连续选择作品。当前刮削运行时，后续确认进入同一串行队列（最多100项），状态显示排队数；海报及目录视图的手动识别入口仍可用，重置与整库操作继续保护。队列不提前修改正在使用的索引，轮到执行时重新核验任务配置、生成目录身份和作品；同一待执行作品不重复入队。停止刮削会清空队列并取消当前操作，重启不重放；配置变化导致未执行的匹配停止并记日志，不能把旧确认应用到新目录。

“以太工坊”首项以太识律，依次为识别规则、命名规则、媒体分类、洗版策略、辅助配置五个栏目。识别规则提供配置与只读预览；命名支持剧集/电影可视化源码模板，洗版支持10组排序启停及线性总分比较，多版命名暂占位；媒体分类预设有分类目录与分类规则两个编辑栏目，仅剧集、电影两类。TMDB和AI沿用辅助配置窗口，原数据及配置接口保持。栏目使用原生导航链接和统一面包屑，按账号记忆侧栏返回位置，手机沿用可横向滚动的页签。任务中心原目录整理改为整理归档，保存目录、方式、规则关联及相关开关等配置，但不调度执行；原分类选择兼容读入，统一输出mediaCategoryRuleId。见[以太识律](rules-workspace.md)、[媒体分类](media-categories.md)、[整理归档](organize-archive.md)。

辅助工具的媒体深度删除窗口提供以链联动选择、显式启用确认和20条分页记录；以链更多选项可设置媒体目录映射。只有通过以链主动删除普通STRM才联动源文件，删除整部作品完整枚举其普通指针。CAS/分享/ED2K专用指针、扫描移除和原服务直连请求不触发，详见[媒体深度删除](media-deep-delete.md)。

## 滚动行为

- 文件管理和直链缓存存在超出一页的条目时，窗口内外的滚轮使用相同顺序：下滑先滚动页面，到窗口顶部距面包屑下方 8px 时再滚动条目；上滑先滚动条目，条目到顶后再上移页面。连续滚轮按实际步长平滑过渡，并遵循减少动态效果偏好。
- STRM刮削和运行日志按整页正常滚动，筛选栏随页面移出，不固定在面包屑下方。面包屑始终固定，海报、文件和日志仍使用虚拟列表，底部显示总数。运行日志向下滚动超过一屏约四分之三且至少320px后，在右下角显示“回到顶部”箭头按钮；点击或键盘激活后立即回顶并将焦点交还日志列表，回顶后隐藏。结构化及原始模式均支持，按钮避让手机安全区。
- 任务栏目及设置跳转页、CAS绑定池、日志和历史命名记录的主页面滚动条从面包屑以下开始，统一8物理像素并适配日夜主题、DPR和缩放。绑定池账号窗口和通知等内层保持原公共细轨；联动列表不再独立滚动。
