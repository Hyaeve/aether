# 会话与传输视图

- `/dashboard` 入口及页面标题改为“信息总览”，路由和功能不变。原“太一档案”改为[档案中心](taiyi-archives.md)，档案路由、接口和持久文件名不变。顶栏显示当前模块及其栏目，例如“文件服务 → 文件管理”“档案中心 → 刮削档案”；设置和绑定子页继续显示所在栏目与子页名称。窄屏隐藏品牌前缀，路径单行收缩，不遮住右侧操作。
- 侧栏12个入口分三组，标题为12px灰色文字及两侧细线，不作为可点击入口或新增路由。“以太视界”包含信息总览、文件服务、存储管理；“以太工坊”包含传输中心、任务中心、虚拟链库、以太链接、辅助工具、档案中心；“系统面板”包含通知服务、运行日志、系统设置。组间12px，组内保留原按钮及间距，运行日志与系统设置不贴底。侧栏220px、品牌底部间距收紧，放不下时在导航区滚动并隐藏滚动条，不裁掉末尾入口。760px及以下收起侧栏，无悬浮的触屏设备在高度500px及以下同样收起；内容与顶栏使用相同条件取消左侧偏移，其他尺寸为侧栏保留220px，不能让侧栏覆盖内容。手机与短横屏保留既有展开导航和安全区。分组不改变各入口的会话记忆或浏览器前进后退行为。
- 任务中心的首个栏目“任务面板”位于 `/tasks/panel`，直接访问 `/tasks` 默认显示该栏；已有侧栏会话仍可恢复用户上次的普通任务栏目。面板每1.5秒读取受认证保护的只读快照，展示运行中的目录任务、解析生成队列、刮削与联动状态，支持按类型和名称筛选并跳转到对应栏目。已知总量才显示百分比，未知只显示真实处理量和阶段，目录整理等占位能力不伪造运行记录。后台页面暂停读取，离页取消，账号切换清空旧内容，10秒超时后可继续刷新，不叠加未完成请求；运行任务本身不依赖面板打开。
- 辅助工具的首个栏目改为“我的插件”，使用错位方块线条图标，侧栏“辅助工具”名称和原工具功能不变。
- 刮削海报墙保留宽屏最多七列和2:3海报比例，虚拟行距使用实际首行卡片高度及12px间隔；窗口或列数变化后重新测量，避免小数列宽舍入在大量行中累积成空隙或末行不可达。
- 音频侧栏可通过Esc或叉关闭并停止播放、清空本次队列；折叠仍只缩为胶囊继续播放。叉位于折叠按钮朝页面内侧的一边，左右停靠同步镜像。焦点在普通页面或胶囊时Esc同样可关闭，其他活动模态框保留自己的Esc优先级。
- 当前浏览器会话恢复各模块最近的栏目、文件管理的存储池和完整目录。新会话仅恢复长期保存的存储池及排序、视图偏好，不恢复目录。会话信息按管理账号隔离，不写服务端配置。
- 侧栏不记忆独立跳转页：缓存设置返回缓存任务，CAS/ED2K存储绑定池返回对应任务，115秒传中心返回辅助工具，夸克链库设置返回夸克链库，备份设置返回备份规则。已有会话中保存的这些子页同样按返回栏目恢复；直接打开、刷新和浏览器前进后退仍可访问子页，不影响普通栏目或文件目录记忆。
- 收藏夹目录与最近访问历史属于管理账号的跨客户端记录，服务端持久保存到 `/data/runtime/state.json` 的 `fileFavorites` 和 `fileVisits` 字段，不写 `/config`，配置备份不包含它们，导入配置不覆盖现有记录。保留 `/data` 持久化映射即可在容器重启、换浏览器后恢复；账号改名仍保留。添加/取消逐条合并，其他已打开客户端随约5秒状态轮询更新。旧 `/config/state.json` 收藏在启动时迁移；旧浏览器localStorage收藏和访问历史在进入文件管理时自动合并，成功后移除本地旧字段，失败保留以便重试。已取消收藏不会被旧浏览器迁移重新加入，旧访问记录不会覆盖新的共享顺序。展开状态、视图和排序仍是浏览器偏好。
- 文件管理收藏夹桌面宽208px、手机宽154px；上方存储池选择器同时加宽为160px/110px，按同一布局变量保持右边界对齐，折叠、目录及收藏行为不变。
- 历史访问仅记录根目录下至少两级的目录，同存储池同分支保留最深位置，兄弟目录分别保留，最多五条。无记录时按钮仍可点击展示空记录菜单；悬浮超过0.6秒展开，移向菜单的间隙保留关闭容错。
- 重命名工作台最近五个目录的操作记录保存到 `/data/runtime/state.json`，最新操作目录在前；重启后恢复记录和顺序。保留原 `/config` 和 `/data` 持久化映射，勿删除数据卷；只有配置备份不包含这些运行历史。历史命名记录的目录选择器占满标题至全选按钮之间的固定区域，下拉菜单同宽，不随悬浮伸缩，路径不足时以 `/../` 明示省略父目录。
- 传输记录按实际传输字节显示进度与最近两秒平均速度。已知总大小的条目及顶部汇总百分比保留最多两位小数、向下截断，避免大文件很长时间显示整数0%，也不提前四舍五入到100%；未知总大小显示已传输字节，不使用虚假流动进度。成功记录从完成时保留一分钟，失败记录保留三天，支持手动清除失败记录。
- 日间侧栏采用浅灰蓝表面、深色文字及左侧选中标记，夜间保留深色侧栏。悬浮文字轻微缩放但不改变按钮尺寸；减少动态效果时关闭缩放。
- 刮削、分享栏、云下载、回收站和传输列表共用紧凑多选胶囊，内部按钮无独立底框，文字悬浮缩放；云管理三栏采用相同的较明显蓝紫选择底色和描边。保留原二次确认、Shift、全选、Esc与外部退出。
- 传输的复制、上传、下载统一为“进度状态”：状态前有语义图标，下方104×4px真实字节进度；成功、跳过、忽略为绿，进行、预处理、等待为蓝，暂停、排队为橙，失败、错误为红。取消归错误，详细原因使用安全提示和运行日志；部分按需读取结束不伪造100%。
- 三种传输栏目都支持右键或键盘空格进入多选，批量暂停、恢复、重试、删除只处理当前支持的选项。删除与重试二次确认，删除只取消受控任务并清记录，不删除来源或已完成的目标。原生云端复制提交后无法暂停或撤回，按钮禁用。
- 备份规则的设置和添加按钮保持与栏目标题同行，窄屏栏目可在自身范围横向访问，不把操作区挤出视口；传输任务的搜索和筛选操作在700px及以下换到下一行，两者的换行规则分别生效。
- 本地与跨池代理复制在扫描、读写和发布边界响应暂停/取消；来源目录和文件按已核验名称展示，多选显示首个名称和总项数。同池云操作复用其已有源目录读取，不额外请求一次列表。
- 手动重试目前仅支持当前进程中有安全重建上下文的本地普通文件复制：重新核对两端配置、原文件身份、大小和修改时间，目标必须不存在，不覆盖。目录复制、移动、浏览器请求体、实时下载、备份及已提交云写不能从记录重放，应从原入口重新发起；重启恢复的失败记录同样不带重试能力。
- 上传并发等待显示排队，取得资源但尚未开始正文时为等待，暂存与发布准备显示预处理，首个真实正文读写后为进行。忽略扩展名记录为忽略，上传目标已存在记录为跳过，均零覆盖。状态筛选器只在当前传输栏目内有效，切栏目、离开页面或刷新重置为所有状态。
- 三个传输类型统计区显示记录条数、已处理/总字节和百分比；没有记录显示“0 空闲”。含未知总量时显示总量待确认，保留真实已处理量，不伪造百分比。
- 存储卡片的会员背景标识取自独立只读查询，详见[存储会员信息](storage-membership.md)。容量查询失败可沿用已核验容量，但不能借此保留过期会员等级。
- 文件管理复制和移动允许选择不同类型的已启用存储池。跨池且涉及非本地存储时，完整预扫最多100000项/128层，复用正文暂存、上传发布和SHA256校验；不是把某一云盘的文件ID交给另一账号。目标同名不覆盖、符号链接不传输。移动在目标和源内容全部校验后才清理源文件，远程空目录保留，本地空目录只做非递归安全删除；失败和结果不明不自动重提。
- 跨类型复制/移动及实际上传下载在传输中心显示来源、目标和进度，并写系统日志。跨池总条目随源内容实际写入本机暂存的字节更新，不再等整份文件校验后才累计；不把后续目标写入再次累加。已读完100%但尚在发布或校验时仍为执行中，成功只在目标校验通过后确认。原同池原生操作、本地间操作和上传入口保持；云端内部复制无法提供的字节进度不伪造。大文件正文经过服务器及临时目录，真实云盘性能、配额和权限仍需现场验收。
- 上传、备份和跨池复制以实际目标决定单文件入口上限：原生移动选择PC时500 GB，其他云盘及网关目标保持100 GiB，本地文件系统目标不套云端100 GiB门槛，受实际空间及文件系统约束。500 GB按十进制计算，完整暂存和内容校验仍执行；PC配置不扩大本地下载器或CAS特征下载等独立保护限额，详见[移动PC上传](mobile-pc-upload.md)。
- WebDAV同客户端同文件的Range读取合并为共享下载条，按唯一字节范围显示进度，关闭一段不会标整文件成功；两分钟空闲且仅部分读取以“跳过”结束并保留真实比例。近期终态及失败有30秒合并/冷却，减少探测和重试产生的重复条目。客户端与存储/文件修订隔离、256会话保护及票据边界见[115本机读取](115-reading.md)。
- 应用退出时关闭共享WebDAV会话登记，同步完成或阻止在途结束日志写入，再完成退出；空闲计时器停止，迟到回调不重复写入。未读完的条目按取消结束，已完成或失败的结果和实际字节不改；不再接受新的共享会话，也不重放云端请求。
- 跨池复制或移动失败时，运行日志和失败条目保留失败阶段，已知时附所选项目的相对路径；两端位置及已处理字节沿用实际任务记录。阶段包括来源/目标读取、选区核对、同名检查、扫描、路径准备和目录创建；文件正文进一步区分下载取链、本机暂存、来源完整性、本地目标创建/写入/同步/发布、云端上传和目标校验，整批源清理单独报告，不把最后处理的文件误标成清理失败文件。移动云盘到本地存储经服务器暂存后落盘，不使用云端内部复制。
- 已知校验错误可明确说明，空间不足、只读、权限、授权、同名冲突、路径非目录、取消、超时、DNS及连接失败等按安全类别反馈。移动目录/取链、WebDAV目录和上游正文的HTTP错误保留本地产生的状态说明，未知上游错误不回显原文、凭据、签名链接或本机绝对路径。失败记录重启后仍保留安全说明，旧日志中缺失的信息无法事后补回。`0/0`本身不能定位网络错误；总量在完整预扫后建立，后续按实际暂存字节累计，失败时保留已处理部分。
- 备份扫描、缓存/CAS扫描及STRM替换不使用往返或原生不定进度动画。已知总量时按实际处理数更新；未知总量时显示真实计数、当前阶段和静止轨道，不把扫描中显示成虚假的百分比。云下载进度条宽度随上方时间文本，不占满整个状态列。
- 任务卡片和通知时间统一为`26/10/24 18:59`，缺失时间保留原空态含义，不虚构执行时间。
- 数字统计默认用1400ms四次ease-out单调递增动画，前段快速大步逼近，进入目标值最后10%后步长减小、变化减速，避免过长拖尾；减少动态效果时直接显示实际值。这是展示过渡，不改变实际统计或任务进度。
- 最近通知中每条通知的时间与标题同一行靠右，右侧额外内收6px，保持完整单行和原灰色，字号13px；长标题单行省略，可通过共享全文提示查看，通知详情独立保留在下方。通知84px行高、三行可视区、清除及点击进入日志的行为不变。
- 联动任务的上次结果写入 `/data/runtime/state.json`，不会混入 `/config/task/automation.json`。下一次执行由服务端 Cron 计划提供，手动联动显示 `--`。
- 文件夹大小由查看详情计算并缓存；刷新当前目录清除其直接子目录的计算结果，不自动遍历重算。原始文件大小不受影响。

## 滚动行为

- 文件管理和直链缓存存在超出一页的条目时，窗口内外的滚轮使用相同顺序：下滑先滚动页面，到窗口顶部距面包屑下方 8px 时再滚动条目；上滑先滚动条目，条目到顶后再上移页面。连续滚轮按实际步长平滑过渡，并遵循减少动态效果偏好。
- STRM刮削和运行日志按整页正常滚动，筛选栏随页面移出，不固定在面包屑下方。面包屑始终固定，海报、文件和日志仍使用虚拟列表，底部显示总数。运行日志向下滚动超过一屏约四分之三且至少320px后，在右下角显示“回到顶部”箭头按钮；点击或键盘激活后立即回顶并将焦点交还日志列表，回顶后隐藏。结构化及原始模式均支持，按钮避让手机安全区。
- 任务栏目及设置跳转页、CAS绑定池、日志和历史命名记录的主页面滚动条从面包屑以下开始，统一8物理像素并适配日夜主题、DPR和缩放。绑定池账号窗口和通知等内层保持原公共细轨；联动列表不再独立滚动。
