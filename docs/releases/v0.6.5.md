# v0.6.5

## 夸克分享链库

- 开放“夸克链库”，一条分享对应一张卡片，桌面三列并适配窄屏。可设置分享链接、名称、五段 Cron、容器生成位置、目录名称和媒体及元数据扩展名。
- 保存启用的卡片后首次生成，也可手动执行或定时增量读取。媒体生成分享 STRM，元数据按配置下载；自定义扩展名优先于默认值，保留相对层级，不覆盖外部同名或被修改的文件。
- 修改生成位置或目录名称时核验已登记文件，复制校验并保存新配置后再清理未变化的旧产物。保留用户文件，冲突、身份变化、符号链接或目录重叠时停止；迁移提交前中断可能留下待人工核对的副本。
- 底部提供环状统计及独立设置入口。默认绑定首个启用的夸克存储，确认失效的分享默认保留 15 天；网络、授权或令牌异常不冒充分享失效。移除卡片撤销播放授权，本地产物保留。
- 播放按需转存单文件到固定 `/Aether/Share` 下的独立目录，已确认文件优先复用。有效的夸克 STRM 接管绑定复用 TV 302 通道，否则使用支持 Range 的中继；HEAD 探测不创建云端文件。
- 临时转存默认连续 12h 无调用后清理，仅处理身份仍匹配且未在中继中的已登记文件。写前持久化意图，结果不明或重启不自动重放；不递归删除云端目录或清空回收站。
- 配置、生成授权、迁移和临时操作回执分别持久化，日志记录实际阶段与结果，不包含分享密码、Cookie、Token 或签名直链。

## 以太链接

- 更多选项新增“中继守护”，默认开启，旧卡片缺省兼容；“始终中继”模式下不可切换。
- 关闭后，客户端网络命中 302 策略时必须取得可用直链；解析、探测或目标可达性失败返回 502，不再退回中继。另一侧本应中继的网络及普通非 STRM 媒体保持原有处理方式。

## 目录选择与构建回归

- 修复共享目录选择器把路径独占工具栏一行的布局回归。桌面路径、筛选和新建按钮同行；700px 及以下仅筛选移到第二行，路径与新建按钮仍同行。
- 路径本身不换行，宽度不足从根后浅层省略，优先保留最深目录；各级和省略菜单仍可点击跳转。
- 增加日夜主题、1440/701/700/390px 布局回归，保留原有精确对齐、日期字号及路径导航断言，不放宽测试超时或关闭截图诊断。

## 升级与验收边界

- 保留 `/config`、`/data` 及主密钥。夸克链库卡片和设置位于 `/config/state.json`，生成授权及临时操作意图位于 `/data/runtime/state.json`；运行态丢失不能自动恢复旧播放授权或判断未知写入结果。
- 移动链库、CAS 链库和外部插件运行时仍未开放。本地模拟测试及 Linux 交叉构建不替代真实云盘、TV 授权、迁移中断、12h/15d 保留策略和 Docker 部署验收。
