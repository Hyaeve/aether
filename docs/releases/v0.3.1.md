# v0.3.1

## 界面与实时流量

- 移除存储管理顶部统计区，直接展示存储池与添加入口。
- 顶部上传、下载改为实时速率，每秒刷新，显示 B/s、KB/s、MB/s，空闲归零。
- 优化仪表盘窗口、通知明细、重命名工作台、分享转存交互和星空动画。

## 传输与存储

- 新增传输中心，展示最近传输记录及可观测的字节进度。
- WebDAV 管理员支持上传、新建目录、移动、删除及锁操作，独立用户保持只读；目录浏览不再提前请求文件下载地址。
- FUSE 增加容量报告和内核权限检查，新挂载默认权限为 0777，已有配置保持不变。
- 分享转存支持有界分批提交，防止重复提交与错序执行，改善多链接进度反馈。

## 任务与媒体

- 任务支持排序与媒体、元数据扩展名配置，选定元数据按原样复制。
- 改进中文季集、特别篇和跨季作品识别，保留手工匹配；刮削工作台记忆所选库并优化虚拟滚动。
- Emby 入库通知展示电影、剧集及季集信息，同服务器同剧同季在十分钟内归并并去重。
- 增加 CI 截图捕获的有限重试，持续失败仍报告错误。

## 使用边界

- 顶部速率统计已接入跟踪的 Aether 文件传输与 ZIP 输出，不是宿主机网卡总流量；302 直连、网盘内部复制和以链独立代理不计入。
- 传输请求结束不代表远端已完整下载；未知总量不显示虚假百分比。
- 真实网盘账号、Linux FUSE 内核、TMDB 与第三方 Webhook 仍需部署环境联调。
- 镜像工作流保持仅构建 linux/amd64（x86-64）。
