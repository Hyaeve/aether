# v0.4.3

## 视图与文件编辑

- 图片预览对照 Lumic 调整右上关闭、边缘切图及底部 Dock 的浮现和延时隐藏；点击退出，拖动与双击缩放不误退出。
- 音乐支持顺序播放、随机播放、列表循环、单曲循环；单曲上下首重新播放。三点菜单包含下载和列表，音量支持滚轮调整；抽屉更圆润、封面更大，胶囊使用封面磨砂底色、旋转封面和独立播放控制。
- 文件管理与刮削文件视图共享紧凑 STRM/NFO 编辑器，采用媒体中立 STRM 图标，校验文件版本避免覆盖已变更内容。
- 刮削文件视图去掉类型栏，路径和操作增加悬浮反馈，剧集与季目录均可识别或重置。历史访问按钮与刷新图标统一。
- 直链缓存、日志、通知和重命名面板采用统一三物理像素滑块；日志和缓存先滚动短页面头部，再滚动原有虚拟列表，页面不显示外层滑动条。

## 备份规则

- 传输中心内容延伸到页面底部，备份编辑使用标准 640px 宽度，适配日夜输入层级。
- 本地源目录可开启文件系统监听：参考 Nestify 五秒元数据指纹轮询，变化稳定两轮后执行备份；云盘源使用定时扫描。
- 新增完成后保留源文件、删除已备份源文件、删除已备份源文件与空文件夹。所有目标复制成功且内容校验通过后才清理；跳过、失败、取消、源变更时保留文件。空目录非递归清理仅支持本地，不删除源根目录。
- 配置继续位于 `/config/transfer/backup.json`，执行结果与删除计数位于 `/data/runtime/state.json`。

## 存储健康与读取

- 存储健康改为按提供商自适应检查周期、认证退避、网络短重试与单存储探测合并；任务按实际读取来源检查认证阻断。
- 空间查询与健康巡检合并，成功结果缓存到运行数据，页面直接使用快照。移动原生空间查询增加 `ud_id` 支持；缺少账户 ID 时展示用户名。
- 修正反代场景登录同源校验，仍拒绝不可信跨站请求；相关部署说明见 `docs/reverse-proxy.md`。
- 本机代理读取 115 时每存储最多两个并发读取请求，每请求上限 50MB/s，优化 FUSE 缓存命中与连续读取。不是保证速度，仍受出口、上游和磁盘限制。

## 验证边界

本地前端构建、147/147 Playwright、Go 全量测试、go vet 与 Linux amd64 测试交叉编译及构建通过。已检查桌面及手机、日间及夜间截图；不将本地验证等同于远端 GitHub 镜像构建成功。

真实网盘账户、天翼令牌轮换和 Linux 内核 FUSE 挂载未在本机联调。备份清理会额外读取目标验证内容，云盘删除遵循存储删除模式；运行期间第三方写入无法提供跨服务事务保证。构建仍只发布 linux/amd64 镜像。
