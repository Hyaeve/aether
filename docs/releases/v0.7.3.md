# v0.7.3

本版包含重命名六类规则、CAS智能计算与目录保护、分享活链及转存记录、115上传与挂载修复，以及工作区交互调整。

## 重命名与文件管理

- 重命名工作台支持查找替换、修改名称/添加序号、添加字符、删除字符、移动字符和字符转换。“添加规则”先展开类型列表，右侧角标同步展开/折叠；规则预览、执行和规则集保存共用校验。
- 编号支持统一名称、前后位置、起始值、补零位数及分隔符；忽略项不占序号。字符位置按Unicode字符计数，删除支持八类字符、独立左右方向的范围和自定义首次/全部匹配。
- 大小写、繁简和全半角独立选择，默认不转换。繁简使用固定版本OpenCC内嵌词典，支持香港、台湾地区变体，无联网转换或外部词典依赖。
- 除查找替换外保留文件最后后缀，文件夹处理全名。查找替换可修改后缀；115后缀变化使用原文件SHA1秒传新建，核验新文件身份后才将原件移入回收站，不回退普通上传，不自动重放未知写入。
- 内联重命名铺满名称列，工作台目录图标与操作区尺寸对齐；单项改名使用新ID/PickCode继续预览。收藏栏展开时按钮持续高亮；访问历史改为点击开关，保留空态、键盘及手机菜单边界。

## 任务中心与CAS

- 任务面板移除统计横条，已知总量按真实处理量显示进度；本地CAS哈希按实际读取字节推进，未知总量不伪造百分比。
- CAS目录生成保留所选源目录的末级名称，例如源`/139/剧集`、生成位置`/家庭影音`，实际输出到`/家庭影音/剧集`。根目录不额外包层，旧平铺产物不自动迁移或删除。
- 新增默认“智能计算”：原生移动媒体使用已有有效SHA256，本地及其他远程源执行完整计算；远程正文沿用两槽、暂存及完整性保护。已有有效`.cas`和`.cas.strm`以其内容为准，不随计算选项裁剪特征。
- STRM、CAS、ED2K和目录缓存保护实际源目录、内容及会影响它的上级，生成任务同时保护实际输出；不相关兄弟目录和不相交任务不因同池被全局禁用。无法核验目录时仍拒绝操作，冲突气泡说明运行任务的类型和名称。
- 执行中的任务卡片可以查看完整配置，但不能修改或保存；本次查看不会因任务结束自动变成可编辑。

## 分享与虚拟链库

- 链接转存目录池固定三行、两字头像和浅品牌色；新增按30条分页的转存记录，区分浏览器、Bot、计划和手动来源，不将仅接受回执显示为确认成功。
- 移动、夸克的单文件夹分享支持活动链接。目录默认更新周期7天，可设0至365天，0禁用；逐条Cron可留空停用，非空相邻至少12小时。后台更新保持分享层级、只补目标缺失文件，不因浏览器关闭取消执行。
- 活链支持执行、编辑和删除；保存目录改名读回确认后同步关联记录。“移除记录”仅停止跟踪，“确认删除”同时删除已核验的保存目录及内容，均保留未知写入防重放与配置修订保护。
- 夸克编辑窗口按分享链接/名称、生成位置/目录名称、Cron/级联清理排列。仅在标记缺失且完整核对原归属清单、摘要和目录身份时恢复标记；外来或改变的标记、未知及外改文件仍拒绝，失效到期删除不自动恢复标记。
- STRM内容替换移除固定10000项扫描上限，保留流式读取、深度、大小和执行时限。预览改为独立列表，最多展示100条样例，支持单行省略、静止300ms全文提示及隐藏滚动轨。

## 上传与传输

- 115分片上传补充顺序分片、SHA1和OSS UA初始化参数；禁止上传及缺失/超限额度在正文和秒传提交前拒绝，保留原16MiB分片、取消和失败中止、合并回调确认。
- 上传、备份失败明确区分权限、摘要、秒传、票据、分片初始化/上传/合并及回调等阶段；安全日志保留可定位原因，不泄露凭据、签名链接或上游正文。旧泛化日志不能据此反推现场唯一根因。
- FUSE传输句柄绑定服务生命周期，实际发布只合并当前回调和任务取消，避免旧请求取消污染后续写入。挂载仍受只读、UID/GID、暂存、空间和云端权限约束，不需要额外上传端口；LitePan的42069用于BT而非FUSE。
- 传输筛选改为圆角漏斗图文按钮和逐行菜单，状态图标在左、选中勾号在末尾，保留多状态选择、键盘及临时筛选重置。

## 插件与界面

- 代理配置从我的插件移入账号安全，与账户配置平行展示并独立保存；沿用既有加密凭据和代理用途。统一115插件标题及静止300ms功能描述，媒体扩展名移除漫画快捷组，手动输入及“保留扩展名”的快捷组不受影响。
- 秒传记录区分“失败跳过”和已确认的“失败删除”，全文提示按480px/视口宽度排版；监控记录弹窗加宽并隐藏滚动轨，说明图标位于勾号左侧。
- 秒传主记录、监控记录和档案的数字跳页统一上下界回正、空值提交恢复及总页数收紧，输入本身不触发跳转请求。
- 统计数字在1500ms内由快到慢落值；相邻汉字显示增加0.1em留白，不改变原文、复制、搜索、输入值或汉字与字母交界。
- 日间页面采用雾蓝灰底色、侧栏稍深，内层逐级至纯白；关于以太的侧栏始终使用夜间配色。侧栏右上圆角外露区域跟随面包屑顶栏。
- 夸克存储卡片仅显示接口明确提供的VIP、SVIP、SVIP+、88VIP或迷你VIP；失败或未知状态不猜测会员等级。

## 验证与升级边界

各模块开发期间运行了独立Go与Chromium/WebKit专项，首失败、修复和每轮结果分别保留，不合算为完整套件通过。最新重命名专项20项Go顶层、50项前端单元、23项Chromium及补拍面板的独立1项通过；生产构建、Go vet和Windows/Linux amd64无CGO构建通过。

Windows WebKit重命名七项首轮及独立复核均为3通过、4超时，原因未确认；此前截图或trace归档异常也未统一解决。没有放宽45秒用例/5秒断言或关闭诊断。此次发布前不宣称完整Go、race或完整浏览器套件已重跑通过，远端CI须独立确认。

升级保留原`/config`和`/data`，不自动改写已有CAS计算选择或搬迁旧产物。真实云盘秒传、上传、Bot、会员、NAS/Docker、FUSE及实体iOS仍需部署验证。源码推送不等于CI完成或GHCR镜像已更新。
