# v0.3.8

## 音乐播放

- 新增右侧音乐播放侧栏：曲名下方为可点击、拖动和键盘调整的进度条，显示格式及实际解析到的 kbps；提供顺序、循环、随机模式、上一首、播放/暂停、下一首和歌曲列表，单曲禁用上下首。
- 同目录当前筛选和排序后的音频形成队列，顺序播放到末尾停止，循环回到首曲，随机避免相邻重复。侧栏收起或切换管理页面不中断播放，关闭或退出登录停止。
- 显示内嵌封面、标题、艺人、专辑与歌词；同目录同名 LRC 优先，封面可回退同名图片或 cover/folder/front 图片。封面向上下高斯模糊延伸，点击切换完整歌词页，歌词按时间高亮并支持点击跳转。
- 点击其他区域收起为可拖拽的侧边悬浮胶囊，松手停靠左/右边缘，点击重新展开；提供键盘移动方式，适配桌面、手机、短屏和减少动态偏好。
- 标签通过管理员鉴权的受控 Range 接口有界读取，切歌或关闭取消旧请求并释放封面资源；不自动联网补歌词，不新增音频解码器，格式支持仍取决于浏览器，无法读取的码率不伪造。

## 读取与分享

- 修正 115 下载响应票据的 CDN 主机与路径绑定，保留下载所需请求头并隔离登录 CK。DAV/FUSE 读取遇到 401/403 时仅重新取链一次，保留读取偏移，不重复写入，不输出敏感直链或凭据。
- 修正移动分享目录协议，不把 nodNum 当作当前目录分页总数；保留完整性、唯一性与数量限制，避免误报“分享列表分页不完整”。
- 登录后的分享链接监听识别 115、夸克和移动链接，填入分享转存窗口但不自动执行；遵循浏览器剪贴板权限，拒绝时不持续提示，弹窗与文本编辑期间避让，退出后清理监听。

## 界面整理

- STRM 海报选择态使用左上勾选、整卡细描边与轻微悬浮放大；底部居中胶囊 Dock，打开其他弹窗退出选择状态。
- 通知时间精简为月日时分，调整通知图标与细滑块；上传图标补齐底部框，日志时间使用独立颜色。
- 系统日志筛选不持久化，通知跳转的临时日志定位离开页面后清除。
- 重命名工作台使用间隔条框、细滚动条与固定底部规则集区；“新”标记为绿色，名称变更片段为橙色。调整存储目录选择路径、搜索及新建按钮对齐。
- 调整星空密集星带、星旋自然渐淡与左下深色陨石漂移，登录和关于页面同步。

镜像仍仅构建 linux/amd64。真实网盘账号、Linux 内核 FUSE、媒体库及全部专有音频编码未联调；本地回归不能替代现场风控与权限验证。远端 CI 和镜像结果以 GitHub 实际运行结果为准。
