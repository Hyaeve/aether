# v0.4.1

## 模块配置

- 改用固定名称 JSON：`/config/storage`、`task`、`link`、`tool`、`file`、`transfer` 分别保存各模块配置，任务按类型、工具按插件拆分，不再以长摘要作为日常配置文件名。
- 普通配置可读，CK、Token、上游密码和 API Key 等字段使用 AES-256-GCM 加密；登录密码保持加盐哈希。模块完整性校验防止篡改，启动后从内存读取配置，未变化模块不重复写入。
- 支持旧加密快照迁移、未完成保存恢复及外置主密钥；内置备份在目标主密钥下重新加密。旧文件保留但不再同步，缺失或损坏的新配置不会回退过期快照。详见[配置说明](../configuration.md)。

## 分享链接与访问历史

- 已授权且处于前台的管理页面定期检查剪贴板中的 115、夸克和移动分享链接，进入对应转存窗口；账号菜单增加授权及重试入口，不自动执行转存。
- 非安全 HTTP 或拒绝权限时提示 Ctrl+V 后备，编辑中及其他弹窗打开时不抢占操作，退出登录取消迟到请求。
- 修复异步目录加载覆盖最新访问历史的竞态，补充延迟响应回归，修正上一版本 CI 的历史访问测试超时；未提高测试超时或跳过测试。

## 115 本机读取

- 修正下载请求头仅保留响应票据、丢弃认证 CK 的处理：仅向官方 HTTPS、默认端口的 115 下载域名保留驱动返回的必要认证 Cookie，跨域跳转继续清除凭据，不将 CK 返回浏览器。
- 内部取链与文件读取使用一致的普通浏览器 UA，API 与读取复用默认传输层；播放请求仍使用客户端 UA。WebDAV、本地挂载保持服务器代理读取，备用接口仍只尝试一次，不重放写操作。详见[读取说明](../115-reading.md)。

## 验证与边界

- Go 全量、静态检查、Linux amd64 编译及浏览器回归验证；镜像仍仅构建 `linux/amd64`。
- 真实 115 账号及 Linux FUSE 内核未联调，需部署后用原失败文件确认，不能将模拟 CDN 测试等同于现场读写恢复。
- 浏览器剪贴板受 HTTPS、安全上下文、焦点和用户授权限制，不能保证普通内网 HTTP 或后台页面自动监听。
