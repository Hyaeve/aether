# v0.4.4

## 会话与文件管理

- 当前浏览器会话恢复文件管理的完整目录和各模块最近栏目；新会话仅恢复长期保存的存储池、排序和视图偏好。
- 历史访问菜单加宽，显示无框存储图标、分色存储名称和优先保留最深目录的路径。
- 文件详情改为文件视图内的右侧抽屉，统一文字与数字字号，保留位置、115 CID 复制和多选统计概览。
- 刷新目录清除其直接子目录的大小统计缓存，不自动遍历重算；再次查看详情时计算，并拒绝刷新前的迟到结果写回。
- 无任务时的圆角面板延伸到页面底部。

## 传输与联动

- 面包屑上传、下载速率可点击直达对应传输栏目，箭头略加粗并保留速率颜色。
- 传输任务采用固定表头和虚拟列表，新增大小、实际速度和分色状态；先滚动页面头部，再滚动任务列表，空列表不产生额外页面滚动。
- 已知总量显示实际百分比，未知总量显示已传输字节，不使用往返晃动的进度条。速度为各条任务最近两秒的平均传输速率。
- 成功记录从完成时保留一分钟，失败记录保留三天或手动清除；成功记录不跨服务重启保存。
- 联动列表展示名称、箭头流程、上次结果、下一次执行及操作；流程悬浮展开，三点菜单支持编辑、启停与删除，停用条目灰显。编辑窗口采用标准宽度。
- 联动上次结果保存到 `/data/runtime/state.json`，不写入配置文件。

## 活动通知

- 分享转存批次结束后进入活动通知，附带存储图标、提交或完成数量及同名跳过数量，可点击跳转关联日志。
- 夸克仅在最终任务确认完成后显示完成；115 和移动未提供完成查询的路径明确显示已提交，不将提交冒称为完成。
- 通知按分享预览去重，最多保存 200 条，重启可恢复；不保存分享链接、提取码或 CK。

## 验证边界

发布版前端构建、155/155 Playwright、Go 全量测试、go vet 和 Linux amd64 测试交叉编译及构建通过。真实云盘账户与 Linux 内核 FUSE 未现场联调，不能将本地测试通过等同于远端镜像构建成功。本次不包含新的 115 现场 403 修复。镜像仍仅构建 linux/amd64。
