# v0.7.8

## 转存与播放

- TG 选定转存目录后先读取分享名称，再一次性展示确认消息。移动和夸克优先读取分享标题，115 只请求少量根目录元数据。取名最多等待 1.5 秒，超时后仍可返回或确认。完整扫描和转存由后台任务执行。
- 115 链库首次播放使用独立的转存准备时限。提交响应不明确时，同一次播放请求继续检查临时副本。票据暂未就绪时进行有限次只读重试。阶段日志可定位目录读取、转存确认或取链失败。

## 媒体与刮削

- 媒体面板横幅自动轮播，支持悬浮或点击切换。资源推荐的演员卡加入悬浮动效，更新动漫和榜单图标。
- 剧集和电影订阅的搜索框与栏目同行，空列表延伸到页面底部标准间距。
- 刮削平台按栏目记住所选来源和目录。链库按保存目录名称显示，并在列表提供重置与识别。刮削设置的保存按钮位于面板右上角。
- 分享卡片的级联删除与链库刮削选项同行。115 生活事件的说明移入提示图标。
