# v0.3.6

## 刮削工作台

- 匹配后按刮削设置写入元数据并刷新海报，成功作品优先显示新生成的海报，避免旧 cover 遮盖。候选结果采用横向海报卡片，搜索由回车或搜索按钮触发。
- 刮削范围改为可折叠目录勾选树，默认全选，可排除子目录。识别 STRM 库增加二次确认。
- 支持右键进入选择、分段 Shift 多选及底部 Dock 全选、清空、重置、识别；Esc、刷新或离开页面退出选择。海报操作按钮圆角化并增加悬浮上浮效果。
- **Dock 重置会删除所选独立作品目录下的所有非 STRM 文件，包括封面、NFO 和用户其他文件，不可撤销。** 删除前检查共享目录、未选中或未索引 STRM、符号链接等；保留 STRM 与目录。原单作品重置仍只清匹配记录，不删除磁盘文件。外部并发修改及部分删除失败不提供事务回滚。

## 文件与存储

- 图片预览支持缩放、拖动、旋转、切图和适应窗口；视频采用贴合画面的原生播放器，网格可读取浏览器可解码视频的缩略帧。音频双击打开右侧滑入的原生播放窗口。
- 压缩包单选菜单在下载下方增加解压，支持 ZIP、7z、RAR、TAR 及 gzip/bzip2/xz 包装；库支持的加密格式可输入密码。纯 Go 解码，校验后复用存储上传，不覆盖已有内容。输入 10GiB、输出 20GiB、10000 项、64 层、30 分钟限额，一次处理一个包。
- 解压暂存位于 /data/cache/extract，正常结束清理；云端失败可能保留已写入文件，异常退出的暂存需清理。第三方解码器不是资源隔离沙箱，容器仍应配置内存限制。
- 移动存储编辑窗口新增扫码获取 Authorization，授权后手动保存。115 分享预览使用完整浏览器 UA，仅固定接口返回 405 时尝试一次只读备用接口，不重放转存提交；成功提交后导航到转存目录。
- 文件悬浮高亮弱于选中态；重命名预览保留绿色新名称，仅变化片段标橙色。

## 通知与星空

- Emby 通知标题优先媒体库名称、其次服务端名称；计划任务展示任务与完成时间，播放事件展示用户、作品及 SxxExx，不添加电影或电视剧前缀。缺失字段不伪造，重复或不同用户播放保留通知。
- 通知可点击跳转系统日志并筛选对应通知 ID，旧记录按名称回退；已删除日志无法恢复。清除按钮收小，保留极细滚动条。
- 陨石缩小并增至七个，在左下方缓慢漂移；双星旋中心增强、外围亮度渐变更平缓，登录与关于页面同步。

## 验证与限制

- 发布前已通过 88 项完整 Playwright、相关专项复验、Go 全量测试、vet、前端构建及 Linux amd64 测试交叉编译与构建。
- 浏览器媒体支持取决于实际格式和编码，不新增音频/视频转码。真实云盘解压、加密 RAR 实物、扫码账号、分享风控、Emby/TMDB 及 Linux 内核 FUSE 未联调，不宣称全部现场问题解决。
- 镜像仍只构建 linux/amd64；不修改用户配置、数据及正在运行的服务。远端 CI 结果需以 GitHub 工作流实际运行结果为准。
