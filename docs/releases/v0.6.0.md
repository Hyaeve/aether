# v0.6.0

本版从用户指定的 v0.5.6 基线重新开发，发布当前完整源码，不合并 v0.5.7 至 v0.5.9 的历史提交。经仓库所有者明确授权更新 main；既有发布标签保留，不改写旧版本。

## 主要变更

- CAS 任务按输入框自定义扩展名筛选，不再限制为音视频；修复导入重复追加后缀。独立 CAS 使用六字段缩进 JSON，通用 CAS STRM 只保留特征和签名，文件管理可只读查看 CAS。
- 天翼 CAS 采用 OpenList PC 的初始化、秒传检查和提交协议，补齐请求参数；缺少分片大小时按文件大小动态兼容。移动/天翼播放保留有效临时副本复用和兼容类型间的一次回退。
- 分享转存按云盘类型在服务端记忆目标存储池，按池记忆目录；目录窗口可选择同类型全部可用池，跨浏览器和重启保留。慢网络下重新打开弹窗会等待前次目标保存，不自动执行转存。
- 分享准备与执行气泡显示目标池和简要名称，确认成功后保留十秒并可进入目标目录；只确认提交的结果不误报成功。
- 分享栏、云下载和回收站采用分页虚拟列表，只计已加载项；选择高亮、批量终态记录清理、六位回收站密码及旧四位配置兼容载入完善。
- 辅助工具卡片统一标题、副标题和独立功能描述的位置。夸克 STRM 接管明确作用于本项目生成的夸克播放链接，按有效绑定和策略返回 TV 版 302；普通下载与挂载路径不变。
- 音乐与视频共享竖向音量控件，完善播放队列、键盘操作、字幕、音轨及视频信息。浏览器不支持音轨切换时如实说明，不伪造实时网速。
- 备份与115监控复用五组扩展名快捷按钮和输入校验；完善任务表单、目录输入、历史悬浮、系统日志刷新和日夜主题布局。
- 恢复标签图标原绘形并提高资源画布尺寸；WebDAV ISO 使用通用可寻址二进制类型，增加脱敏读取诊断。

## 升级与边界

- 升级前备份 `/config`、主密钥和需要保留的 `/data`。分享目标配置位于 `/config/state.json` 的 `shareTransferPreferences`，不保存剪贴板原文、分享链接或提取码。
- 已有 STRM 不自动重写，签名密钥仍须保留；自定义文件扩展名不代表客户端可以播放任意格式。
- 回收站新密码须为六位数字；旧四位配置不会阻止启动，但须更新后才能执行清理，不自动补零或猜测密码。
- 不绕过云盘授权、会员权益或浏览器剪贴板限制。移动创建分享和未接入云盘回收站不伪造支持。
- 本地回归与模拟接口不代表真实云盘、iStoreOS/FUSE/NFS、TCL ISO 或 Docker 部署验收；现场性能问题仍需目标环境验证。
