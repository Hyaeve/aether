# v0.6.8

## CI 测试与构建

- 修复 Go 测试集中在单个包进程、整套累积触发10分钟默认超时的问题。CI 将完整竞态测试确定性分为8片，子测试随父测试完整运行，跨包同名测试进入同片。
- 保留 `-race`、原包级超时和全部业务断言，不使用 `-short` 或新增跳过。每片运行后核对发现清单与实际结果，缺失、重复或意外多跑均报错；原有平台环境跳过规则不变。
- 任一片失败不会取消其他片的诊断。全部 Go 分片与前端验证成功后，才能构建和发布镜像，不以普通测试替代竞态检查。
- 每片始终上传测试发现、分配清单、Go JSON 与错误输出，保留超时堆栈、断言或竞态报告。运行方法见[测试与 CI 诊断](../testing.md)。

## 验证与升级

- 本地完整分片覆盖800项：799通过、1项原有Linux FUSE环境跳过，无遗漏或重复；28项脚本及前端单元通过。这些为Windows普通测试，不冒充Linux竞态测试已通过。
- 不改变 Go/Vue 业务行为、云盘协议、配置、运行态或媒体文件，不新增依赖。保留现有 `/config`、`/data` 和主密钥。
- v0.6.7标签保留，不改写已发布历史。新版本源码推送、远端 CI、GHCR镜像及部署验收分别确认，不能仅凭本地通过认定镜像已可拉取。
