# v0.4.13

- CAS/ED2K统一完整媒体文件名加`.cas.strm`/`.ed2k.strm`，移除保留扩展名选项；新增完成动作，默认保留源文件。删除模式按成功产物、元数据复制及源内容校验逐项清理，失败、跳过和新文件保留，本地只清理空子目录。远程空目录因缺少原子判空删除接口保留，不保证外部并发写入的跨服务事务。
- 其他远程存储CAS下载至本地暂存后计算双哈希与切片特征，跨任务最多两个文件同时处理；取消、失败清理暂存。移动/天翼继续使用有效上游哈希，115 ED2K读取也共享远程并发上限。
- 系统传输设置保留等宽两列，速度限制下方增加临时文件位置与目录选择，全局忽略扩展名横跨下方整行；有效输入自动合并串行保存，失败保留输入并提供重试。临时位置用于远程哈希、备份、上传和挂载写入暂存。
- 分享解析树支持目录及文件选择；三网盘每批严格小于500项（499）。夸克分享会话复用同一令牌并接续同源Cookie轮换，403按失败阶段报告，不自动重放转存请求；真实扫码账号仍需现场验证。
- 新增115虚拟链库，分享STRM包含分享码、访问码、文件ID与名称，临时播放复用115绑定池；新增STRM常规/正则替换预览、变更数量与执行确认。详见[虚拟链库](../virtual-library.md)。
- CAS/ED2K解析生成目录按浏览器、账号与类型记忆；历史重命名目录选择器固定宽度，最近目录排序及历史持久化说明；标签页logo放大、筛选最大最小名称和传输设置图标调整。
- 剪贴板声明标准宽度、10秒及阅读到底双条件确认；双星璇随机位置与大小、任务卡片和主题栏目、环状图与绑定池动画等交互细化。
