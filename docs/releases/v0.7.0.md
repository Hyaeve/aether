# v0.7.0

本版扩展通知渠道，并合并 v0.6.9 之后的复制诊断、115 监控、STRM 格式、链库统计及导航调整。

## 通知服务

- 消息配置新增 QQ 官方机器人和飞书群通知，支持独立保存、测试、默认隐藏凭据及管理员按需显隐。QQ 使用 AppID、AppSecret、群 OpenID；飞书使用官方 Webhook 和可选签名密钥。
- QQ、飞书启用后异步接收普通任务和备份的成功、失败、停止结果。队列有界，配置变化停止旧目标，未知回执和重启不自动重发；不新增 QQ、飞书指令或链接转存。
- 宽屏按 QQ Bot、飞书通知、TG Bot 三列排列，企业微信在下方占两列；企业微信移除字段问号，桌面两列或三列输入，窄屏按空间调整。消息配置栏目使用消息气泡图标。
- 最近通知时间与标题同行靠右，保持灰色和完整分钟时间；长标题省略，详情保留在下方。

## 传输与115秒传

- 跨存储复制、移动失败日志补充具体项目、预检、取链、暂存、本地写入和发布、目标校验等阶段，以及安全的 HTTP、磁盘、权限和网络原因。旧日志中缺失的原因无法事后补回。
- 总复制进度按真实暂存字节更新，不重复累计目标写入；其他未知总量进度取消往返动画，不伪造百分比。
- 监控新增失败后“删除”：与传输策略同样按 10、30、60 分钟重试，第三次重试仍明确未命中后，核验源身份、内容和配置才处理单文件。删除需二次确认，变化、取消和结果不明时保源。
- 带重试的监控 Cron 间隔严格大于 120 分钟；旧短周期可载入但暂停，避免启动循环。手动与监控独立执行，同文件仍防止重复提交。
- 秒传记录固定窗口、每页30条，提供首页、末页和页码跳转；PickCode 完整展示，按真实摘要和上传字节显示阶段进度。

## STRM与链库

- 115 带名称链接改为 `/d/账号ID/纯pickcode/完整文件名`，文件名采用标准路径段转义，不在 PickCode 后附媒体扩展名。
- 系统 STRM 配置新增“STRM覆盖模式”，默认直接跳过，可选覆盖生成；只影响普通 STRM，独立于任务全量/增量，不改变 CAS、ED2K、元数据及虚拟链库策略。
- 夸克链库概览采用 CAS 同款统计和设置入口；修复固定 `/Aether/Share` 创建后可见延迟及可信 Cookie 接续，不新增临时目录配置，不重放不明确的云写入。
- 缓存设置、CAS/ED2K绑定池、115秒传中心、夸克链库设置及备份设置不再成为侧栏恢复页，切换后进入对应返回栏目；普通栏目、目录记忆和浏览器历史保持。

## 升级与边界

- **旧 115 扩展名 PickCode、`?/名称` 及无账号格式不兼容，返回404。** 不自动改写旧文件或删除旧索引；需要更新时选择覆盖生成并重新执行普通 STRM 任务。
- QQ 官方主动群消息受平台权限、群 OpenID、IP 白名单及额度限制；飞书需正确配置群机器人与签名。平台拒绝、未知回执和网络失败不冒充送达。
- 新渠道默认停用；凭据加密保存，飞书 Webhook 同样按秘密保护。真实账号送达、云盘写入、NAS/FUSE/NFS、Docker及实体 iOS 仍须部署验收。
- 本地专项、普通 Go、浏览器回归、Linux 竞态 CI、镜像发布和用户验收分别记录。推送成功不等于镜像构建或部署已通过。
