# v0.3.9

## 配置与任务

- 配置按模块加密保存在 `/config/storage`、`task`、`link`、`tool`、`file`；STRM、CAS、ED2K、缓存任务分别保存，WebDAV及本地挂载分别保存。兼容旧主配置与旧工具快照迁移，保留加密备份导入导出及原子提交。
- 空 Cron 不再自动补每日整点计划，仅手动或联动触发；已有非空计划保持不变。
- 新增最后一个“联动任务”栏目，支持手动/定时/任务成功后触发及有序任务、缓存刷新、延时动作，按上一步结果执行，可停止并防止内部触发循环。未接入参考项目全部动作类型。
- 栏目溢出时横向滚动、隐藏滚动条，优先保证右侧按钮显示；溢出标签区域滚轮在两端不传递到页面。

## 文件与仪表盘

- 分享转存选项仅支持的存储显示，修正移动分享官方分页字段及子目录路径，超过100项继续读取；同名目录合并、同名文件跳过，不覆盖。
- 文件搜索输入即时筛选当前目录，回车深度搜索当前及子目录，保留结果路径和虚拟列表，迟到结果不会覆盖已切换的目录。
- 仪表盘新增真实缓存命中图、最近活动和前六个存储快捷入口，无滚动条查看后续存储。

## 验证与限制

配置迁移、加密恢复、失败回滚、空 Cron、任务排序、联动顺序/条件/取消及分享分页/合并均有回归测试。真实移动、115、夸克账号未联调；异步分享转存完成与网盘风控以实际服务结果为准。请备份整个 `/config` 后升级，不只备份主索引文件。镜像工作流保持仅 linux/amd64。
