# v0.3.3

## FUSE 与 STRM

- 原生 go-fuse 接入4 MiB分块磁盘读缓存，目录为 /data/fuse_read_cache，已有映射可直接使用。10 GiB容量上限、LRU、7天闲置过期、并发合并、校验损坏重取及缓存盘失败回退。
- 本地文件和写句柄绕过缓存；Aether写入和手动目录刷新使旧块失效，缓存命中不计为上游下载。重启首次读取清理旧缓存，不跨重启复用。
- STRM任务更多选项新增刮削参与选择，与保留扩展名同行；旧任务默认参与，不参与任务不作为刮削库。视频与元数据快捷图标更新。
- 刮削作品增加子目录筛选，保留跨季归组，支持括号数字分集及tvshow.nfo证据，海报操作悬浮显示。

## 分享、插件与界面

- 115分享预览对齐当前115driver接口及Referer，区分预览/转存错误；115读取增加Chrome302后的受控备用接口，不自动跟随携带凭据的重定向。
- 夸克接管窗口按LitePan布局重排绑定列表和播放设置，支持分流名单与解绑确认。
- 115同播绑定窗口简化，目录选择新增面包屑与新建目录确认；重命名工作台紧凑化及橙色新名称。
- 最近通知显示一天内记录，无则最近五条，修正Emby图标和细滚动；传输隐藏完成项，失败保留三天并可手动清除。
- TMDB匹配语言和请求间隔、代理可选账号密码；文件双击菜单、星团和陨石外观调整。

## 验证边界

- 缓存明文保存媒体数据，请保护缓存目录。远端无修改时间的同大小替换需手动刷新；不提供远端强一致或缓存备份保证。
- 真实115/夸克账号、Linux内核FUSE和Docker挂载未联调；上游授权/风控错误不能由读缓存消除。
- 镜像工作流仍只构建 linux/amd64。
