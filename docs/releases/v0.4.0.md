# v0.4.0

## 工作台与文件浏览

- STRM 刮削保留虚拟海报列表，收紧海报及底部信息，以星光状态点区分匹配、刮削与错误状态。选中描边增加蓝紫光晕，清空退出选择，悬浮操作改为图标文字磨砂按钮，范围和设置窗口统一加宽。
- 已扫描的作品索引与封面短期复用，封面按作品探测而非逐集读取；生成任务执行、设置变更和刷新使缓存失效。外部修改未触发任务时，可手动刷新，缓存最长五分钟。
- 文件管理新增浏览器访问历史，保留最近五条，祖先路径合并到最深目录，兄弟路径分别保留，支持跨存储跳转。
- 重命名比对行和规则更紧凑，两侧增加圆角边界及细滑块，原名称浅色、新名称正文色，只有变化片段标橙色。日夜输入框与外层面板采用分层明暗。

## 辅助工具与存储

- 夸克 STRM 接管添加绑定自动选择首个可绑定存储并获取二维码；没有存储或均已绑定时提示。空绑定仍显示播放设置，扫码保留同账号校验及第三方授权告知。
- 调整 Emby、夸克接管及115同播复制图标，简化 Emby 描述，复制目录与存储名称对齐；STRM 替换字段改单行输入。
- 检查镜像更新失败时仍显示当前版本。星空陨石分布扩展到左、下、右侧。
- 115 Android（新版）CK 使用 Android 下载接口，读取拒绝后仅一次只读接口回退，保持 UA 与下载票据隔离。天翼扫码补齐时间戳和设备指纹。

## 备份规则

- 传输中心实装备份规则，支持源/目标存储目录、同名跳过或覆盖、名称/扩展名/大小过滤、手动或 Cron 执行、停止与进度；规则加密存于 `/config/transfer`，纳入配置备份。详见[备份规则](../backup-rules.md)。
- README 精简为模块功能与部署概览，离线下载栏目字号统一。

## 验证与边界

- 本地 Go、前端及浏览器回归验证；镜像仍仅构建 `linux/amd64`。
- 夸克公开二维码接口可返回图片和扫码令牌；真实账号授权/播放、115现场 FUSE读取及天翼扫码仍需部署验证，不将界面或模拟测试等同于真实云盘联调。
