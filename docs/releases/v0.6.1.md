# v0.6.1

本版在 v0.6.0 基础上修复三项浏览器时序问题，并调整 STRM 刮削海报墙。不合并此前排除的历史提交，不改写既有发布标签。

## 修复

- 视频缩略图等待浏览器实际呈现帧后再绘制，避免媒体事件已触发但捕获到黑帧。保留旧浏览器降级、取消及迟到回调保护，不以颜色规则排除真实黑色视频。
- 字幕轨道加载时，按钮禁用导致失焦不再关闭鼠标仍悬浮的菜单；内部焦点移动也不会误关，保留移出容错。
- 文件详情的关闭状态与退出动画分离，快速重新打开时不再被旧退出回调关闭。多选统计公式保持不变，焦点恢复不改变页面位置。
- 浏览器回归使用固定生成的 VP8 素材，排除运行时录制首帧差异；保留原像素、数量和点击断言，未增加超时、跳过用例或关闭诊断。

## 海报墙

- 桌面每行最多 7 张海报，海报保持 2:3 比例，窄屏按可用空间减少列数。
- 虚拟滚动行高跟随海报尺寸，悬浮操作锚定海报底部；修复平板宽度下工具栏溢出。

## 验证与升级

- 修复前新增三项回归均复现失败；修复后相关专项连续三轮 63/63 通过，完整浏览器回归 326/326 通过，另有截图稳定性专项 3/3 通过。
- 本地验证不代表 GitHub Actions、镜像构建或用户部署验收已通过，远端结果以本次发布触发的工作流为准。
- 无配置或运行数据迁移，不自动重写现有 STRM，不修改云盘接口或工作流验证门槛。真实云盘、Linux 浏览器、Docker、FUSE/NFS 与播放器现场联调未在本地执行。
