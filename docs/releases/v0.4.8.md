# v0.4.8

## CAS 通用特征与绑定池

- 新 CAS 任务不再绑定账号，生成 `.cas.strm` 同时保存 SHA256、MD5，缺少的字段留空；已有 `.cas`、`.cas.strm` 可按原名称和相对目录结构重新生成。
- 独立移动、天翼存储绑定池支持多账号时间窗口轮换、优先类型及各自临时文件保留时间。播放优先复用池内仍存活的秒传文件，不上传媒体内容。
- CAS 页新增成功率环图、执行进度、成功生成和异常数，以及滑入式绑定池。配置位于 `/config/task/cas-pool.json`，计数与临时文件追踪仍在 `/data`。
- 无有效特征的源文件跳过并批量记录日志。旧已绑定的播放链接继续兼容；新链接需要配置绑定池，迁移仍需保留签名密钥。

## 备份与交互

- 备份筛选改为图标规则类型选择，新增路径前缀和路径正则。规则支持黑白名单、文件/文件夹范围、关键词标签及默认关闭的区分大小写；扩展名自动去点并小写化。
- 空备份窗口可添加规则，顶栏去除刷新，编辑窗口隐藏内外两层滑动条，保留短屏访问设置的滚动能力。
- 全量重置移到编辑下方；任务非按钮区域点击编辑，短长按拖拽时卡片跟随指针。任务、存储、以链和挂载复用拖拽反馈；更多选项展开自动滚动，菜单字号统一。
- 缓存环图和统计右移并增加圆角边框；刮削状态增加方形、三角形等形状，保留“未匹配”和“待确认”的实际识别结果含义；系统日志条纹变浅。

## 滚动与部署

- 文件管理与直链缓存：下滑先滚页面、再滚条目；上滑先滚条目、再滚页面，窗口内外保持同一顺序。刮削和日志恢复正常整页虚拟滚动，面包屑固定。
- FUSE 磁盘缓存只在 `/fuse_read_cache` 实际映射时启用，不再使用环境变量控制；Compose 服务名改为 `aether`，README 保持同一部署示例。
- 修正备份浏览器回归等待动画完成时可能永久挂起的问题，轮询当前有限动画状态，不提高测试超时、不跳过测试或关闭追踪。

## 验证边界

真实移动、天翼账号秒传与 Linux FUSE 内核未联调，Windows 本机缺少 cgo/gcc，未运行 race；不宣称现场云盘问题已经消除。推送成功不等于远端 Actions 或镜像构建已通过。
