# v0.5.6

本次发布纳入此前完成但尚未推送的云盘管理、CAS、挂载读取及界面改动。

- 视频使用自定义控制栏：空格播放/暂停、上下键调整音量，上一集/下一集按当前目录显示顺序切换，首尾按钮置灰；进度条位于按钮行上方，字幕位于音量左侧。窗口外点击不关闭；全屏Esc返回窗口，再按Esc关闭。保留全屏切换、手机尺寸与焦点恢复。
- 内置文本字幕支持FFprobe探测、FFmpeg转WebVTT，按播放位置分段加载；ASS样式简化为文本，图片字幕暂不支持。服务端需要FFmpeg/FFprobe（Docker镜像已有），读取/输出/并发/时间均受限；不会承诺所有视频编码都可在浏览器播放。
- 存储管理新增分享列表、云下载及回收站；开放已核对的115和夸克能力，无可靠接口的网盘操作明确不支持。115回收站计划清理、一池一规则、加密PIN、保留天数及总控启停。
- CAS仅本地导出，三哈希及分片大小占位、导出FIFO队列与进度气泡。天翼要求完整MD5和分片MD5；本地计算与缺省导入按OpenList天翼PC动态分片规则，明确大小原样保留。
- 115本地挂载复用有界连续响应及预读，降低每4MiB重连风险，保持每池两路、每文件50MB/s；传输生命周期写入持久系统日志。尚未验证真实115/FUSE/NFS现场掉速。
- 音乐逐首点播加入队列与移除切换、共享筛选明暗层级、目录输入及空提示、默认本地挂载0755、容量条统一、存储启停通知、浏览器图标放大及350ms访问历史悬浮。

验证：完整Playwright 283/283通过（12.3分钟），最终视频专项11/11通过（28.6秒）；Go全量通过（核心包336.397秒），字幕/动态分片/日志专项连续三轮通过，14项前端单元、2项版本脚本单元及版本一致性、生产构建、vet、Linux amd64测试编译及构建、diff通过。测试录像改为录制前绘制首帧，避免黑色首帧造成缩略图像素断言波动；未放宽断言或超时。内置SRT字幕真实FFmpeg探测/转换、时间窗及恶意播放列表拒绝均有回归。不包含真实云盘账号、Linux FUSE/NFS和Docker运行联调；Windows未执行race，不宣称远端CI或镜像成功。
