# v0.4.2

## 传输中心备份规则

- 参考 Nestify 的规则行为，编辑窗口分为基本设置、备份规则、扫描规则和筛选规则；支持多源、多目标，每个源复制到每个目标。
- 单源保留原目录结构，多源使用独立目录名前缀并处理同名冲突，保留空目录。完整扫描及重叠校验完成后才写入目标。
- 新增名称、扩展名、正则和带单位的大小筛选，支持黑白名单及文件/目录范围；保留旧规则兼容。
- 支持 Cron、间隔扫描、手动执行、停止、执行详情和默认停用的规则副本；进度区分扫描与复制，重复执行重新计数。
- 规则定义仍保存在 `/config/transfer/backup.json`。这是传输中心的目录备份，不是辅助工具的配置备份；不包含文件监听、源清理、镜像删除、增量扫描或资源队列。详见[备份规则说明](../backup-rules.md)。

## 配置与运行结果

- 任务、联动和备份进度、执行时间及结果，存储/挂载状态、通知和 CAS 临时记录迁移到 `/data/runtime/state.json`；会话迁移到 `/data/runtime/sessions.enc`，兼容旧数据。
- `/config` 保留模块定义和凭据，任务进度不再重写配置；运行数据校验完整性，敏感字段继续加密，保留旧迁移文件。
- 配置导出排除运行数据，导入避免旧运行结果覆盖导入内容；需要保留历史和会话时，请同时备份 `/data` 和主密钥。详见[配置说明](../configuration.md)。

## STRM 刮削与夸克接管

- 刮削工作台刷新在即时搜索左侧，右侧切换海报墙/文件夹视图，按浏览器账号保存选择；文件夹视图使用虚拟列表、可点击路径及范围筛选。
- 支持预览刮削图片、查看和编辑 STRM/NFO 内容，增加共用文件图标；编辑受库目录、文件类型、大小及内容版本约束，运行刮削时禁止编辑。
- CAS、ED2K 任务增加 STRM 刮削参与选项，修正识别名称中的指针后缀；统一海报选中描边、星光状态及透明操作按钮。
- 对照 LitePan 处理夸克 TV `32009`：明确提示设备数超限及重新绑定步骤，失败不保存无效绑定，不泄露上游凭据。

## 缓存与界面

- 缓存进度条改为细轨道，显示真实扫描计数和状态；未知总量不虚构百分比。新建缓存任务默认扫描四层，编辑保留旧深度。
- README 恢复完整 Compose 示例，Docker FUSE 缓存独立映射为 `./fuse_read_cache:/fuse_read_cache`，默认不放在 `/data` 下；原生运行默认路径不变，缓存目录加入挂载保护。
- 历史访问排除根目录及第一级目录；重命名只在规则有效时静默更新预览，保留滚动位置并隔离迟到响应。
- 运行任务和备份增加绿色动态描边、轻红停止按钮；调整时间位置、星河宽度、日志/重命名/WebDAV 卡片层级及本机图标日夜配色。
- 云盘卡片异步显示可获取的空间用量，失败回退账号名称，不阻塞首屏；移动存储未接入未经验证的容量接口。详见[空间信息说明](../storage-usage.md)。

## 验证与边界

- 本地前端构建、139 项浏览器回归、Go 全量、静态检查及 Linux amd64 编译验证；镜像继续只构建 `linux/amd64`。
- 真实云盘账号、夸克扫码和容器 FUSE 内核尚未联调，不宣称现场读写或账号限制已经解除。本版本不新增 115 上游 403 修复。
- 升级后若需保留运行历史，请同时保存 `/config`、`/data` 及主密钥；独立 FUSE 缓存可重建，无需迁移旧缓存块。
