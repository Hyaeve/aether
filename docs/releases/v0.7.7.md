# v0.7.7

本版在v0.7.6同版本修复457b3b7之后，新增探索发现、媒体订阅、追剧日历和我的媒体，并纳入此前未发布的链库播放、STRM目录恢复、级联设置和刮削界面改动。

## 探索发现

- 资源推荐提供全部、剧集、电影、动漫、榜单，复用TMDB配置，支持海报浏览、搜索、更多分页、媒体详情和添加订阅。
- 剧集与电影订阅按作品/季去重，支持基础和进阶配置、转存目录、海报背景卡片及确认取消，20项分页并自动回正跳转页码。
- 追剧日历按已订阅季读取TMDB播出日期，提供月份切换、日期筛选和作品日程。
- 资源来源仍为占位，未启动站点爬取、资源搜索调度或云盘自动转存，不伪造订阅完成进度。

## 我的媒体

- 新增媒体面板、内容排行、缺集管理、控制中心。按原顺序复用所有以链卡片，包括停用卡；服务选择和展示媒体库保存在服务端，换浏览器仍可读取。
- 面板最多五张横幅，右下白条可悬浮、聚焦或点击切换；显示最近入库、实际数量、当前播放用户和进度。ABS使用书封、作者/播讲及收听统计，影视服务使用影片和剧集展示。
- Emby及兼容服务按实际播放次数汇总排行，ABS按收听时长统计；缺集仅支持Emby，对照TMDB已播集与本地季集，不将未来集计入缺集。质量统计由用户点击扫描执行。
- 扫描支持取消，分页不完整或范围改变时保留上次结果；结果独立持久化。旧服务请求不阻塞或覆盖新服务，移除当前Emby后回退到剩余Emby。上游不支持的接口如实提示。

## 链库与STRM

- 移动、夸克的卡片扩展名非空优先，空值沿用链库设置；TG新卡写入当时默认值，重复分享不覆盖已有自定义。
- 移动转存直链复用存储池授权，以独占临时目录中唯一、名称及大小相符的实际副本确认完成，兼容任务查询不回显编号的情况；原未知提交不重放及身份保护保留。
- STRM生成目录设备号变化但inode仍匹配时可按认证记录恢复；其他身份变化可由手动全量同步核验恢复。空目录可重绑，未知、外改或无法核验的目录仍拒绝，不生成新的owner文件。
- 普通STRM与四类分享卡的级联删除统一为刮削选项下一行全宽扩展名输入，带图片/数据快捷添加；空值关闭，旧开关配置兼容。只改Cron不会因旧值展示转换而触发额外生成。

## 界面与运行反馈

- 刮削设置成为平台最后一个独立栏目，移除工作台重复设置弹窗；STRM刮削、链库刮削、以太识律图标简化。
- 保留原星空，缓存底图维持原预算，独立轻量流星层逐帧绘制，后台、减少动态及隐藏状态保留暂停/释放机制。
- 成功登录、重新登录和创建管理员均进入信息总览；浏览器首次进入当前版本弹出更新日志，支持叉、知道了、窗口外或Esc关闭并按版本记忆。
- 整理规则改两列，菜单约四项高，洗版与处理并发同行；并发默认1、范围1至3，越界回正，文件过滤MB与步进同位。洗版隐藏长说明和权重，突出序号，评分算法保持。
- 链库、档案及任务空面板底部统一标准间距。实际整理归档执行器仍待接入，本版并发仅保存配置。

## 构建与验证

Docker后端阶段补复制更新日志嵌入包和正式版本说明，增加构建输入回归。各模块专项、前端单元、构建、静态检查及平台编译保留独立证据，不将分轮结果合成完整Go/race/E2E全过。真实云盘、媒体服务、TG、Docker/FUSE、NAS、设备帧率及内存仍需部署验收；源码推送、CI、镜像和现场状态分别核实。
