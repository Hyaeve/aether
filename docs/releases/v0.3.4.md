# v0.3.4

- CAS任务改为生成`.cas.strm`，单行签名播放URL包含SHA256、MD5或两者及还原保留时间。移动源只能绑定移动，天翼源只能绑定天翼，本地源可绑定两者并保留双哈希。
- ED2K绑定任务改为生成`.ed2k.strm`，支持本地或115源，播放时通过绑定115的原生离线服务还原、核验完成文件并返回直链。115源完整读取内容计算ED2K，会消耗下载流量；并非无需读文件即可取得哈希。
- 保留旧CAS导入、旧播放地址和无绑定ED2K任务兼容。旧输出不自动删除，请重新执行生成新格式；新文件仍遵守保留扩展名、增量与目录结构设置。
- 缓存任务进度条由22px调细至16px，保留状态文字。

秒传命中和115离线完成取决于云端资源与账号权限，不保证即时成功。本地模拟测试不等同于真实云盘、媒体库或Linux FUSE联调；镜像工作流仍只构建linux/amd64。
