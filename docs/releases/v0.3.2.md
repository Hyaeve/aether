# v0.3.2

## STRM 工作台

- 目录优先归组，跨季及特别篇合并到剧集，电影多版本合为作品，排除非 STRM 和旧索引非法条目。
- 卡片左下重置识别元数据、右下识别；重置需确认，不删除磁盘 NFO、封面和 STRM。
- 优先展示已有 cover/poster/folder 封面，登录后通过受限接口读取。
- 媒体/元数据扩展名预设、保留扩展名（默认 iso）、目录选择中新建文件夹。

## 播放与插件

- ED2K 本地源绑定115，生成播放STRM；请求时等待115原生离线完成后返回真实直链。
- 115同播复制：十分钟内后续不同客户端使用数字后缀副本，每存储独立配置。
- STRM内容替换：确认后后台执行，活动通知展示进度和修改文件数。
- 辅助工具配置迁移到 /data/tools 加密快照，配置备份携带实际插件设置。
- 调整115设备下载接口、错误诊断及DAV/FUSE读取兼容；增加存储周期健康检查。

## 界面与任务

- 活动通知清除、三条可见及细滚动，Emby支持多类型通知。
- 缓存统计与进度、扩展名预设配色、短按住拖拽、重命名工作台与文件详情优化。
- 新建媒体任务Cron留空按创建小时保存每日整点计划；星空与实时流量显示调整。

## 边界

- 真实115/夸克等账号、离线资源和Linux FUSE内核未联调，不能保证现场读取错误已经消除。
- ED2K单次等待最多90秒；未知提交不重放。同播副本不自动清理，客户端按可信来源IP与UA区分。
- STRM替换失败前已发布的修改不回滚，执行前请备份。无季集证据的模糊目录仍可能需要手工匹配。
- 容器镜像仍仅构建linux/amd64。AGENTS.md仅本地保存，不纳入仓库。
