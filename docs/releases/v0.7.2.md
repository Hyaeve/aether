# v0.7.2

本版包含任务中心、传输控制、115插件、云盘会员与CAS播放、分享STRM取链及日夜界面的更新。

## 任务中心与CAS

- 任务管理更名任务中心，新增首栏任务面板，集中显示运行目录任务、解析生成队列、刮削和联动的真实状态；页面隐藏暂停读取，离页取消请求，不影响后台任务。
- CAS目录任务固定增量生成，已存在同相对位置、完整名称的 `.cas.strm` 直接跳过，不再提供全量重置。跳过的媒体不重新计算，也不因完成动作删除。
- 新增“CAS 信息”：全计算、移动CAS、天翼CAS，六字段保留空值占位。选择移动源默认移动CAS，可手动修改并持久保存。需要读取远程媒体时保留共享两槽和暂存完整性校验。
- 云盘目录内已有JSON/Base64 `.cas` 可直接提取已有有效特征生成，不必重新下载对应媒体；不会凭空补算特征文件里缺少的哈希。
- **CAS正文改用 `/cas/`，不兼容旧 `/stream/` CAS播放及解析。** 普通存储与ED2K路由不变。旧产物不自动迁移，增量任务会跳过已有文件；需自行移除旧CAS产物后重新生成，不删除源媒体。

## 传输与云盘

- 复制、上传、下载统一进度状态、语义图标、细进度条和真实字节汇总；支持临时状态筛选、右键或空格多选，以及按实际能力暂停、恢复、确认重试和删除。
- 复制任务显示真实来源名称；同名跳过与扩展名忽略独立记录，不伪造完成量。重试仅限当前进程持有完整核验上下文的本地普通文件复制，其他任务不能从历史盲目重放。
- WebDAV同客户端同文件的Range读取合并记录，按唯一区间计算进度，关闭一段不误报整文件完成；失败冷却和票据刷新有界。
- 修正本地复制目标误套云端100GiB限制；移动PC目标500GB及其他上传、特征暂存等独立边界保持。115官方HTTPS跳转在严格可信链内接续必要登录字段，不向非官方地址泄露凭据。
- 存储卡片显示可确认的115、移动、天翼会员等级；查询失败或过期不猜测高等级，也不借容量快照保留旧会员。
- 移动CAS轮换账号失败后尝试其他已绑定可用移动账号，并在新建前按普通5GB、白银8GB、黄金20GB、钻石PC500GB/Web50GB预检；天翼黄金200GB，超过仅接受明确有效铂金权益。额度合格仍以实际秒传结果为准。
- 移动播放秒传持久记录未知提交意图，重启不盲目重放同账号同特征；存活临时文件仍优先复用。

## 分享播放与115插件

- 115和夸克分享STRM正文保留原始中文、空格和方括号等可读名称，只对URL语义冲突字符作必要转义，继续保持仅文件名及私有授权索引。
- 修正分享入口只读HEAD被当成最终直链缓存的问题；实际播放使用有界GET准备并解析最终CDN，派生缓存最多5分钟。中继401/403撤销对应票据，不自动重放当前播放请求。
- 新增首项115签到，每个真实账号一条计划，持久记录同日提交与结果，未知回执不重复提交。
- 115同播复制、文件夹清理、回收站清理和签到统一固定窗口、两行任务条及底部添加入口；文件夹清理支持确认后立即执行，继续完整预扫、身份核验和未知写入保护。
- 秒传记录区分监控名称与手动执行，重试成功简化为“重试1次成功”等；名称全文提示加宽并使用独立表面色。

## 界面与移动端

- 日间侧栏使用浅色表面，夜间保留深色；刮削、云管理和传输共用紧凑无内框多选胶囊及一致选择态。
- 提取码日间星空蓝紫、夜间星光黄，保持纯文字高亮，不加底框。
- iOS及独立窗口顶栏从顶部安全区下沿开始，内容与滚动区同步避让；Worker只缓存公开离线提示，不缓存CAS播放或账号数据。
- 数字统计改为1400ms渐缓过程，前段快速、最后10%小步减速；通知时间内收，运行日志新增回到顶部，主滚动轨加宽。

真实云盘会员权益、秒传、签到、清理、TV/CDN播放、Docker、NAS与FUSE仍需部署验证。源码推送不等于远端CI完成或GHCR镜像已经更新。
