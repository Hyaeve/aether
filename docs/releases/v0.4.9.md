# v0.4.9

## 构建修复

- 根据 v0.4.8 两次 Actions 的完整日志，实际失败的是 Linux `TestNativeFuse115BoundedCacheCallbacks`，不是备份浏览器用例，也没有数据竞争报告。
- FUSE 磁盘缓存改为仅映射 `/fuse_read_cache` 时启用后，该测试仍隐含依赖默认缓存。现在显式注入临时缓存，并分别验证启用与禁用：同一热块不重复请求；跨块返回时仅启用磁盘缓存才能复用；版本失效重新读取、凭据变化拒绝旧缓存、句柄释放归还资源。
- 不改变生产缓存策略、115 下载并发或限速，不恢复环境变量开关，不放宽断言、增加超时或跳过测试。
