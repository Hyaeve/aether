# v0.8.0

## 115 STRM 全量同步

- 全量同步使用独立目录统计核对批量清单的文件及子目录数。发现差异时逐目录补读，核对返回总数、分页位置和文件归属。
- 清单仍有可核验缺口时，任务报告目录及数量差异，保留原生活事件游标。找到的漏项按原 pickcode 生成，既有产物继续按全量同步的增改规则处理。

## 链接转存

- 夸克与移动活链创建保存目录后保存云盘返回的目录 ID，并等待列表确认。再次执行可核对该回执，确认后继续转存剩余文件。旧回执无法核验时可改用空闲的目录名，原目录和历史会保留。
- 115、移动和夸克的转存目录窗口统一使用日夜主题的标准窗口底色。

## 探索发现与档案中心

- 资源推荐的动漫栏目接入 Bangumi，提供本周放送、热门动画、搜索和作品详情。Bangumi 订阅可在追剧日历中查看播出信息，动漫图标的尺寸与相邻栏目统一。
- 整理档案和刮削档案会记住当前浏览器账号选用的列表或分组模式。
