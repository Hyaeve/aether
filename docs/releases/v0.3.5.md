# v0.3.5

- STRM 大库完整展示，10000 条限制只用于单次自动识别/刮削；修复质量标记位于中文标题前时截断作品名。六列海报、实际作品路径、手动搜索及子目录多选筛选同步发布。
- 文件管理支持图片/视频双击原生预览、网格图片缩略图、选中后 Ctrl+A 全选。目录选择器复用单行可折叠路径，加大新建目录图标。
- 任务新增二次确认的全量重置，清除对应生成库再生成；拒绝公共根、源目录、其他任务重叠及含原始媒体的目录。CAS 缺少目标哈希时跳过继续，并每 50 项汇总日志。
- 传输条目支持选中及右键暂停/继续/删除，读写边界生效；云端已提交复制不支持撤回，失败需重新发起。删除不回滚已经写入的本地内容，暂停过久仍可能触发上游超时。
- 115 下载补传接口返回的 host-only 临时 CDN 票据，排除 UID/CID/SEID/KID，保留跨域重定向凭据隔离。用于修复缺失临时票据导致的 403，不代表真实账号的全部风控/读写问题均已解决。
- 顶栏速率按文本动态占位，补计以链中继媒体流量；302 客户端直连不计入。原始日志时间放到级别后，传输与活动使用细滚动条，主页面从顶栏以下滚动。
- 移除 115 STRM 增强及 115 分享 STRM 工具卡片。通知优先显示 Emby 服务端名称，统一任务图标尺寸；单位输入复用步进位置，星旋方位与亮度调整。

浏览器预览受格式/编码支持限制。真实网盘账号与 Linux 内核 FUSE 未联调；镜像仍只构建 linux/amd64。
