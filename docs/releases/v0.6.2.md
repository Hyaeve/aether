# v0.6.2

本版基于 v0.6.1，整合分享转存、CAS 一次性生成、夸克接管与界面改进，不合并此前排除的历史提交，不改写既有发布标签。

## 分享转存与文件管理

- 转存目录右侧增加保存目录。单文件夹分享默认原名，可替换最外层名称或清空后平铺；文件分享默认不套目录，填写名称后放入该目录。多链接清空并禁用自定义名称，各自保留目录结构。
- 单链接稳定输入后只读获取默认目录名，未就绪时提交等待；失败通过消息气泡反馈，不静默按空目录转存。迟到响应不覆盖人工编辑，隐私说明同步实际处理范围。
- 保留每批最多 499 个文件、先应用原目录勾选再映射目标、同名文件不覆盖和结果不明不重放。成功气泡与页面跳转指向实际保存目录。
- 移动与夸克的 pwd、115 的 password 完整参数统一高亮，保留大小写与原输入，修正粘贴 Markdown 时的高亮边界。
- 文件管理重命名成功后原位更新，不刷新目录、不顶置，保留当前排序位置、选择和滚动状态。

## CAS 解析与生成

- CAS 增加移动分享链接解析，一行一条、最多 50 条，按目录层级进入一次性生成队列，不创建重复计划任务。文本解析支持多行 Base64、JSON 及混合内容；CAS/ED2K 输出保留完整原文件名。
- 分享未返回 SHA256 时，解析只读枚举；经二次确认后使用 CAS 移动绑定池临时转存，读取真实 SHA256，生成并读回校验 STRM 后再逐文件清理。不会下载媒体，不改变播放保活策略。
- 临时转存按分享和父目录隔离、每批最多 499 项。写前持久记录，结果不明不重放；源身份、配置、哈希或产物变化时保留云端文件，远程空目录保留。重启标中断并提示人工核对，不自动补转存或删除。
- 任务卡片增加“最近执行：”标头并向左展开时间和状态区域。

## 夸克接管

- 修复可信上游自动轮换 Cookie 导致同账号 TV 绑定被误判“凭据已变更”。手动换号、原已失效绑定、解绑、停用及迟到响应保护保持；旧失效绑定仍须同账号重新扫码，不能静默恢复。
- 清晰度偏好统一流畅、高清、超清、4K 四档，超清包含 1080p/2K，杜比保持独立开关。旧配置按兼容映射读取和保存，不更改上游权限、MP4 优先与智能 HLS 回退。

## 公共界面与文档

- 全局刷新使用统一透明 PNG，适配主题、尺寸、忙碌旋转及禁用状态，其他非刷新语义图标保持。
- 备份筛选、115 监控筛选和全局忽略扩展名标签共用星空蓝紫浅色主题，输入框层级保持不变。辅助工具卡片保留独立标题、副标题与通栏描述。
- 更新分享剪贴板、CAS 生成、夸克接管、传输设置与原位重命名说明，补充移动分享协议来源。

## 升级与验收边界

- 配置格式保持兼容；CAS 一次性任务运行态增加临时转存回执，旧任务不会自动重放。已有 STRM 不自动重写，分享保存目录不会记成下次默认名。
- 各阶段已运行专项、Go 全量、前端单元、构建及桌面/手机日夜截图核验。完整发布回归及最终结果在发布后本地整版本总结中记录；本地通过不等同远端 CI 或镜像构建成功。
- 真实云盘写入/清理、客户端播放、Docker 与 Linux FUSE/NFS 尚需部署验收；用户样本仅做匿名只读枚举，不将模拟接口测试表述为真实转存通过。
