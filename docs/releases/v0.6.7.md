# v0.6.7

## 夸克链库与 TG 批次交互

- 夸克链库首个全局启用池强制参与，新增持久默认容器生成位置。没有生成位置时可保存未启用草稿，补齐后原位启用；修改默认位置不会迁移或自动启用旧卡片。
- TG 正文或图片说明以 `/share` 或“虚拟链库”开头时进入分享 STRM，普通链接仍为转存。目前仅接入夸克链库，115 和移动分别报告暂不支持。
- 多链接按 115、移动、夸克及分享/ED2K 用途分组交互，当前组结束后再推进。多链接即使只有一个目录也须确认；单链接单目标保留直接入队。
- 分组取消、过期和重启清理等待成员，不重放云端写入。执行核对授权、默认设置和存储修订，可信自动 Cookie 轮换仅接续仍有效的任务。

## 115 秒传监控与文件传输

- 监控失败处理选择“传输”时，明确未命中后依次等待 10、30、60 分钟重试，第三次重试仍未命中才上传。记录区分初次秒传成功、重试次数与传输成功。
- Cron 配合“跳过”会在下次计划重试明确失败文件；未知写入仍不重放。等待状态独立持久，配置改变或停用取消旧等待。
- 监控与备份一致对名称黑名单整支剪枝。修复局域网 HTTP 缺少 `crypto.randomUUID` 导致添加监控卡住，以及配置锁内文件系统校验问题。
- 文件管理支持跨存储类型复制和移动，复用服务器暂存、摘要校验和传输记录。移动在发布校验后才清理源，失败保源，远程空目录保留。
- 移动下载仅在上游 `cdnSwitch=true` 时选用 CDN 地址；此修正不等于实际 NAS 或挂载吞吐已经验收。

## 云管理与媒体界面

- 任务、通知及云管理时间统一为 `YY/MM/DD HH:mm`。云下载分离任务链接与目标路径，时间及进度合并为执行状态，以绿、红、橙进度表达结果；CAS 显示已知真实目标路径。
- 分享栏增加时间，分享、下载和回收站调整列宽与字号；已加载数量移到刷新左侧，清理按钮采用浅红悬浮态。
- 普通 STRM 的保留扩展名默认仅 `iso`，显式清空生成 `名称.strm`；填写 `mp4` 则生成 `名称.mp4.strm`。新增漫画快捷组。已有产物不自动改名或删除，同名冲突仍拒绝；CAS/ED2K 命名不变。
- 音频增加内侧关闭按钮，页面焦点下 Esc 可停止并关闭，折叠仍继续播放。视频详情仅全屏显示，放大文字和窗口，移除网速占位；音量、字幕和音轨浮层共用详情表面。

## 导航与消息配置

- 仪表盘改为“以太视界”，系统日志改为“运行日志”，原路由保持。侧栏略收窄，11 个入口连续排列，空间不足时隐藏轨道滚动；顶栏显示模块、栏目和已知子页。
- 通知服务首栏改为“消息配置”，TG 窗口改为“TG Bot”，下方新增企业微信独立表单，支持管理员按需显示秘密字段、显式清除和独立保存。
- 企业微信接入应用消息测试及可选加密回调。仅向明确配置的成员发送，不默认全员；验证签名、时间窗、企业、应用与成员，当前回调仅支持连接回复和只读状态查询。
- 企业微信秘密字段沿用配置加密和脱敏；令牌只在内存缓存，写入结果不明不自动重发。尚未接入企业微信转存、离线、分享 STRM 或全系统事件推送，TG 原流程保留。

## 升级与验收边界

- 保留 `/config`、`/data` 和主密钥，不自动迁移或删除云盘文件。本地设计文档和用户原稿不进入发布提交。
- 本地专项、模拟协议和交叉编译不能替代真实 TG/企业微信、云盘写入、公网回调、Docker、Linux FUSE/NFS 或实体 iOS 验收。
- Windows WebKit 环境存在 WAV 加载失败记录；未删改解码断言，不宣称全部 Safari 音频验收通过。远端 CI 和镜像构建状态以实际运行结果为准。
