# v0.4.5

## 文件与页面体验

- 文件搜索栏略加宽，历史访问按钮与刷新统一颜色、大小和悬浮态；历史菜单右移，统一存储图标主体大小，优先显示完整最深目录，缺省上级路径显示 `/../`。
- 文件详情侧栏略收窄，项目数量放到标题旁，位置标签与路径对齐，使用自然的右侧滑入动画并支持点击外部关闭。
- 所有排序方向均保持文件夹置顶，再分别排序文件夹和文件；文件窗口底部显示当前页项目数量，空收藏栏不再显示提示文字。
- 文件管理、直链缓存、日志和传输任务逐步滚动短页头，再滚动原有虚拟列表，停靠时与面包屑保留 8px 间隔。空任务、挂载和传输面板采用统一 8px 底部留白。
- 加强存储、任务、挂载和 WebDAV 用户卡片悬浮描边，保留运行及不健康状态颜色；移除 WebDAV 用户操作按钮的原生悬浮文本框。
- 日志列表模式按浏览器账号保存，搜索、级别和模块筛选仍不持久化；日间结构化列表灰白条纹与页面背景区分。
- 本地目录分批读取元数据，减少整目录中间对象和内存分配，保留根目录安全边界、大小和修改时间；支持批次间取消，不承诺慢磁盘或网络挂载目录立即加载。

## 夸克下载

- 普通下载使用完整夸克 PC 请求头，吸收下载 API 更新的同源 Cookie 并加密保存、本机代理读取使用新凭据；不改为 302、不改变代理插件范围。
- 取链错误区分 DNS、超时、TLS、提前断开等，业务拒绝与空链接单独报告；不输出 CK 或签名 URL，不自动重试 POST，迟到响应不覆盖已编辑凭据。

## 验证边界

前端构建、162 项完整 Playwright、Go 全量测试、vet、Linux amd64 测试交叉编译和构建通过。最后联动面板底部留白调整后的 11 项相关布局回归也全部通过；测试未放宽超时或跳过用例。

真实云盘账户和 Linux 内核 FUSE 未联调，不将模拟下载测试通过宣称为现场问题已消除。镜像仍仅构建 linux/amd64；本地验证与远端 CI 构建分别报告。
