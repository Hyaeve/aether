# 存储健康巡检

参考 LitePan 的按账号调度、轻量探测、授权退避和被动恢复机制，按 Aether 实际凭据类型实现；不是统一频率的全目录扫描。

- 启动五秒后检查本地巡检计划，启用存储依次巡检，存储之间间隔两秒。每十五秒检查到期计划，不是每十五秒请求网盘；保存的未到期计划在重启后继续沿用。
- 正常间隔：夸克七十分钟，天翼四十五分钟，115、移动、OpenList、WebDAV 和本地存储一小时。115 使用 CK，不套用 OAuth Token 的刷新周期。
- 云盘和 OpenList 只读取一个目录条目，WebDAV 使用 Depth 0，本地读取至多一个条目，不遍历全盘，也不替换业务目录缓存。探测最多三十秒。
- 天翼会话临近到期时重新登录，令牌模式有刷新令牌时主动续期；新的令牌仍加密保存在配置中。CK 或移动 Authorization 没有可用刷新协议时只检查有效性，不假装自动更新。
- 可恢复的认证失败按一、二、五、三十分钟退避，第五次失败后每天复查一次；明确凭据失效直接进入每日复查。网络故障一分钟后复查，不累计认证失败次数。冷却中的被动业务错误不会反复耗尽重试预算。
- 异常存储卡片红色描边；源存储处于冷却、失效状态时，新任务暂缓启动，备份检查实际访问的源和目标。CAS/ED2K 生成不访问绑定网盘，不因绑定网盘离线而拦截本地生成。更新凭据清除旧判断，手动测试连接可立即复查，成功后恢复。不自动取消已有运行任务，也不自动续跑未完成任务。
- 巡检成功后同轮更新云盘空间，查询失败保留最近成功值，不仅因容量接口失败就判定账号失效。健康计划和容量写入 `/data/runtime/state.json`，不是 `/config`。

同一存储并发巡检合并，删除、停用或修改配置后拒绝写回旧请求结果。空间查询需要的移动账号域 ID 见 [云盘空间显示](storage-usage.md)。健康探测成功只代表目录访问正常，不能证明下载 CDN、写入权限或 FUSE 内核一定正常；真实云盘环境需部署验证。
