# PWA 与 iOS Safari

Aether 提供 Web App Manifest、192/512px 安装图标、180px Apple Touch Icon 及同源 Service Worker。安装图标由既有 Aether 标志生成，浏览器标签页仍使用原来的 favicon。

## 访问与安装

- 在 iOS Safari 打开部署地址，通过系统分享菜单“添加到主屏幕”访问独立窗口。
- Service Worker 仅在浏览器认可的安全上下文中注册：生产环境应使用受信任的 HTTPS，开发环境可用 localhost。普通局域网 HTTP 仍可使用网页界面，但不会注册 Worker，也不保证所有安装、离线及系统剪贴板能力。
- 手机布局包含 `viewport-fit=cover`、动态视口高度、刘海/状态栏/底部手势区域和横屏左右安全区；输入控件使用适合手机的字号。允许用户缩放，不锁定屏幕方向。
- 手机及独立窗口的顶栏从顶部安全区下沿开始，顶栏本身保持48px，按钮不进入状态栏不可点击区域；内容和主滚动区同步下移。顶部填充仅作背景，不拦截点击；通知等下拉窗口仍跟随实际顶栏位置。
- 这是 Web 应用，不新增原生 iOS 客户端、后台云盘传输或系统推送能力。WebKit 自动化不能替代实体 iPhone 的主屏幕安装、系统键盘及安全区验收。

## 缓存与更新

Worker 只保存公开、无用户数据的离线提示页。认证页面、API、Token、云盘响应、缩略图、媒体正文、签名播放链接及写请求均不缓存；业务操作始终连接服务器。断网时访问已接管的应用页面显示离线提示，不展示旧账号内容，也不假装任务已提交。

任务中心 `/tasks` 与 `/tasks/panel` 属于应用导航，断网时同样显示公开离线提示；`/cas/` 播放请求不是应用页面，不被Worker拦截或离线缓存。

`sw.js` 和 manifest 返回准确的内容类型及 `Cache-Control: no-cache`；缺失 PWA 资源返回404，不降级为应用首页。Worker 更新遵循浏览器生命周期，不强制刷新或立即替换正在使用的窗口；只清理本项目自己的旧离线缓存，不删除其他应用缓存。
