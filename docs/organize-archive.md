# 整理归档

任务中心原“目录整理”栏目更名为“整理归档”，路径仍为`/tasks/organize`，沿用侧栏返回记忆和统一面包屑。栏目与任务卡片使用独立绘制的文件流入归档盒线图标。

本阶段按用户确认先提供可保存的任务卡片与表单；识别、命名、媒体分类和洗版现已提供规则配置与纯求值，执行器仍待接入。任务卡片可添加、编辑、确认删除，显示名称、两端存储和目录、整理方式及“待配置规则”；不提供执行入口，也不进入调度器或触发文件整理。

编辑窗口不显示滚动条，内容超出可用高度时保留内部滚动，标题和底部操作固定。行序如下：

| 行 | 左侧 | 右侧 |
| --- | --- | --- |
| 第一行 | 任务名称 | 待整理目录 |
| 第二行 | 整理方式 | 归档目录 |
| 第三行 | 命名规则、媒体分类、洗版策略三个同行选择器 | 各占三分之一 |
| 第四行 | 冗余归类 | 文件过滤（MB） |
| 第五行 | 元数据归档 | 排除名单 |
| 第六行 | AI增强识别、TMDB刮削、FFprobe解析、智能清理四个同行开关 | 各占四分之一 |

“冗余归类”沿用原失败目录配置，默认留空不处理。选择目录后作为未识别或内容重复项的归类位置；文件夹按钮只展示待整理目录的同一个存储池，未选择源池时不可点，可单独清空。更换或清除源池时清空旧目录，同池更换待整理目录时保留。“文件过滤”默认0 MB不限制，仅接受非负整数，错误时提示且不能保存，前后端均校验；旧值保留。

三个规则选择器读取“以太识律”对应栏目现有卡片，默认各自第一项，保存所选ID，服务端复核所属类别。规则菜单固定208px高，视口不足时收缩，超出滚动且隐藏轨道，可用键盘选择；弹层独立于编辑窗口，避免内部滚动裁切。空列表显示尚未添加，不伪造默认卡片；已选规则被移除时需重新选择后保存。命名/洗版编辑器已提供默认草稿及恢复默认；全局默认卡片自动创建、首卡保护与至少保留一张仍留后续，不静默往现有配置插入卡片。

元数据归档默认`srt;ass;ssa`，留空表示不做字幕同步。排除名单用英文分号分隔：普通关键词用于文件名，`.mkv`用于扩展名，`.cas.strm`支持复合后缀，`/花絮`用于目录关键词，例如`预告;.mkv;.cas.strm;/花絮`。扩展名统一小写，保存时去空白和重复项；旧`*mkv`或`*.mkv`配置读取时显示为`.mkv`，读取不改磁盘，保存后写入新格式。AI增强识别默认关闭，仅在辅助配置中的AI服务已配置并启用时可选；支持不要求密钥的有效自托管服务，不读取或返回API密钥。TMDB刮削默认开启，FFprobe解析默认开启，智能清理默认关闭；显式关闭或空扩展名会保留，旧配置读取补默认但不重写磁盘。

### 后续执行规范

用户已确认本轮只完成窗口、规则关联和配置保存，以下是后续执行器要求，当前不发送媒体请求或移动/删除文件：

- 全局[识别规则](recognition-rules.md)已具备配置与只读预览：前置匹配只处理识别名称副本；后置命名替换、发布组扩展、黑名单与体积过滤的纯处理函数等待执行器调用。黑名单命中移到本任务`failureDirectory`（当前界面为“冗余归类”，本次需求称失败处理）；未设置则采用对应存储的回收站操作。全局体积阈值0不限制，正值以下直接删除的处置也留待执行器接入，不因保存配置而触发。
- 默认识别视频文件，以及视频扩展名后跟常规`.strm`、`.share.strm`、`.ed2k.strm`、`.cas.strm`的指针；排除名单可进一步排除类型。
- 源和归档端已有相同内容时，按可取得的同算法SHA1/SHA256/MD5或可靠内容校验值判等，归到冗余目录；没有可信校验值不自行认定重复。保留已有归档项。
- [命名模板和洗版评分](naming-upgrade-rules.md)已具备纯逻辑及持久配置。洗版仅针对已确认同作品/同一集的版本，开启分组按N到1线性加权并合计总分，同分保留现有版本；落败版本的移动决策使用本任务冗余目录，未设置则保留，实际移动仍待执行器接入。
- 同目录、同名元数据按主文件的新名称同步改名归档。TMDB刮削复用识别信息，在作品对应位置生成NFO与媒体图片，减少重复请求。
- FFprobe仅在命名模板需要但文件名缺少分辨率、特效、视频/音频编码、帧率及ISO质量等信息时取链并读取少量文件头，支持STRM指向的媒体；用存储可得可靠内容哈希缓存，避免重复读取，不整文件下载。具体提供商能力和读取预算由后续执行器验证。
- 智能清理在主文件完成后进队列，未开启字幕同步时也处理可清理残留字幕；合并可清理父子目录后批量删除，不等整轮扫描，保留含媒体目录、排除目录、失败字幕及来源根目录，失败留待下轮检查。

任务名称1至200字，输入和目录/方式控件均40px高。源、目标目录任意一方均可先选；另一端仅展示同类存储池，按存储类型匹配，不限制为同一账号。目录通过现有虚拟目录选择器选择，保留池ID、目录ID、完整展示路径和面包屑身份；允许分别清除后重选，不静默替换另一端。两端不能是同一存储池的同一目录。

默认方式为“移动”。本地存储可选移动、复制、硬链接、软链接；其他存储仅移动、复制。先选择本地归档目录时也会显示本地方式，并限制待整理目录为本地。用户已选的合法方式保留；清除后或切换类型导致原方式不再合法时回到移动。服务端保存时再次检查类型、可用存储和方式，不允许绕过界面提交云盘硬链接或不同类目录。

配置通过受保护的`/api/organize-tasks`及`/{id}`接口持久化到`/config/state.json`的`organizeTasks`，使用现有事务、完整性校验和配置备份，最多1000条。没有执行状态、Cron或文件写入意图，不假定云盘跨账号复制、文件系统跨卷链接等执行能力已实现。删除仅移除配置，不删除目录或媒体。已经移除/停用的池可在卡片上发现并重新选择，未完成执行规则前不会调度这些配置。
