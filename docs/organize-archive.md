# 整理归档

栏目顶部的环状图显示配置完整率。任务卡片和虚线添加卡片沿用任务中心的桌面两列、窄屏单列布局，显示名称、来源、归档目录、整理方式和执行结果。

任务中心原“目录整理”栏目更名为“整理归档”，路径仍为`/tasks/organize`，沿用侧栏返回记忆和统一面包屑。栏目与任务卡片使用独立绘制的文件流入归档盒线图标。

配置源目录、归档目录、命名和媒体分类规则后，点击卡片上的播放图标执行。作品识别使用已启用的 TMDB 配置。任务在后台扫描和整理，卡片与任务面板显示进度。执行期间可打开配置查看，可点击停止，已完成的归档会保留。每个文件的来源、去向和结果可在整理档案查看。服务重启后未完成的任务显示已中断。

编辑窗口不显示滚动条，内容超出可用高度时保留内部滚动，标题和底部操作固定。行序如下：

| 行 | 左侧 | 右侧 |
| --- | --- | --- |
| 第一行 | 任务名称 | 待整理目录 |
| 第二行 | 整理方式 | 归档目录 |
| 第三行 | 命名规则 | 媒体分类 |
| 第四行 | 洗版策略 | 处理并发 |
| 第五行 | 冗余归类 | 文件过滤（MB） |
| 第六行 | 元数据归档 | 排除名单 |
| 第七行 | AI增强识别、TMDB刮削、FFprobe解析、智能清理四个同行开关 | 各占四分之一 |

处理并发默认为 1，最高 3。识别和探测可同时进行，归档目录内的版本判断和写入按顺序提交。文件过滤的 MB 与步进按钮复用输入框最右侧同一位置。

“冗余归类”沿用原失败目录配置，默认留空不处理。选择目录后作为未识别或内容重复项的归类位置；文件夹按钮只展示待整理目录的同一个存储池，未选择源池时不可点，可单独清空。更换或清除源池时清空旧目录，同池更换待整理目录时保留。“文件过滤”默认0 MB不限制，仅接受非负整数，错误时提示且不能保存，前后端均校验；旧值保留。

三个规则选择器读取“以太识律”的规则卡片。命名和媒体分类默认各自第一项。洗版策略默认“不洗版”，会接收内容不同的版本，同名时依次使用 `_1`、`_2`。规则菜单约四项高，超出可滚动。已选规则被移除后需重新选择。

元数据归档默认`srt;ass;ssa`，留空表示不做字幕同步。排除名单用英文分号分隔：普通关键词用于文件名，`.mkv`用于扩展名，`.cas.strm`支持复合后缀，`/花絮`用于目录关键词，例如`预告;.mkv;.cas.strm;/花絮`。扩展名统一小写，保存时去空白和重复项；旧`*mkv`或`*.mkv`配置读取时显示为`.mkv`，读取不改磁盘，保存后写入新格式。AI增强识别默认关闭，仅在辅助配置中的AI服务已配置并启用时可选；支持不要求密钥的有效自托管服务，不读取或返回API密钥。TMDB刮削默认开启，FFprobe解析默认开启，智能清理默认关闭；显式关闭或空扩展名会保留，旧配置读取补默认但不重写磁盘。

### 执行流程

- 扫描视频与 STRM 文件。任务排除名单优先，黑名单命中项按冗余目录归类，未设置时移入回收站。全局体积阈值以下的待处理文件进入回收站。任务自身的文件过滤阈值仅跳过小文件，STRM 指针按媒体引用处理。
- 识别使用名称副本，按需调用已配置的 AI 服务辅助识别，再经 TMDB 匹配。套用媒体分类、命名模板、命名替换和发布组规则时保留原有复合扩展名。
- 相同体积且可靠的同算法校验值一致时，按冗余配置处理重复文件。启用洗版后对同一作品或同一集评分。新版胜出时先归档新版，再将旧版移入冗余目录。同分保留已有版本和待整理源文件。
- 同名字幕随主文件改名归档。TMDB 刮削复用识别详情，补写缺少的 NFO 与海报。FFprobe 按需读取最多 8 MiB 的媒体数据，探测失败时用已有名称信息继续整理，并在档案中提示未补全。常规 Aether STRM 引用可按签名解析。其他直接 HTTP(S) 指针可探测公开地址。
- 智能清理在主文件移动完成后处理同名残留字幕和可确认的空目录。源根目录、排除项和仍含文件的目录保留。
- 本地支持移动、复制、硬链接和软链接。云端同池操作使用存储驱动，跨池复制后核对内容再移走源文件。目录重叠或存储身份变化时停止相关写入。


任务名称1至200字，输入和目录/方式控件均40px高。源、目标目录任意一方均可先选；另一端仅展示同类存储池，按存储类型匹配，不限制为同一账号。目录通过现有虚拟目录选择器选择，保留池ID、目录ID、完整展示路径和面包屑身份；允许分别清除后重选，不静默替换另一端。两端不能是同一存储池的同一目录。

默认方式为“移动”。本地存储可选移动、复制、硬链接、软链接；其他存储仅移动、复制。先选择本地归档目录时也会显示本地方式，并限制待整理目录为本地。用户已选的合法方式保留；清除后或切换类型导致原方式不再合法时回到移动。服务端保存时再次检查类型、可用存储和方式，不允许绕过界面提交云盘硬链接或不同类目录。

配置通过受保护的 `/api/organize-tasks` 接口持久化。`POST /api/organize-tasks/{id}/run` 和 `POST /api/organize-tasks/{id}/stop` 分别负责手动执行与停止。运行结果单独保存，配置备份只包含任务定义。删除卡片只移除任务及其最近一次运行状态，整理档案和已归档文件继续保留。
