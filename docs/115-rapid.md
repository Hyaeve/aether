# 115 秒传中心

辅助工具的115签到之后提供独立的115秒传中心。手动任务选择容器内待传目录和115存储目录，默认第一个启用的115存储；目录、扩展名和处理方式由管理员共享，保存在`/config/tool/115-rapid.json`，不依赖浏览器。

## 处理规则

- 扩展名空白表示处理普通文件，仍遵循全局忽略文件扩展名；可通过视频、音频按钮添加常用扩展名。扫描保持所选目录下的相对层级，不创建待传目录本身的额外包装层。计算与上传遵循现有全局并发限制，本地上传回退遵循全局上传速度限制。
- 默认成功后清理源文件，失败跳过；可改为保留源文件或选择传输。监控失败处理名称为“直接跳过、重试传输、重试删除”，选项尾部的感叹号可悬浮查看说明。“重试传输”在首次明确未命中后等待10min重试，重试仍未命中则分别等待30min、60min；第三次重试仍未命中才上传本地正文。各间隔从前一次失败结束起算，不占用执行线程等待。手动秒传保留“跳过、传输”及明确未命中后立即上传的既有行为。成功秒传只提交摘要与115校验信息；115要求的校验片段仍可能读取本地文件。
- 监控额外提供“重试删除”，保存前须二次确认。它使用相同的10/30/60min三次重试，不回退正文上传；第三次重试仍收到明确未命中结果后，重新校验源文件内容、身份、祖先目录、配置和取消状态，只删除这份未变化的源文件。重试回执保存源摘要，等待期间即使大小和修改时间没变，摘要变化也停止该重试链。网络、授权准备失败、云端结果不明、目标冲突或文件变化时不因重试耗尽而删除。手动模式不提供此选项。
- 目标已存在同名文件则拒绝覆盖，也不将它当作本次成功结果。成功清理须重新读取云端目录，校验名称、大小、SHA1和PickCode；显式选择的监控失败删除是另一条经确认的规则，不伪装成秒传成功。
- 源文件内容、身份、修改时间、目录或存储配置发生变化时不清理。跳过符号链接和特殊文件，保留空目录；不得扫描系统配置、日志、缓存和运行数据目录。校验与删除之间不承诺对外部并发改名的跨进程原子事务。
- 写入请求结果不明时不自动重复提交。持久化执行意图对同一任务、文件、大小、修改时间和配置去重；重启后在途记录标记失败且保留意图。确定尚未提交的授权或API等待失败可以进入安全重试，已提交却无明确回执的请求不会自动重放；需要先检查网盘和源文件。

## 监控与记录

监控支持原生文件系统事件和五字段Cron表达式。文件系统事件等待2秒稳定后执行，30秒补查新子目录和遗漏事件；服务启动时也检查已有文件。监控任务在监控通道串行，手动通道可独立执行一个任务，不因监控运行禁用开始按钮；两者仍共用全局资源、并发和限速。同一份正被处理的本地文件不由两个通道重复提交，跳过原因记录日志。最多64个监控、单次100000个扫描项目、10000个监听目录。

监控编辑器复用备份筛选规则：扩展名、名称、正则、路径前缀、路径正则及最大最小。名称黑名单在扫描、监听注册和事件入口剪枝，命中目录不遍历子树，命中文件不计算摘要；不逐个处理黑名单目录中的文件。筛选设置与监控一起持久化，变更使新任务使用新规则并取消旧配置的等待重试。已有不明确写入意图不会自动重放。

Cron配合“跳过”时，本次明确未命中的文件保留在本地并释放本次去重，下一次Cron重新扫描符合筛选条件的文件，包括上次未命中的文件；成功和写入结果不明的文件仍受防重放保护。监控配合“传输”或“删除”的定时重试独立于下一次Cron，到达10/30/60min期限后调度。

带重试策略的Cron计划，相邻执行间隔必须严格大于120min，正好120min也拒绝；检查不只比较当前后两次，还覆盖日内、跨午夜、日期条件及所用时区的夏令时边界。旧短间隔配置仍可加载，监控暂停并记录原因，不能导致容器启动失败；新增、修改及导入须满足新限制。“直接跳过”没有这段延迟重试，但仍须遵守全部Cron[至少15分钟](cron-policy.md)的下限。

秒传记录、防重放意图及`rapid115Retries`等待队列位于`/data/runtime/state.json`，不随配置备份导出；最新记录排在前面，最多5000条，执行意图和等待队列各最多100000项。确定的等待重试可跨重启保留，在途写入不重放。记录区分“秒传成功”“重试1次成功”“重试2次成功”“重试3次成功”“传输成功”和“重试3次失败后删除”，等待记录显示下一次重试及次数；时间使用`26/10/24 18:59`格式。主记录与监控记录窗口共用简洁文案，旧成功记录的标准悬浮提示按显示层同步，不改写历史数据。设置导入不会移除现有执行意图。

主记录窗口每页30条，按完整一页预留固定空间，末页不塌缩，随页面滚动而不再使用内部滚动条。标题采用清单勾选图标，与监控历史按钮的回溯图标区分。提供首页、上一页、下一页、末页及页码跳转，超过末页直接取最后一页。列顺序为文件名称、文件大小、PickCode、触发来源、执行时间、秒传状态；文件名单行省略，静止300ms显示最宽560px、受视口约束的浅蓝紫圆角全文提示，移动立即隐藏；该提示样式只用于秒传文件名。PickCode保持完整单行。监控来源只显示历史记录中的监控名称，最多五字后省略，全文提示保留完整名称，不再显示“监控 · ”前缀；颜色为监控蓝色。手动显示橘色“手动执行”。旧记录仅显示层归一，不重写历史。手动、监控和记录窗口是平行表面，日间最内层内容纯白，向外按共享层级变灰，夜间使用相反亮度层级。

监控条目使用名称前两字的48px文字图标，以蓝色/金色背景区分文件系统/Cron；两行文字分别为监控名与待传→目标目录，优先显示两端最深目录。支持长按拖拽和Alt上下键排序；纯排序不取消待重试，真正修改配置仍取消。升级时仅将与当前配置完全匹配的旧摘要迁移为顺序无关摘要，计数/期限/内容摘要保留，未知配置和在途请求不恢复执行。

编辑按钮左侧的记录按钮按真实监控ID打开独立分页窗口，每页10条，省略来源列，时间为`10/27 18:59`，其他列随窗口收窄。旧记录没有监控ID时不按名称猜测归属，只在总记录中显示。两处分页相互独立，接口每2秒读当前页实际进度。

状态文字在进度条上方并带对应语义图标，进度条104px宽/4px高，成功绿色、失败或删除红色、执行和等待橙色。计算摘要及正文上传按真实读取字节报告当前阶段进度；等待资源、提交秒传或校验云端结果没有可靠百分比时显示阶段与静止轨道，不使用往返动画，也不编造百分比。高频进度仅在内存更新、通过不缓存的分页接口轮询，终态才随记录持久化，不按每块文件正文写配置。

监控添加兼容普通局域网HTTP没有`crypto.randomUUID()`的环境，保存失败恢复按钮并以消息气泡反馈；文件系统校验不在全局配置锁中进行。

115接口、账号状态或资源是否已进入115秒传数据库，会影响实际命中；本地模拟回归不等同真实账号验证。

## 同播复制

115同播绑定的复制保活默认为12 h，可设1至8760 h；同一客户端继续请求副本时续期。临时副本身份及到期时间保存在`/data/runtime/state.json`，到期检查原账号、目录、名称、大小和pickcode后清理。变更过的云端文件不删除；删除结果不明的记录不自动重放。
