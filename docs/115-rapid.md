# 115 秒传中心

辅助工具首项提供独立的115秒传中心。手动任务选择容器内待传目录和115存储目录，默认第一个启用的115存储；目录、扩展名和处理方式由管理员共享，保存在`/config/tool/115-rapid.json`，不依赖浏览器。

## 处理规则

- 扩展名空白表示处理普通文件，仍遵循全局忽略文件扩展名；可通过视频、音频按钮添加常用扩展名。扫描保持所选目录下的相对层级，不创建待传目录本身的额外包装层。计算与上传遵循现有全局并发限制，本地上传回退遵循全局上传速度限制。
- 默认成功后清理源文件，失败跳过；可改为保留源文件，或者仅在115明确未命中秒传时继续本地上传。成功秒传只提交摘要与115校验信息，无需上传完整文件数据；115要求的校验片段仍可能读取本地文件。
- 目标已存在同名文件则拒绝覆盖，也不将它当作本次成功结果。生成后重新读取云端目录，校验名称、大小、SHA1和pickcode，才允许清理源文件。
- 源文件内容、身份、修改时间、目录或存储配置发生变化时不清理。跳过符号链接和特殊文件，保留空目录；不得扫描系统配置、日志、缓存和运行数据目录。校验与删除之间不承诺对外部并发改名的跨进程原子事务。
- 写入请求结果不明时不自动重复提交。持久化执行意图对同一任务、文件、大小、修改时间和配置去重；重启后未完成记录标记失败且保留意图。手动重新点击不会重放未经确认的云端写入，需要先检查网盘和源文件。

## 监控与记录

监控支持原生文件系统事件和五字段Cron表达式。文件系统事件等待2秒稳定后执行，30秒补查新子目录和遗漏事件；服务启动时也检查已有文件。所有秒传任务在当前服务内串行，最多64个监控、单次100000个扫描项目、10000个监听目录。

监控编辑器复用备份筛选规则：扩展名、名称、正则、路径前缀、路径正则及最大最小。匹配在所选待传目录的相对路径下执行，黑名单优先，目录排除会停止遍历对应子树；筛选设置与监控一起持久化，变更使新任务使用新规则。已有写入意图不会自动重放。

秒传记录及防重放意图位于`/data/runtime/state.json`，只保存运行态、不随配置备份导出；最新记录排在前面，最多5000条，执行意图最多100000项。默认显示时间、文件名、大小、pickcode、秒传状态及手动/监控来源。设置导入不会移除现有执行意图。

115接口、账号状态或资源是否已进入115秒传数据库，会影响实际命中；本地模拟回归不等同真实账号验证。

## 同播复制

115同播绑定的复制保活默认为12 h，可设1至8760 h；同一客户端继续请求副本时续期。临时副本身份及到期时间保存在`/data/runtime/state.json`，到期检查原账号、目录、名称、大小和pickcode后清理。变更过的云端文件不删除；删除结果不明的记录不自动重放。
