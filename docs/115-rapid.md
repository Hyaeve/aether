# 115 秒传中心

辅助工具首项提供独立的115秒传中心。手动任务选择容器内待传目录和115存储目录，默认第一个启用的115存储；目录、扩展名和处理方式由管理员共享，保存在`/config/tool/115-rapid.json`，不依赖浏览器。

## 处理规则

- 扩展名空白表示处理普通文件，仍遵循全局忽略文件扩展名；可通过视频、音频按钮添加常用扩展名。扫描保持所选目录下的相对层级，不创建待传目录本身的额外包装层。计算与上传遵循现有全局并发限制，本地上传回退遵循全局上传速度限制。
- 默认成功后清理源文件，失败跳过；可改为保留源文件或选择“传输”。监控选择“传输”时，首次明确未命中后等待10min重试，重试仍未命中则分别等待30min、60min；第三次重试仍未命中才上传本地正文。各间隔从前一次失败结束起算，不占用执行线程等待。手动秒传保留明确未命中后立即上传的既有行为。成功秒传只提交摘要与115校验信息；115要求的校验片段仍可能读取本地文件。
- 目标已存在同名文件则拒绝覆盖，也不将它当作本次成功结果。生成后重新读取云端目录，校验名称、大小、SHA1和pickcode，才允许清理源文件。
- 源文件内容、身份、修改时间、目录或存储配置发生变化时不清理。跳过符号链接和特殊文件，保留空目录；不得扫描系统配置、日志、缓存和运行数据目录。校验与删除之间不承诺对外部并发改名的跨进程原子事务。
- 写入请求结果不明时不自动重复提交。持久化执行意图对同一任务、文件、大小、修改时间和配置去重；重启后在途记录标记失败且保留意图。确定尚未提交的授权或API等待失败可以进入安全重试，已提交却无明确回执的请求不会自动重放；需要先检查网盘和源文件。

## 监控与记录

监控支持原生文件系统事件和五字段Cron表达式。文件系统事件等待2秒稳定后执行，30秒补查新子目录和遗漏事件；服务启动时也检查已有文件。所有秒传任务在当前服务内串行，最多64个监控、单次100000个扫描项目、10000个监听目录。

监控编辑器复用备份筛选规则：扩展名、名称、正则、路径前缀、路径正则及最大最小。名称黑名单在扫描、监听注册和事件入口剪枝，命中目录不遍历子树，命中文件不计算摘要；不逐个处理黑名单目录中的文件。筛选设置与监控一起持久化，变更使新任务使用新规则并取消旧配置的等待重试。已有不明确写入意图不会自动重放。

Cron配合“跳过”时，本次明确未命中的文件保留在本地并释放本次去重，下一次Cron重新扫描符合筛选条件的文件，包括上次未命中的文件；成功和写入结果不明的文件仍受防重放保护。监控配合“传输”的定时重试独立于下一次Cron，到达10/30/60min期限后调度。

秒传记录、防重放意图及`rapid115Retries`等待队列位于`/data/runtime/state.json`，不随配置备份导出；最新记录排在前面，最多5000条，执行意图和等待队列各最多100000项。确定的等待重试可跨重启保留，在途写入不重放。记录区分“秒传成功”“重试1/2/3次秒传成功”“传输成功”，等待记录显示下一次重试及次数；时间使用`26/10/24 18:59`格式。设置导入不会移除现有执行意图。

监控添加兼容普通局域网HTTP没有`crypto.randomUUID()`的环境，保存失败恢复按钮并以消息气泡反馈；文件系统校验不在全局配置锁中进行。

115接口、账号状态或资源是否已进入115秒传数据库，会影响实际命中；本地模拟回归不等同真实账号验证。

## 同播复制

115同播绑定的复制保活默认为12 h，可设1至8760 h；同一客户端继续请求副本时续期。临时副本身份及到期时间保存在`/data/runtime/state.json`，到期检查原账号、目录、名称、大小和pickcode后清理。变更过的云端文件不删除；删除结果不明的记录不自动重放。
