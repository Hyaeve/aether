# 媒体分类

入口为“以太识律 → 媒体分类”，原“二级分类”的界面与任务选择字段已统一更名。可创建多张满宽规则预设卡片，每张独立保存名称、说明、目录及规则；整理归档编辑窗口选择其中一张，默认仍为本栏目第一张。现有卡片ID与任务选择保留，不因改名重建预设。

本阶段完成编辑、配置保存和纯分类求值，实际整理归档执行器仍未接入；保存预设、修改目录或调用预览不会建立、改名、移动或删除真实媒体目录。

## 编辑窗口

卡片编辑窗口有“分类目录”和“分类规则”两个栏目，切换时保留同一份未保存草稿。共同的名称、说明、取消及保存沿用标准弹窗，头尾固定，内容超出时内部滚动并隐藏轨道。日夜主题与40px控件不另建样式体系；栏目支持方向键、Home/End切换与焦点跟随。关闭或取消不修改原卡片，保存失败保留所有输入。

### 分类目录

只提供“剧集”和“电影”两个大类。两者根目录固定保留，不能改名、停用、删除或换成其他类型。

可在各大类下添加目录，填写：

- 目录名称：显示名称，不作为规则引用身份。
- 目录路径：相对本大类根目录，以`/`分隔多层，例如`动画/国漫`。路径可包含隐式父目录，不必为每个中间目录另建分类条目。
- 启用状态。

每个目录使用独立稳定ID。更改名称或路径后，已配置规则仍引用同一个目录；不同路径可使用相同显示名称，选择器会同时展示名称和路径。路径最多8层、512字节，每段最多128字节，不允许绝对路径、上级跳转、空段、保留名称和控制字符；同一大类内路径按不区分大小写去重，剧集与电影互不冲突。

每个大类可选择一个已启用的兜底目录，默认分别为剧集、电影根目录。规则或兜底仍引用的目录不能直接移除；被启用规则或兜底引用时不能停用。先调整引用后再删除目录条目，删除配置不会删除真实目录。

### 分类规则

规则按显示顺序求值，只使用第一条命中的已启用规则。每条支持名称、剧集/电影大类、启停、目标目录、复制、删除、上移和下移；目标只能选同大类目录。停用规则保留配置和目标，但不参与匹配。未命中任何规则时使用该大类的兜底目录。

条件可以递归组合：

- 普通条件：字段、比较方式及匹配值。
- 全部满足：所有子条件都成立。
- 任一满足：至少一个子条件成立。
- 取反：恰好包含一个子条件，并将其结果取反。

支持名称、原始名称、年份、类型/题材、类型ID、国家/地区、原始语言、评分、关键词、识别来源、成人内容共11个标准字段。字段和比较方式由受保护的服务端目录提供；不执行任意表达式或脚本，不为分类额外请求元数据来源。

| 值类型 | 例子与比较方式 |
| --- | --- |
| 文本 | 等于、不等于、包含、前缀、后缀、属于/不属于列表 |
| 年份/评分 | 相等、大小比较、包含端点的区间、属于/不属于列表；年份必须整数 |
| 类型/国家/关键词列表 | 包含任一、包含全部、不包含这些项 |
| 成人内容 | 是、否 |
| 所有字段 | 存在、不存在 |

列表用英文分号输入，如`CN;JP`、`16;99`；类型ID为整数，文本比较区分大小写。区间填写`起点;终点`，起点不得大于终点。缺失或空事实不满足普通比较，只能显式使用“不存在”匹配；取反对其子条件结果进行布尔取反。条件组不能留空，最多嵌套6层、每条规则128个节点；目录和规则分别最多512项。

分类器只消费已识别的标准事实：例如`countries`为国家代码字符串列表，`genreIds`为整数列表，`genres`为类型名称列表。它不假定不同元数据来源的原始响应相同，实际来源投影与整理执行流程留待后续接入。

## 保存与兼容

预设通过原`/api/rule-presets`接口保存，分类预设的技术类型`kind:categories`及`/rules/categories`路径保持兼容。具体定义存于卡片的`mediaCategory`，包含目录、规则和各大类兜底映射。旧名称/说明预设读取时补两大类根目录；读取不修改原记录，显式保存后持久化。旧客户端仅修改名称/说明时保留已有媒体分类定义，不清空其目录和规则。

整理任务对外字段现为`mediaCategoryRuleId`。原`categoryRuleId`只作读取兼容；新响应和保存输出使用新字段，两个字段同时给出且值冲突时拒绝，不静默选择其中一个。任务规则类别检查、失效引用提示、默认第一张及加密备份导出/导入继续有效。

新增`GET /api/media-categories/catalog`返回字段、比较方式和两类默认结构；`POST /api/media-categories/preview`对给定配置与已识别事实进行只读分类，返回目录ID、相对结果路径和命中规则ID。两者管理员鉴权、`no-store`。当前界面不另增加第三个栏目或独立预览面板。
