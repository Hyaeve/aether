# CAS链库

虚拟链库的“CAS链库”现提供移动分享链接的持久卡片与实际生成，入口`/virtual/cas`，设置页`/virtual/cas/settings`。只接受移动云盘官方分享链接；115、夸克分享走各自的分享链库，不将分享地址伪装成CAS播放地址。

设置页可保存默认生成位置、媒体扩展名和机器人新卡更新周期（默认7天），并提供CAS存储绑定池入口。添加/编辑卡片可设置分享链接、显示名称、生成位置、目录名称、Cron、媒体扩展名及排除目录/文件/类型；媒体扩展名留空继承默认设置。启用卡片后手动“执行”，或按Cron执行，Cron为空表示仅手动执行，非空沿用至少15分钟的统一间隔。手动保存只保存配置；执行前的确认说明临时转存和清理行为。

输出位于`生成位置/目录名称/分享内部相对路径/原文件名.扩展名.cas.strm`，正文为现有签名`/cas/`地址，六字段CAS保留SHA256及两个MD5空占位，不使用`.share.strm`。分享能提供有效SHA256时只读元数据直接生成，不读取媒体正文；SHA256缺失时使用CAS绑定池中可用的原生移动存储，复用已有CAS链接解析的临时转存流程。

临时文件放在移动个人云`/Aether/cas-import-任务ID/batch-序号`内。创建/提交前先记录意图，确认任务回执后读取本次副本的名称、大小、ID和SHA256，生成并读回核验CAS指针，再按既有删除方式清理仍匹配的本次副本。空临时目录保留，因为云端没有原子“仅空目录删除”。不删除分享源文件、用户原有文件或未知文件，不通过下载媒体补算哈希。没有可用绑定池、账号变更、读取失败或结果未知时停止；未确认的回执保留，不自动重放。相同分享的移除重加或提取码更改不会绕过未确认保护。

生成固定为增量：已有同路径普通CAS文件直接跳过，不改写；异常节点或符号链接不接管，不按分享删除反向清理旧CAS文件。修改位置后旧位置文件保留；移除卡片只移除配置，已生成的可移植CAS指针保留。执行保护所用输出目录，拒绝与运行任务冲突或覆盖配置/运行数据，发布前复核配置、授权和目录身份。

配置保存在主配置的`casLibrary`和`casLibraryCards`，分享链接按secret字段加密。结果位于运行态`casLibraryRuntime`，临时转存仍使用生成队列`generationJobs`的持久回执。配置备份不携带运行结果或临时意图，导入保留目标部署已有的CAS结果与本模块生成回执。重启将执行中任务标为中断，未知临时操作不自动再执行，须核对生成队列记录与网盘临时资源。

同一生成位置的目录名称不可与移动、夸克或其他CAS记录重复，输出目录不可重叠。网页重名返回字段冲突、留窗并要求修改；机器人新建不同分享的同名目录追加`_1`、`_2`等最小可用数字序号，跳过链库记录及磁盘已有名称，相同分享复用原卡片，已有目录不自动改名。每种卡片最多200条，前端每页20条，窗口至少填充页面剩余高度，带关键词搜索和单选状态筛选，只在筛选后超过20条时展示翻页和跳转控件；后端CAS分享扫描沿用10000条、32层、1000次只读请求、单次解析2分钟和现有临时转存499文件单批保护，不以分页截断实际扫描。

用户修改同一生成位置内的保存目录名称时，直接重命名整个本地CAS库目录，保留全部内容并更新内部目录身份与关联生成记录路径，不新建目录逐文件转移。目录身份存于casLibraryRuntime，按运行态持久化，配置导出排除、导入保留现有运行态；不生成owner文件。仅改名不触发云端解析或生成。

机器人命令：`/cas 移动分享链接`生成CAS链库；`/share`或“虚拟链库”后的115、移动、夸克链接分别生成对应分享STRM。直接发送分享链接仍是转存。CAS命令按本页默认设置添加/复用卡片并执行；默认位置为空时仅保存未启用卡片，已有停用卡片不被自动启用。全局默认位置被清空时，不通过机器人启动旧卡片，网页手动执行仍可使用该卡片自身位置。

多链接结果按网盘和处理类型合并，每条以`· 名称（实际处理数）`展示；转存结果只有提交回执时明确标为“已提交、待确认”，失败保留原因，不冒充成功。详情见[通知服务](notification-service.md)。本地模拟测试不能代替真实移动账号、TG、NAS或实体设备验收。
