# 以太识律

“以太工坊”的首项为“以太识律”。媒体命名、分类、洗版和识别相关入口集中在此，原“我的插件”中的整理规则、二级分类、洗版策略、AI辅助识别、识别规则、TMDB配置六项已移出。

页面依次包含四个栏目：

| 栏目 | 内容与状态 |
| --- | --- |
| 命名规则 | 整理规则、识别规则占位，标明待实装 |
| 二级分类 | 分类归档规则占位，标明待实装 |
| 洗版策略 | 画质及版本偏好占位，标明待实装 |
| 辅助配置 | TMDB配置、AI辅助识别两个可用配置窗口 |

默认进入命名规则。切换到其他侧栏再返回时，沿用已有会话导航机制恢复该账号上次访问的栏目；刷新和直接访问子路径均可。路径为 `/rules/naming`、`/rules/categories`、`/rules/upgrade`、`/rules/assist`，`/rules`重定向至命名规则。

辅助配置保留图标启停、读取现有配置、保存、测试连接和密钥按需查看。继续使用 `/api/plugins/tmdb`、`/api/plugins/ai` 及原有配置存储，没有迁移、重置或复制已有密钥。加载失败会显示错误且不能据空值启停；保存失败保留现有状态。占位区域没有可提交的规则编辑器，也不创建任务或发起整理操作。

“我的插件”现为11项，其搜索结果只包含剩余工具；Emby通知、媒体深度删除、115系列和其他已有工具入口保留。插件市场及系统代理配置位置不受此次调整影响。
