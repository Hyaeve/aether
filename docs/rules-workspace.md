# 以太识律

“以太工坊”的首项为“以太识律”。侧栏使用单独绘制的扫描识别与规则分流图标，沿用公共线条粗细、尺寸和日夜颜色，图形不另占可访问名称。媒体命名、分类、洗版和识别相关入口集中在此，原“我的插件”中的整理规则、媒体分类、洗版策略、AI辅助识别、识别规则、TMDB配置六项已移出。

页面依次包含五个栏目：

| 栏目 | 内容与状态 |
| --- | --- |
| 识别规则 | 匹配替换与只读预览、归档黑名单、命名替换、发布组扩展、文件体积过滤的配置 |
| 命名规则 | 多套剧集/电影模板，标签拖拽、可视化/源码切换和示例；多版命名占位 |
| 媒体分类 | 可新增多套规则预设，各含分类目录、分类规则两个栏目，仅剧集和电影 |
| 洗版策略 | 多套策略，10个可启停/排序的分组、固定组权重与组内等差递减总分 |
| 辅助配置 | TMDB配置、AI辅助识别两个可用配置窗口 |

默认进入识别规则。切换到其他侧栏再返回时，沿用已有会话导航机制恢复该账号上次访问的栏目；刷新和直接访问子路径均可。路径为 `/rules/recognition`、`/rules/naming`、`/rules/categories`、`/rules/upgrade`、`/rules/assist`，`/rules`重定向至识别规则；旧命名规则子路径仍有效。

命名、媒体分类、洗版三个栏目都采用满宽横条预设卡片，常规纵向视口在页签下约可放三张，最低180px；短横屏继续滚动，不压缩成窄小卡片。卡片末尾有同等高度虚线添加框，点击卡片或编辑按钮可修改；删除需确认，服务端成功后沿用配置卡片消散反馈。名称1至200字，同类名称不可重复，三个类型互相独立。编辑器不再提供预设描述，旧说明数据保留；字段统一“规则名称”、半栏40px高。命名/分类栏目等分窗口宽度，命名栏目使用剧集、电影等语义图标。洗版恢复默认按钮位于名称右侧。拖动标签时浮动卡片跟随指针，保留按钮和键盘替代操作、Esc取消；命名标签使用细描边。刷新和服务重启后保留；保存失败留在原窗口。命名和洗版详见[命名规则与洗版策略](naming-upgrade-rules.md)；媒体分类详见[媒体分类](media-categories.md)。实际整理归档执行器尚未接入，配置操作不移动或改名真实文件。

首次初始化、旧配置读取或导入时，只补齐缺少的命名、媒体分类、洗版三个类别默认卡片，不覆盖用户已有卡片、顺序和任务关联。默认命名为现有剧集/电影模板，媒体分类为剧集/电影根目录兜底，洗版为十组开启的默认优先级。每类至少保留一个预设，最后一张前端禁删且服务端事务内拒绝删除；被任务引用的预设也须先解除引用。三个编辑窗口均为960px宽、最高860px，随视口收缩，固定头尾、内部滚动隐藏轨道。整理归档仍默认“不洗版”，不会因有默认洗版卡而自动启用。

预设通过受保护的`/api/rule-presets`及`/{id}`接口增删改查，存于`/config/state.json`的`rulePresets`，使用现有完整性校验、事务写入和加密配置备份流程。每类最多1000张，客户端不能更改服务端ID、创建时间或已有预设类型；不把预设写入任务运行队列。

辅助配置直接显示TMDB与AI两个配置窗口，桌面左右各半并占据页签下的一页，标题、表单和底部测试/保存直接可用，不再点击卡片打开弹窗。手机纵向排列，短横屏窗口内部可滚动且隐藏滚动条，保留标签与按钮的可达性。继续保留图标启停、读取现有配置、独立保存、测试连接和密钥按需查看，使用 `/api/plugins/tmdb`、`/api/plugins/ai` 及原有配置存储，不迁移或重置已有密钥。启停仅更新已保存配置的开关，不顺带保存当前表单的未提交修改；读取失败禁用该窗口操作，另一个窗口仍可用，保存失败保留输入与现有状态。

识别规则已提供可保存配置与服务端预览，详见[识别规则](recognition-rules.md)。前置匹配只修改识别名称副本，后置命名替换与发布组扩展已定义纯处理函数；黑名单按大小写敏感的文件关键词、.扩展名及/目录关键词判断。实际归档、黑名单转移/回收和体积删除仍等待整理执行器接入，保存配置不会触发文件操作。

“我的插件”现为11项，其搜索结果只包含剩余工具；Emby通知、媒体深度删除、115系列和其他已有工具入口保留。插件市场及系统代理配置位置不受此次调整影响。
