# Aether Design System

LitePan is the primary layout and interaction reference, including its local AdminView, AddAccountDialog, DriverPickerStep and authorization flow. Aura is no longer the layout reference. User-selected colors remain unchanged.

- Primary `#3A4980`, soft lavender `#B4B9D6`, sidebar accent `#5263A8`.
- Sidebar `#181E2D`; white content surfaces with neutral gray background.
- Secondary functional colors: muted green (connected), amber (pending), red (failure).
- Fonts: Inter/Segoe UI for Latin; Microsoft YaHei/PingFang SC for Chinese. System fonts only, no remote font dependency.
- Alternate font combinations: Segoe UI + Microsoft YaHei; system-ui + PingFang SC.
- Typography: 15px sidebar navigation, 17px account menu, 14-15px controls, 12px supporting text and 24px page headings; zero tracking and no viewport-scaled type. Light sidebar labels and group headings use black; hover and selected labels stay black, with selection distinguished by its fill and left marker. Group headings remain 12px, with the existing night palette also used on About.
- All text uses native glyph spacing with zero added tracking. The Han character wrapper and build transform have been removed, so selection stays continuous across Chinese text and mixed scripts. Native text/input selection uses deep cosmic blue-purple `#3a4980` with white foreground in both themes. Visit-path fitting measures actual text without synthetic padding.
- Statistical counters settle within 1000ms, including custom durations. Scale steps with the value difference, use quartic ease-out and progressively slower update cadence near the target; retain the original deadline when a value changes during the transition. Reduced motion skips the animation, and unmount cancels pending work. These counters are display transitions, never simulated task progress.
- Spacing: 4/8/12/16/20/24/32/48px. Repeated item cards <= 8px radius.
- Fixed 220px sidebar with thirteen destinations in three groups and a fixed breadcrumb/traffic header. Task kinds live in page tabs; system settings use inner navigation. No workspace switch or sidebar connection/version footer.
- Theme: one icon cycles light, dark and system; persists locally and reacts to OS theme changes. A task notification bell follows it, with per-account local read markers.
- Current light content surfaces use a neutral gray-white with a faint blue tint: the large area to the right of the sidebar is `#f1f3f6`. Inward layers progressively brighten through shell `#f3f5f8`, frame `#f6f8fa`, surface `#f8fafc`, item `#fafcfd`, rule `#fdfefe`, then pure-white inputs. Parallel surfaces share tokens. The mist blue-gray sidebar stays `#d9e0ef`, hover `#ccd5e9` and selected `#bac8e8` with dark text. Dark tokens and the About page's local night sidebar remain unchanged.
- Number controls share one accessory slot for units and hover/focus steppers. Form focus stays within the existing rounded boundary.
- Media-category preset editors keep the standard modal shell, a fixed header/footer and a hidden-track scrolling body. Directory and Rule tabs use keyboard focus navigation; TV and Movie are the only media roots. Nested condition groups reuse40px selects and number inputs, bounded fixed popups, stable directory references and single-column phone fields. Number steppers retain the shared accessory hover behavior rather than introducing a separate control style.
- Naming/wash preset editors use a wider960px shell capped to the viewport, with fixed header/footer and hidden-track inner scrolling. Naming variables are muted green, repeatable literal text cream and path separators orange, with distinct night colors. Source and visual modes share one validated draft; TV/Movie previews retain native selectable text. Reorder handles support pointer/touch and Alt+arrows, alongside visible selection/move buttons; wash group weights recompute only across enabled groups. Multi-version naming remains an explicit placeholder.
- Rules' Recognition tab uses four themed configuration windows in two desktop columns and one phone column, followed by the size threshold and a shared save action. Ordered replacement rows retain two40px text fields, a horizontal regex checkbox and accessible move/remove controls. Blacklist editing expands below its trigger; release groups start at five lines and grow with content. Preview/error text wraps without horizontal overflow; failed saves restore enabled fields before moving focus to the invalid input.
- The organize/archive editor uses six rows: two paired source/destination rows, three equal rule selectors, paired redundancy/size fields, paired metadata/exclusion fields, then four switches in one row. It hides scrollbars while preserving internal scrolling and fixed header/footer. Rule menus use an opt-in fixed portal with208px bounded height, hidden tracks, keyboard navigation, visible theme-colored focus and viewport clamping; other select instances retain their existing layout. Redundancy keeps the source-pool-only path picker. Size filtering remains0 MB default; AI is unavailable until configured/enabled, TMDB and FFprobe default on, smart cleanup defaults off.
- STRM task cascade switches use a label above a 40px control row, centered against the adjacent extension input. STRM content uses label-above-select layout. Transfer temporary path and size cap share equal columns, including narrow screens. Account and notification popovers leave 16px desktop / 24px mobile clearance from the right edge so page scrollbars cannot cover actions.
- My Plugins descriptions disclose full text only when actually clipped, after 300ms of stationary hover. Pointer movement restarts the delay. Rename confirmation uses original name, a downward arrow and new name on separate rows; prioritize changed fragments and nearby context before ellipsizing, with the same 300ms full-text disclosure only on overflow.
- The compact rename rule panel uses 36px input/select heights, including the rule-type selector beside the rule number. Only multiple-rule lists show small pale-red delete controls; ignore, edit and rule-delete tooltips require 500ms of stationary hover. Other standard editor controls remain 40px.
- Storage: cards without a connector footer; compact two-step modal, icon/name-only selection, previous/save controls and lower-left authorization. Small screens retain scrolling without visible scrollbars.
- Provider choices show a themed soft filled block and border on hover or keyboard focus; later transparent idle styles must not erase this feedback. Membership badges keep their compact upper-right slot while independent membership lookups avoid waiting for capacity.
- Tools use four-column plugin cards on desktop with honest unfinished states. About reuses the animated starfield and checks GHCR image revisions explicitly.
- The grouped sidebar places Transfers last in Overview, after Dashboard, Files and Storage. Workshop starts with Rules, followed by Tasks, Virtual Libraries, Links, Tools and Archives. Rules' Assist tab directly embeds equal-width TMDB and AI forms with independent headers, enable controls, errors and save/test footers. Desktop panels fit below the tabs; phones stack them, while short desktop viewports keep each input reachable through the hidden-track form scroll area.

## Compact Workspace

- File services consolidate file browsing, WebDAV and local mounts into three page tabs, with browsing first and legacy-route redirects.
- Center emblems have a soft elliptical light beneath them without a mesh. Meteors start across the top band from one-third of the scene width to the right edge, with tails spanning 4%–6.5% of travel.
- Login fields and button share a 350px maximum width. Account fields and session duration share a 40px height and equal width. Tab glows use a rounded pseudo-element independent of the straight active underline; WebDAV's cloud outline is enlarged to match adjacent icons.

- Select triggers use 12px corners while preserving native keyboard and mobile picker behavior. Breadcrumb controls, refresh and log-mode buttons keep accessible labels without hover titles.
- Unselected navigation and page tabs have a softer rounded hover wash between their resting and active states. Framed orbit-provider icons use 25% corner radii, matching the Quark mark.
- Login and About center emblems share a responsive Canvas gravity well: a depressed membrane mesh with a dark interior, drawn on resize without an additional animation loop.

- Login and account settings share equal-height 62px rounded icon fields with accessible names and placeholder text, without visible field labels. Account settings are a compact 380px panel. Login uses larger consistent typography and no version footer.
- About keeps provider icons on a slow elliptical orbit around the central identity, with update and repository buttons at the bottom. WebDAV combines a cloud outline with DAV text; local mount/storage uses CloudDownload.
- Selected and unselected tabs use identical 17px/600 typography to prevent layout shifts. Rounded diffused selection remains visible. Deep cosmic blue-purple navigation includes animated twinkling selection stars, respecting reduced motion.
- Meteor tails span only 1.8%–3.8% of travel. Raw JSON logs remain fully wrapped with no line clamp, using 14px text and 24px leading.

- Use a 236px cosmic indigo sidebar, 48px topbar, rounded sidebar right corners and square main-surface junctions. Logs and settings are bottom-pinned. Active navigation has translucent highlights and restrained star points.
- Do not repeat page titles beneath breadcrumbs. Align task tabs and actions in one desktop row. Settings use horizontal tabs without a general-settings section.
- Storage cards use compact padding and 14px corners; the dashed tile is the only add entry and provider icons toggle enabled state. Account menus use compact 14px typography.
- Task forms use two-column rows and select controls for generation mode. A combined source picker places accounts on the left and directory rows on the right; CAS filters eligible providers.
- Share-library settings keep retention controls in equal-width columns, including phones. Mobile playback mode pairs with rotation; Quark output location pairs with rotation. Rotation defaults to24h and is visibly disabled for one selected available pool. Numeric frames fill their columns; touch controls show units beside steppers, and long retention labels reserve matching title height.
- 115 STRM offers update, missing-only and life-event generation; there is no tree option. In More Options, the half-width request interval follows cache TTL on the same row, including narrow screens. Reuse NumberInput with a visible label and ms unit, default 0; preserve existing saved values. Scroll padding and bottom space keep the final input clear of the fixed footer.
- Meteors retain parallel trajectories at slope 0.30 with short tails. Each trail randomly uses the original duration, twice that duration or three times that duration; fades begin after at least one third of travel. Login fits the viewport without visible scrollbars.
- About displays seven floating provider icons around the central content, using CloudDownload for WebDAV and FolderSync for local storage, matching navigation. Sidebar and tab selection use rounded diffused highlights, not rectangular fills.
- Toasts slide in from the upper right with a colored left edge and filled status icon, then fade and slide out; reduced-motion preferences are respected. Raw logs use wrapped JSON, severity coloring and measured variable-height virtualization, with a single current-mode icon toggle.
- Page tabs use 17px text and a stronger active underline. Workspace scrollbars are thin pale indigo with a darker hover. Logs use a fixed-height virtual list; account settings are framed and About fills remaining page height.
- Accessibility: labeled icon controls, visible focus, modal focus containment and restoration, Escape close, live notifications, reduced motion.
- States: genuine empty state, pending connection, disabled, error, active task, interrupted task. No fabricated storage or task metrics.
- Login: 3:2 desktop split, twinkling canvas stars, a cached particulate galaxy with dark dust lanes, faint constellations and occasional meteor trails; three floating elliptical orbits. Provider logos have no added frames, remain upright and complete a revolution in 180 seconds. Motion runs automatically without a playback button; hidden tabs and reduced-motion preferences still suspend animation. Mobile hides the decorative side. Brand assets are bundled locally; sources are recorded in `web/public/providers/SOURCES.md`.
- Login retains its original starfield, orbiting storage icons and layout; About keeps the same sky design. Painting is capped near 30fps while movement follows elapsed time. The foreground canvas is limited to 1.5x density and 3 million backing pixels; each broad galaxy/nebula cache uses at most 1x density and 1.5 million pixels. Reuse fixed moon, spiral and rock textures across viewport changes; unchanged-size notifications do not rebuild artwork. Hiding the responsive login panel or unmounting releases its backing stores. These bounds describe canvas pixels, not measured browser process/GPU memory.
- File rename submission closes the inline editor or confirmation immediately and previews the requested label with a small syncing indicator. Keep the authoritative ID, path and playback URL until acknowledged; only then report success. A failure or incomplete acknowledgement restores the displayed name and asks the user to verify storage, without claiming to undo a cloud write.
- Login input focus stays inside each existing rounded border; password wrapper highlights as one control. A closed eye indicates concealed text, an open eye indicates visible text; accessible labels describe the next action.

## 存储徽章与配置卡片删除

存储池卡片的115品牌图像与其他品牌共用48×48px边界。会员信息以19px高的紧凑图标文字徽章放在右上角，横向三点按钮位于徽章下方，卡片底色保持共享主题；未知、过期或失效会员仍按原规则隐藏。账户、任务、以链、分享链库等配置卡片保持各自现有尺寸。

WebDAV主体在普通存储图标中使用36px，在存储卡片中使用48px边界。选择存储目录窗口左侧的存储池图标去掉附加圆角框、底色和边框，品牌图像或SVG占满原32×32px位置；移动、夸克使用已有独立主体图像。存储条目自身的选中背景与可点击范围保留，紧凑文件选择器图标沿用既有规格。

配置卡片删除由共用消散效果反馈：服务器确认成功后，原卡片内容在约680ms内淡出并化为小粒子，相邻卡片平滑补位。取消、拒绝、失败、编辑、排序、筛选、翻页及普通刷新不会触发。支持DELETE单项接口、明确标记为删除的整表PUT，以及活链的移除/删除动作；文件操作和传输历史不接入。减少动态效果时立即完成视图更新；切页、退出账号、后台及视口变化会清理特效。最多两个并行效果，每个最多640粒子、60万画布像素、1.5倍绘制倍率，930ms兜底释放。绘制失败不改变删除请求的成功结果，不重放请求。
