# 识别规则

入口为“以太识律 → 识别规则”。本阶段完成配置、持久化与只读预览，替换原占位窗口；整理归档执行器仍待后续接入，保存或预览不会改名、移动、删除真实文件，也不改变已存在的刮削/手动重命名流程。

各配置窗口单列上下排列，每行一个完整窗口，桌面和手机一致。

## 匹配替换

每条包含原文本、替换文本及正则开关，可添加、删除、上移和下移。从第一条开始顺序执行，后一条处理前一条的结果。普通文本为区分大小写的字面匹配，替换内容里的`$1`在普通模式下也按字面文本处理；正则采用现有Go RE2编译器，替换可用`${1}`或`$1`引用捕获组，不支持前后查找和模式反向引用。无效正则明确标出条目、保留草稿并阻止保存，不静默跳过。

替换文本留空相当于从识别名称副本中过滤这一段，原文件名、路径和存储身份保留。空白字符可作为有效字面规则，不自动裁掉；全空的新增条目不保存。每组最多512条，每条原文本/替换文本分别最多1024字节，预览名称及替换结果最多4096字节。

预览示例默认是`【高清影视之家发布】www\.abc.com@蜘蛛侠_2021_国语中字_1080p.WEB-DL.H265-TnT.mkv`，保留用户指定的反斜杠。编辑规则或示例后延迟250ms请求同一个受保护的服务端替换实现，结果为输入框下的小字。仅最新请求可更新显示，旧回包、离页和换账号不会回写当前结果；预览不保存配置或执行文件操作。

## 归档黑名单

下拉展开多行编辑器，一行一条，所有匹配区分大小写：

- `预告`：文件名包含此关键词。
- `.mkv`：文件名以此扩展名结尾；`.MKV`是不同规则。
- `.cas.strm`：复合扩展名，同样支持`.share.strm`、`.ed2k.strm`。
- `/花絮`：目录名包含“花絮”；命中目录及其全部后代都属于黑名单。普通文件关键词不会把同名目录整体归入黑名单。

列表只去首尾空白、空行及完全重复项，不转小写，最多512条。扩展名和目录关键词均不可写成路径。

已定义供后续执行器采用的处置：黑名单命中项优先移到整理归档任务的失败处理目录，复用当前“冗余归类”的`failureDirectory`配置；为空时使用对应存储的回收站删除语义，不做永久删除。没有实际整理任务运行时，本页面不会自行扫描或触发这些操作。

## 命名替换

与匹配替换使用相同的两列编辑器、正则和顺序语义。输入是命名规则已经生成的目标名称，逐条替换后才进入发布组扩展。它不作为识别前置规则，也不会通过配置保存直接调用文件管理重命名。

## 发布组扩展

多行输入，一行一条，初始为五行，回车或粘贴多行后自动增高。原始文件名包含词条就命中，按输入顺序取第一条，区分大小写；不按参考项目的完整片段匹配缩窄用户要求的“包含”语义。

目标格式示例：

| 命名规则及命名替换后的名称 | 命中`TnT`后的名称 |
| --- | --- |
| `蜘蛛侠.mkv` | `蜘蛛侠-TnT.mkv` |
| `蜘蛛侠.mkv.strm` | `蜘蛛侠-TnT.mkv.strm` |
| `蜘蛛侠.mkv.cas.strm` | `蜘蛛侠-TnT.mkv.cas.strm` |
| `蜘蛛侠.mp4.ed2k.strm` | `蜘蛛侠-TnT.mp4.ed2k.strm` |
| `蜘蛛侠.mkv.share.strm` | `蜘蛛侠-TnT.mkv.share.strm` |
| `蜘蛛侠.cas.strm` | `蜘蛛侠-TnT.cas.strm` |

常见媒体/字幕扩展名与复合STRM后缀整体保留，没有媒体扩展名时插入相应STRM后缀前；年份片段不会当成媒体扩展名。已在相同位置带有同一发布组时不重复添加。词条不能包含路径分隔符，命名结果仍须经过文件名安全校验；执行器尚未调用这些纯处理函数。

## 文件体积过滤

最后一行使用非负整数数字输入框，单位MB，默认0不限制。这里1 MB为1,000,000字节；设10时，小于10,000,000字节的文件会被判定为直接删除，等于阈值保留，大小未知不判定。该全局体积规则与整理任务自身的“文件过滤”配置分开保存；二者如何调度，由后续整理执行流程接入，不因保存配置而发起删除。

## 保存与接口

无需保存按钮：停止编辑500ms或离开输入框后自动保存四类规则与体积阈值，示例名称仍只用于预览。状态文字说明等待、保存中或已保存；无效数字/前置正则不提交，后置规则仍由服务端完整校验。保存期间可继续编辑，串行提交独立快照，旧响应不会覆盖新输入；切换栏目会提交最后的有效改动，重开编辑器等待先前已排队的保存结束再读取。

读取失败禁用编辑并允许重新读取；保存失败保留可编辑草稿、显示气泡和字段错误，用户修改后再次自动保存，也可点击“重试”。失败请求不自动循环重提，自动保存不抢走当前焦点；离页或换账号的回包不写回当前窗口。

配置保存在主配置`recognitionRules`中，经现有完整性校验、事务写入和加密备份导出/导入。读取旧版本缺省配置时返回空规则与0阈值，不写回磁盘。新增`GET/PUT /api/recognition-rules`与`POST /api/recognition-rules/preview`，全部管理员鉴权、`no-store`；导入同样校验正则、列表及数值。

只读对照本地115-station的`RecognizeTab.vue`、`recognize.ts`及`internal/api/organize.go`，独立复用Aether已有名称替换编译器，无参考代码、样式、资产或新依赖引入。
