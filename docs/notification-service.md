# 通知服务与链接转存

侧栏“通知服务”位于辅助工具之后，包含“消息配置”和“链接转存”。宽屏消息配置上排按“QQ Bot”“飞书通知”“TG Bot”三列等宽排列；下方企业微信占两列宽。1200px及以下切两列，760px及以下切单列；企业微信字段桌面两列、1600px起三列、手机单列，不显示字段问号按钮。输入框40px、操作按钮36px。沿用`/notifications/telegram`以兼容旧导航和收藏；转存目录编辑使用640px标准窗口。

“消息配置”栏目使用带文本线条的消息气泡图标，与“链接转存”的目录图标区分；复用公共线条、尺寸和当前主题颜色，选中、悬浮与键盘焦点沿用公共栏目样式。

## QQ Bot

接入QQ官方机器人，不是OneBot、NapCat或普通QQ账号。配置AppID、AppSecret及群OpenID（`group_openid`，不是普通群号），默认停用。凭据来自QQ开放平台，群身份、机器人上线或沙箱资格、出口IP白名单、主动消息权限和额度须由平台侧配置；没有权限时明确报告失败，不能保证所有账号可主动群发。不接收官方事件，不提供QQ指令或链接转存。

保存后可发送测试通知。后端从`https://bots.qq.com/app/getAppAccessToken`换取令牌，再向官方`/v2/groups/{group_openid}/messages`发送文本，使用`QQBot`授权；令牌只在内存按配置身份及有效期复用，凭据或目标变化不复用旧身份。仅有HTTP成功还不算发送成功，须取得有效消息ID。

## 飞书通知

接入飞书群“自定义机器人”，配置官方Webhook地址，可选签名密钥，默认停用。不需要创建飞书应用或公网回调；不提供飞书指令、交互转存或国际版Lark地址。仅接受`https://open.feishu.cn/open-apis/bot/v2/hook/…`，拒绝用户凭据、查询参数、片段及其他主机；签名启用时按时间戳和密钥执行官方HMAC-SHA256协议。关键词、签名和群机器人权限须与飞书侧一致。

Webhook本身具有发送权限，与签名密钥同样加密保存、GET脱敏，默认隐藏且可经管理员接口按需显隐。测试确认有效业务回执后才报告成功，缺失或错误回执不冒充送达。

## 新渠道结果推送

QQ Bot和飞书除手动测试外，启用后接收普通任务与备份的成功、失败和停止结果，包括任务名及实际处理数；不转发原始错误、任意运行日志、密钥或完整播放链接，失败详情留在运行日志。TG原有交互及企业微信只读回调范围不因新增渠道扩大，不宣称全系统事件已接入。

结果通知通过64条有界内存队列异步串行发送，不阻塞任务完成；队列满时记录未发送。每次发送有20秒上限，禁止重定向和自动重发，配置变更停止尚未发出的旧目标消息。重启不重放队列，已在途消息不能撤回；无网络、未知回执或配额失败须查通知日志后人工决定是否重试。

四个表单独立保存到`/config/state.json`的`notifications`，新增`qqBot`与`feishu`子项。秘密使用AES-GCM，GET仅返回存在标志；旧客户端、其他窗口或未修改的占位不会清除已保存凭据。显式清空在保存时提交`clearSecrets`，启用渠道不能清空必需凭据；密钥显隐接口需管理员会话且禁止缓存。通知接口审计与发送结果归“运行日志→通知服务”。真实平台账号和送达效果仍须部署验收，模拟不替代现场联调。

## 企业微信应用

企业微信默认关闭，使用自建应用的企业 ID、应用 Secret、数字 Agent ID 和接收成员 UserID；接收成员用分号分隔，最多100个。留空不会默认向全员发送；只有明确填写`@all`才向该应用可见范围全员发送，不能与单独成员混填。API 地址默认`https://qyapi.weixin.qq.com`，可指定受信任的 HTTPS API 代理，不允许在地址中加入用户凭据、查询参数或片段，不跟随重定向。

应用 Secret、Token、EncodingAESKey默认隐藏，复用管理员按需显隐接口。配置保存在`/config/state.json`的`notifications.wecom`，三个密钥均使用现有AES-GCM与完整性机制，GET只返回存在标志。修改一个窗口不会覆盖另一个窗口或转存目录；未修改的占位及旧客户端空值保留密钥，在网页主动清空会明确提交清除字段。清空应用Secret前须先停用；Token和EncodingAESKey要同时填写或同时清空，后者须为43位有效编码密钥。服务重启保留配置，临时access_token只在当前进程内按配置和有效期缓存。

“测试通知”向已保存的接收成员发送一条应用消息，不向任意输入号码或其他群组发送。测试须先保存配置，不要求启用开关。凭据获取与消息发送均有界、超时且不自动重发；部分成员无效时提示其他成员可能已收到，不伪报全部成功。上游错误只报告阶段、HTTP状态或业务码，不回显Secret、Token、成员名单、API查询地址或原始正文。凭据获取期间配置变化会停止尚未发送的消息，已在途的请求不能撤销。

可选机器人回调使用Token与EncodingAESKey，页面显示当前服务来源下的`/notify/wecom`地址；企业微信必须能访问此来源，局域网或回环地址本身不代表公网可达。停用或没有完整回调密钥时该端点返回404。GET验证签名并解密回显；POST验证签名、五分钟时间窗、企业ID、Agent ID和接收成员身份，有界读取XML并使用企业微信AES-CBC/32字节填充协议回复加密XML。普通配置和回调均不把密钥写进日志或浏览器持久存储。

当前回调仅提供连接回复及`/status`或“状态”的只读存储池/任务数量查询；不处理企业微信云盘转存、离线或分享STRM命令，不推送全部系统事件。相关云端写操作仍仅由现有TG流程按其授权和确认规则执行。协议使用Go标准库独立实现，应用权限、可信IP、网络出口及真实企业微信收发仍须部署联调，模拟协议不等同真实账号验收。

## TG 接入

- Bot Token：从 Telegram 的 BotFather 创建机器人后获取，不是自己的账号登录凭据。
- Chat ID：指定接收消息和允许交互的会话数字ID；私聊为正数，群组通常为负数。先与机器人发起会话，或将机器人加入指定群组。
- 授权用户 ID：允许发起转存的 Telegram 用户数字ID，支持分号、逗号或空白分隔，最多20个。私聊未填时保存采用该正数Chat ID；群组必须明确填写授权用户，不能只凭群组ID开放给所有成员。
- 开关默认关闭。保存配置后可“测试通知”，先核验机器人，再向已保存的Chat ID发送测试消息。开启后使用getUpdates长轮询，无需公网端口或Webhook；同一Bot不能同时由其他服务轮询。已有Webhook时明确报错，项目不会自动删除它。

只有Chat ID及发送用户ID同时匹配，且不是机器人发送者，才处理消息/图片说明中的官方HTTPS分享链接及有效ED2K文件链接。未知链接、其他会话、其他用户和编辑消息不触发云盘写入。单条消息合计最多50个链接；同一分享不同提取码报错，不静默选取一个。ED2K校验名称、大小和32位哈希，规范化后去重，不把磁力或任意网址当作ED2K。当前通知范围是连接测试、TG转存/离线交互、分享STRM生成及其执行结果，不宣称推送所有系统事件。

Token通过现有AES-GCM字段保护及配置完整性协议保存，GET不返回Token；默认圆点隐藏，小眼睛经管理员授权接口按需读取真实已存Token，可再次隐藏。该接口禁止缓存，不把Token写入浏览器持久存储；未修改占位或留空保存均保留已存值。配置、开关和目录卡片存于`/config/state.json`的`notifications`，无需新增配置模块格式；勿手动破坏完整性封装。不要公开Token、分享口令或运行态文件。

## 链接转存目录池

115、原生移动、夸克各有独立目录池。目录卡片保存云盘类型、存储池、目录ID和完整路径，可再次选择同类型其他存储或目录，支持删除、拖拽排序及Alt+上下方向键排序。卡片前不显示排序数字，组内顺序仍持久化，Bot按此顺序显示；没有可用用途的卡片时该类型不启用对应TG操作。

115添加/编辑窗口有“分享转存”“ED2K离线”两个独立开关，默认前者开启、后者关闭，可以同时开启或全部关闭。卡片分别以浅蓝色和星光金色用途标识展示，全部关闭显示未启用；移动、夸克仅用于分享，不显示离线开关。设置存于目录卡片的`shareTransfer`和`ed2kOffline`；旧记录缺失前者按开启兼容，缺失后者按关闭兼容。只有勾选ED2K离线的115目录参与ED2K目标选择，不复用CAS或ED2K播放绑定池，也不根据文件扩展名排除合法链接。

三个目录池各用独立圆角面板，标题保留云盘图标，背景使用该云盘品牌色的浅色变体，日夜分别混合当前主题表面色。目录卡片改为存储名称前两个字的文字头像。目录选择复用任务源目录窗口，路径各级可点击跳转，窄屏经省略菜单访问上级。重新打开已保存目录时只读核对完整路径及最终目录ID；路径或身份变化使用气泡提示并从根目录重新选择，不静默改写已保存目标。只有确认选择并保存才生效。

先按云盘类型及当前链接用途筛选目录。仅一条链接且只有一个匹配目录时直接加入转存或离线队列；多个匹配目录先选择再确认，按钮左侧“返回”、右侧确认。多条链接按115、移动、夸克顺序分组，同一类型的分享与ED2K分别确认，各组内保留输入顺序；即使只有一个匹配目录，也须确认整组链接，此时左侧为“取消”。前一组全部结束、取消或过期后才显示下一组，未配置可用目录的组报告未执行并继续下一组，不悄悄改变目标。

返回会恢复同一消息原来所在的目录页，保留链接，不转存、不取消任务；返回后旧确认按钮失效。目录选择每页最多五项，有上一页/下一页，保留配置顺序，末页不补空条目。分页只编辑原机器人消息，不创建云任务；有效翻页和返回也重新计闲置时间。确认、取消和过期作用于当前整组，不会留下仍能执行的等待成员。回调绑定发起用户、Chat ID、消息ID、随机任务ID、当前页和选项，越界页、已消费翻页及非当前页选择拒绝。目录、用途开关、账号启停、凭据或TG授权变化会停止尚未提交操作，不静默更换目标。已在途的上游请求不能撤销，应核对实际结果。

选择目录后的确认页尝试只读取得分享根名称，最多等待30s，不递归、不创建目录或提交转存。已取得的名称保留在当前交互中，返回选择页也显示；文件分享使用文件名，多根分享展示前两个名称并限长。执行时重新读取分享，准备消息显示实际资源简名和目标存储、目录，不再先发送没有资源名称的“准备转存”。无法读取时报告失败，不编造名称。网页卡片可点击名称或空白进入编辑，Enter/空格同样可编辑，长按拖动及独立编辑/删除按钮保持。

目录池内部只展示三行88px卡片，超过三行在固定列表内滚动且不显示滚动条，添加按钮独立留在列表下方。宽屏三列，窄屏按两列或一列排列；下方为转存记录，不再把三个池延伸到页面底部。移动、夸克卡片的编辑按钮左侧提供“活动链接”图标按钮。

## 活动链接与转存记录

链接转存下方按30条分页展示本次功能启用后的转存记录，字段为云盘类型图标和分享名称、分享链接、转存来源、转存时间、执行结果。来源区分浏览器分享窗口、Bot交互、活链计划及手动更新；结果记录新增提交、同名跳过和失败/中断，移动和115只取得提交回执时仍显示“已提交”，不冒充完成。历史链接展示不带提取码的官方地址，时间为`26/10/29 13:19`；页面约5秒更新，隐藏时暂停请求，账号切换清除旧内容。旧TG终态已清除原链接，不能凭日志回填完整历史。

移动和夸克转存目录编辑中，目录选择与“更新周期”同行，单位天，默认7，允许0至365的整数；0关闭自动更新。接收到该目录的单一文件夹分享，在本轮完整计划被上游接受且确认保存目录ID后登记活动链接，包括浏览器与TG入口。文件分享、多根分享、平铺保存或失败/未确认的初次转存不擅自创建可删除目录的活链。已存在同一分享和目标的活链不重复建记录。第一次周期按本轮转存时间所在小时计算，例如10月29日13:19、7天周期，下次为11月5日13:00，不使用每月`*/7`冒充跨月七天间隔。

活动链接窗口展示分享名称、链接、保存目录、下次执行时间和最新结果，逐条提供执行、编辑和删除。执行加入服务后台，不依赖窗口保持打开；当前活链更新串行执行，每次有30分钟上限。编辑为两行四字段：第一行分享链接和分享名称，第二行Cron表达式和目录名称。Cron留空保存即停用该条计划；非空相邻执行间隔至少12小时，包含跨日边界检查，错误复用Cron警告提示。目录周期仅作为首次登记的默认值，逐条编辑后使用该条Cron，不因再次转存覆盖手动配置。

更新复用官方分享读取和原分批转存：完整枚举目录，保留原层级，按目标内同名文件跳过，只提交缺失文件，不覆盖已有文件，也不删除分享中消失的目标文件。浏览器首次选择排除的路径继续排除；不单凭分享者的修改时间或本机时钟判断新增，避免文件时间缺失或回拨造成漏项。目录读写与499项单批、上限、凭据隔离和取消保护保持。夸克任务查询确认后才记录完成，移动仅返回提交回执时记录已提交。

修改目录名称时按已登记的父目录、目录ID和旧名称核验，云端改名并读回确认成功后，同步更新活链与关联转存历史中的名称；不按名字猜目录，不覆盖同名文件夹。目录被其他活链共用时不允许单独改名或一并删除。删除二次确认底部左侧橙色“移除记录”只移除该活动链接并停止计划，不操作云盘；右侧浅红“确认删除”按存储已有删除策略删除已核验保存目录及全部内容，确认目录已移除后才移除活链。历史转存回执仍保留。

转存历史`shareTransfers`与活动链接`shareLiveLinks`保存到`/data/runtime/state.json`，原始链接按secret字段加密；不混入配置备份，导入配置保留已有记录与写前回执。活动链接最多1000条，转存历史保留最近1000条终态及未结束回执。转存、改名或删除前持久化操作意图，凭据/目标配置变化、目标身份变化或写入结果不明时停止；不自动重试写请求。重启将未结束操作标为中断并停止其自动计划，未知写入意图不解除、不重放。需核对云盘实际目录，必要时只移除记录后重新发起明确操作。外部客户端并发修改仍不属于跨服务事务，模拟接口不替代真实云盘与Bot联调。

选择/确认消息按最后一次有效操作计时，连续10分钟未操作即失效并清理机器人发出的交互消息；选完目录后重新计10分钟，不按最初创建时间截断。未授权、错误或已消费回调不续期。仅清理已记录的机器人消息ID，不删除用户原消息、排队/运行中的任务或独立结果通知。清理是独立后台任务，每5秒检查，不被长时间转存阻塞；先持久化失效状态并清除分享内容，再调用 Telegram `deleteMessages`。

删除失败保留清理回执，每分钟安全重试，成功后记录日志；该删除接口跳过已不存在的消息ID，结果不明时重试不会重发转存。重启仍保持转存中断且不重放，但恢复过期交互消息清理；旧记录无最后操作时间时以创建时间兼容。机器人停用或Token变更时暂缓清理，不拿新Bot删除旧Bot消息；超过Telegram的48小时删除期限停止并记录警告。网络、权限及平台期限会影响实际消失时间，不能承诺离线时仍可删除。待清理回执独立保留，最多200条待清理时暂停新增目录选择交互，避免无界积压。

转存与网页分享复用目录读取、计划和单批提交：完整保留分享层级，每批最多499个文件，同名跳过，不覆盖；移动20万扫描保护、其他网盘既有限额和超时不变。全局仅一个TG执行任务，最多32个活动分组、总记录保护2000条；保留活动消息的完整批次及最近约200条终态，不并发轰炸云盘。夸克按任务查询确认完成再处理下一批，115及移动返回任务编号仅报告“已提交”，不冒充云端完成。

115分享目录ID和计数字段兼容数字及字符串，复用115driver的精确整数解析，不经过浮点转换。夸克在HTTP404正文明确返回41006/41007时按已失效或取消分类；网关HTML、其他404、授权或网络异常不据此判定分享失效，也不据此标记Cookie失效。存储连接正常只说明个人云接口可用，不证明某条分享仍有效。写入失败不自动重试。

ED2K复用现有115 Cookie云下载接口，先只读核验所选目录，再持久化单次写意图并重新检查账号、用途及授权，然后提交一条规范化ED2K链接。使用同一串行TG工作队列，成功仅报告已提交，后续进度到115云下载查看；不轮询等待播放、不生成STRM、不清理源文件或云端文件。失败、结果不明、重复确认或服务重启均不自动重提。通知日志包含目标池、完整目录、文件名、提交或失败结果，不输出ED2K哈希、完整地址或上游敏感错误正文；真实115权益、风控及TG网络需部署验收。

## 回执与日志

TG偏移、待处理任务及写前批次意图保存于`/data/runtime/state.json`的`telegramRuntime`，原始分享作为加密secret字段暂存，终态清除。新Token首次接入只建立最新偏移，不执行积压消息；已确认的更新在外部写入前持久化，重复更新/确认不再次提交。服务重启时未完成任务及确认标记中断，清除链接，不自动重放云端转存。缺失运行态重新建立偏移，不猜测上次结果。

交互记录额外保存最后活动时间、Bot身份摘要及消息清理状态，不保存额外Token副本。移动分享读取和提交复用项目已有的分享页加密正文/签名协议，与网页分享和CAS分享解析使用同一传输实现；每批499及写请求不重试规则不变。DNS失败、TLS校验、超时、连接被关闭/拒绝、网络不可达分别报告，不输出完整请求地址、分享码、提取码或上游敏感正文。“读取分享失败，已提交0项”发生在分享读取阶段，并不表示目标目录无效或CAS哈希秒传失败。

## 分享 STRM 命令

消息以 `/share` 或中文 `虚拟链库` 开头，命令后用空格或换行分隔分享链接，进入分享STRM生成；直接发送链接仍进入链接转存，不会自动生成链库。未知斜杠命令忽略。多条链接按115、移动、夸克顺序串行处理，分别报告每条结果；当前仅接入夸克机器人链库生成，115、移动明确报告暂未接入，不回退成普通转存。

夸克命令使用链库设置的默认生成位置、默认扩展名及绑定账号，不使用TG转存目录。默认生成位置留空时只添加未启用卡片，不生成文件；没有可用夸克存储时同样仅保存未启用卡片，不能读取的名称使用明确的备用名称。设置默认位置不会自动启用已有草稿，须编辑原卡片设置位置并手动启用；未设置全局默认位置时，也不会从TG启动已有启用卡片，网页手动执行不受此默认值限制。

默认位置及账号可用时，新卡片立即执行一次，后续按卡片Cron或手动操作更新。同一分享复用原卡片，不重复创建或覆盖提取码不同的既有卡片；已有未启用卡片不会被命令自动启用。生成复用夸克链库的目录核验、媒体STRM与元数据策略，媒体正文不下载，元数据按原临时转存协议处理。TG授权、绑定账号凭据或链库默认配置在排队/执行中变化时停止后续发布或云写，不静默换账号或输出位置；仅核验过旧存储身份的可信自动Cookie轮换可接续有效链库任务，手动改账号、已失效记录及迟到响应不接续。已完成的上游请求不能撤销。结果及错误同时记录到通知服务和虚拟链库日志；重启中断所有等待、确认和执行任务，不自动重放。

配置变更、开始、逐批提交/跳过、完成、失败和中断写入“运行日志→通知服务”，含任务标识`TG:任务ID`、存储名、目录、资源简名及实际提交数。企业微信记录配置、消息测试与只读回调结果，管理API审计同样归通知服务。Token、Cookie、提取码和完整分享地址不进入日志或回调数据。网络异常和结果不明时停止后续批次，不自动重复写入；检查日志及云盘实际目录后再决定是否重新发送。
