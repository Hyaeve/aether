# 辅助工具与插件市场

辅助工具页面分为“辅助工具”和“插件市场”。内置工具保留原有配置及启停入口，卡片固定图标、标题、短副标题与最多两行描述，统一收紧底部留白。右下搜索按钮可按名称、副标题和描述检索，点击横条直接打开原工具；115 秒传仍进入其独立页面。

共享搜索窗口将搜索图标、输入框和关闭按钮合并为顶部一行，不再重复显示普通弹窗标题。结果横条显示插件图标、名称、已有版本、分类/来源与功能描述；不伪造安装或授权勾选。长描述最多两行，列表内部滚动，支持上下方向键、Enter及Esc，适配手机横竖屏和日夜主题。

## 添加仓库

在插件市场点击“插件仓库”，或悬浮右下搜索按钮后点击上方仓库图标。触屏和键盘也有可用入口。填写仓库名称、公开 HTTPS GitHub 仓库地址、分支或提交（默认 main）。地址可以带 `.git` 或简单的 `/tree/分支`，不得带账号密码、查询参数或片段。

添加或修改启用仓库时，后端先读取并校验索引，成功才保存；失败使用消息气泡，不写入假成功配置。支持编辑、启停与二次确认删除，最多20个来源。相同规范化地址和 ref 不重复，同插件 ID 来自不同来源时分别展示；配置修订冲突时需重新打开仓库窗口。删除来源不执行卸载或删除用户数据。

仓库与顺序保存在 `/config/state.json` 的 `pluginRepositories`，由已有完整性封装维护，重启或更换浏览器不丢；不是浏览器本地设置，也不是此前设计草案中的独立模块文件。已配置来源的卡片会出现在市场，可搜索和打开详情。市场分页加载，每页48项；搜索最多返回100项。

## 静态索引协议

按顺序读取 `package.json`、`package.aether.json`、`package.v3.json`，只有404才尝试下一个；其他错误或格式错误直接报告，不用其他文件掩盖。根对象为插件 ID 到元数据的字典，不是 npm 的 package 格式：

```json
{
  "ExampleTool": {
    "name": "示例工具",
    "subtitle": "文件服务",
    "description": "插件功能描述",
    "version": "1.0.0",
    "author": "作者",
    "icon": "icons/example.png",
    "labels": ["文件"],
    "aether": { "api": 1 }
  }
}
```

ID为英文字母开头，其余可用英文字母、数字、下划线和连字符，最多64字符；拒绝重复和大小写冲突。名称、版本必填，文本有长度上限。图标只接受同仓库同ref的受限路径，外部地址和路径越界不显示；加载失败回退线条图标。元数据只作为文本展示，不执行 HTML、脚本或命令。

协议组织参考 [MoviePilot v3 固定提交](https://github.com/jxxghp/MoviePilot/blob/5258e06fd7e2d512f8d303a8f20cd610449508a5/app/adapters/external/plugin/client.py) 的静态索引字典。这里只读取首个有效索引，不合并 MoviePilot 的多代际库存，也不兼容其 Python 执行接口。`aether.api:1` 仅表示作者声明，不等于已验证版本、权限、资产或可执行兼容性。

## 缓存与边界

- 固定从 `raw.githubusercontent.com` 读取 HTTPS 索引，不携带云盘凭据，不跟随重定向，不开放任意 URL 代理。
- 单份索引最多1 MiB、4096项、64层；最多4个全局同时读取，共享同来源的在途请求。缓存30分钟，失败短暂退避，也可手动刷新。
- 内存缓存最多64个来源快照；失败保留最近成功目录并报告来源错误。缓存可重建，重启后重新读取，不把它当成持久安装记录。
- 当前仅实现仓库配置、目录展示、搜索和详情。**尚未实现外部插件安装、运行、更新和卸载**，市场目录不会混入内置工具，也没有“已安装”假状态。不下载或执行插件发布包，不修改 `Aether-Plugins` 仓库。

运行时、受限能力接口、资产校验、进程隔离及安装事务须另行实现和验收；不能因为插件卡片可以展示，就宣称已有外部插件运行能力。
