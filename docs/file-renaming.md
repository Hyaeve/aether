# 文件原位重命名

文件管理的重命名成功后，仅更新当前条目的名称、标识及签名播放地址，不重新请求目录列表；提交过程中保留原列表、虚拟滚动与滚动位置，不替换为读取目录空态，不将改名条目移到顶端。

本地、OpenList 和 WebDAV 的路径型 ID 随名称更新；115、移动、天翼和夸克的原生文件 ID 保持不变。后端成功响应返回 `processed` 及 `renamed: {id,name,url}`，前端据此更新选中项与锚点，文件夹不使用播放地址。上游身份、重名和权限校验沿用既有操作接口，不能以本地视觉更新代替实际成功。

当前可见顺序保持到显式刷新、重新排序、筛选或重新进入目录；届时按所选排序重新排列。失败保留原名称并用消息气泡报告；请求结果不明或旧服务未返回更新标识时提示手动刷新确认，不自动重放写操作。服务端必要的操作前校验读取不等于前端目录刷新。

任务卡片的状态区域默认显示“最近执行：月-日 时:分:秒”，尚未执行时显示对应空态。中间区域向左展开并保留执行/菜单按钮位置；悬浮或键盘聚焦仍显示任务结果，健康异常仍优先展示暂停原因。窄屏状态区域在下一行，不挤压按钮。
