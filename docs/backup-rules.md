# 目录备份规则

入口：传输中心 > 备份规则（不是辅助工具的配置备份）。规则定义保存于 `/config/transfer/backup.json`，执行状态、计数和时间保存于 `/data/runtime/state.json`；配置带完整性校验，可随配置备份导出和导入。

## 配置与执行

- 编辑窗口按基本设置、备份规则、扫描规则、筛选规则分组，不显示步骤序号或滑动条；内容较多时仍可滚动。同步模式默认单向同步，可选择双向同步。每条规则最多16个源目录和16个目标目录，可以直接选存储根目录。
- 文件系统监听与其他开关采用公共35×20px轨道及匹配的圆点尺寸/位移，不再单独缩小轨道。共享存储目录选择器的路径不换行，并与右侧新建按钮同行；桌面筛选框也在同行，窄屏仅筛选框移到下方。放得下时显示全部祖先，放不下时从根目录之后的较浅层开始省略，优先保留末级目录；省略菜单和各级目录均可点击跳转。
- 选择目录后，备份位置的`label`保存完整存储内路径，目录ID仍保存在`path`；跨浏览器或重开编辑时从完整路径只读恢复并核验末级ID，不把同名替换目录当作原目录。旧115规则仅有ID时复用115只读路径协议恢复祖先，受自定义存储根目录约束；路径失效、身份变化或配置变更通过气泡提示，阻止保存错误选择。其他旧云盘记录若既无祖先也无完整路径且无已接入路径接口，需要从根目录重新选择一次，不能凭空补造祖先。
- 单向同步每个源复制到每个目标。单源保留原相对目录结构；多源各加一层源目录名，重复名称加数字后缀，存储根目录使用存储名称。双向同步各目录按相同相对路径合并，不添加源目录前缀。空目录保留。
- 同名文件默认跳过，也可选择覆盖；同名文件与文件夹冲突时停止，不强制删除。
- 无备份卡片时，占位和栏目右侧均提供“添加规则”；栏目操作不提供刷新按钮，列表仍自动更新。筛选页的“添加规则”打开六种图标类型：扩展名、文件名、正则、路径前缀、路径正则、大小，最多32条。卡头以圆形单选选择黑/白名单、方形复选选择文件/文件夹，至少保留一个适用范围。扩展名、大小仅作用于文件，不阻断目录。
- 扩展名和文件名输入按回车或离开输入框添加 token，可用英文分号批量添加；token 自动换行，不预留删除按钮空位，悬浮或键盘聚焦时原位置显示删除按钮。扩展名去掉开头的点，默认转换小写并去重。文件名支持名称关键词或 `*`、`?` 通配符；旧名称通配符和正则仍可匹配相对路径。
- 名称黑名单按文件/文件夹适用范围在扫描入口排除。命中的文件不计算摘要、不加入复制队列，也不计为已扫描文件；命中的目录整支跳过，不读取子目录或逐个校验内部文件。文件系统监听同样跳过，不因这些内容变化触发备份。父目录列表仍须读取以识别名称，资源上限仍统计已枚举条目；不虚构未进入目录中的文件数量。其他筛选类型维持原有语义。
- 视频、音频、图片、数据和文档扩展名快捷按钮按整组切换：组内未全选时点击补齐，组内已全选时再次点击移除该组全部扩展名。其他组及不属于该组的自定义扩展名保留，按钮高亮同步当前是否完整选中；备份规则与 115 秒传监控复用同一行为。
- 筛选页不再提供“更多选项”或大小写选择，新建及通过编辑器保存的规则默认忽略大小写，扩展名统一转换小写。Go RE2 正则支持显式内联标志，表达式自身的 `(?i)` 等仍可调整局部匹配。旧配置仍兼容执行，重新编辑保存时关闭旧 `caseSensitive` 设置。
- `path_prefix` 每行一个源目录内相对路径，默认三行，可伸缩，重新打开恢复三行。`Movies` 匹配自身及 `Movies/...`，不匹配 `MoviesExtra`；每行拒绝绝对路径、盘符、空目录段、`.`、`..`和NUL。目录白名单放行祖先保证可达，黑名单拒绝目录后其内容不复制。
- `path_regex` 仅匹配规范化相对路径；白名单放行目录以扫描后代，文件仍按表达式筛选。正则和路径正则整行输入，两种路径规则不显示范围勾选，覆盖文件及目录。黑名单优先，同类白名单须至少命中一条。大小上下限各占半行，单位在输入框内，KB/MB/GB循环，默认MB；0不限，仅整数，旧B单位兼容。
- Cron 留空、自动扫描间隔0且未开启监听时仅手动执行；间隔可设置60秒至一年。Cron与间隔同时配置时取下次更早的时间。停用不触发计划，手动执行也要求启用。
- 基本设置中的文件系统监听参考 Nestify 的五秒元数据指纹轮询，单向仅监听本地源，双向要求所有目录为本地并监听两侧，变化稳定两轮后触发备份。初次建立基线不执行，运行期间的后续变化不会丢弃。不是内核事件监听，不监控云盘；云盘使用定时扫描。
- 完成规则默认保留源文件，单向也可删除已备份源文件，或同时清理空文件夹。清理前必须所有目标复制成功，并逐个读取校验 SHA-256；跳过同名的文件不删除。源文件变更、目标校验失败、取消或复制失败不开始清理。空目录清理仅限本地、非递归，不删除选中的源根目录。双向同步固定保留源，完成规则不可选。
- 删除规则默认保留，也可移至回收目录或删除。单向处理目标多余文件；双向还需开启扫描规则中的同步删除才传播已记录的删除。没有基线的首次运行只合并，不推断删除。115、夸克不支持永久删除，选择删除会停止而不是悄悄移入回收站。
- 卡片及执行详情展示扫描、复制、跳过和进度；扫描总数未知时不虚构百分比，完成扫描后按目标复制项计进度。支持停止、编辑、复制和删除；复制的规则默认停用。运行中不可修改或删除，重启标记中断，不自动续跑。

## 数据保护与边界

这是参考 Nestify 分组布局及监听、同步行为的独立实现，不是其完整规则引擎。不包含拖拽排序。备份设置提供扫描并发、执行队列上下限和双向暂停。完整扫描后才发布文件，后续目录不可访问时不会只复制前面的目录；校验会产生额外读取流量。单向完成规则的源清理沿用存储删除模式；新增删除规则独立决定删除方式。

## 双向同步

- 新增与内容修改由 SHA-256 和上次成功基线比较。仅一侧修改时传播该版本；两侧同时修改默认保留冲突副本，也可优先源目录或较新版本。多个源目录按配置顺序优先；时间策略依赖上游修改时间。
- 默认目标独有文件复制到源，也可保留在目标。删除和修改冲突优先保留修改；关闭同步删除或选择保留会恢复其他目录中仍存在的文件。重命名按新增与删除处理，因此旧名称是否移除由删除设置决定。
- 覆盖前保存旧版本至各自目录的 `.aether-history/<规则ID>/...`；保留天数0为永久。正数仅清理基线跟踪且内容校验一致的历史文件，不删除未知副本。回收规则使用 `.aether-trash/<规则ID>/...`。目录只在确认空目录时移除，筛选排除的文件不递归删除。
- 每个目录默认使用 `.aether-sync-owner` 标记，发现其他实例或规则占用即停止；关闭标记不提供跨实例互斥。超过20项且超过删除保护百分比（默认20%）时暂停，卡片提供二次确认入口；确认后重新扫描，变化后的计划仍需要再次确认，计划任务不会自动批准。
- 默认每8次普通扫描或24小时彻底扫描；手动执行总是彻底扫描。本地文件每次校验内容，云盘普通扫描可复用相同大小与非零修改时间的摘要；成功发布后再次读取验证。设置不保证避免上游伪造或遗漏的元数据，周期性与手动彻底扫描用于复核。
- 同步基线、历史清单保存在 `/data/runtime/backup-sync/*.json`，带完整性校验；删除确认状态在 `/data/runtime/state.json`，不写配置。迁移服务时同时保留 `/config` 主密钥与 `/data`；基线丢失重新合并而不推断删除，损坏基线拒绝执行。规则删除不清理已有历史文件或同步标记。
- 所有待复制版本先在传输临时目录的 `.aether-sync-*` 暂存校验，单次暂存默认上限100GiB；实际计划含原生移动PC上传时最多500 GB，但每项仍按实际目标的单文件上限校验，不能扩大其他目标权益。发布前拒绝已变化的目标，成功后复查内容再推进基线。不是跨文件、跨云服务事务；失败前已发布的文件保留，进程崩溃可能留下临时或未登记的历史副本，不自动续传或清理。外部同时写入及多实例部署仍需协调。

默认一次扫描一个备份，可在备份设置调整扫描并发；目标发布和删除仍全局串行。最长 24 小时、扫描最多 100000 项、128 层，单文件默认最大 100GiB；目标为[原生移动PC](mobile-pc-upload.md)时最多500 GB（十进制），会员权限仍由上游核验。先完整扫描并检查重叠，再逐项复制。预检清单加密暂存于 `/data/.aether-backup-queue-*.tmp`，按执行队列上下限加载，正常结束删除；安全索引不受队列上限限制。云盘读取与上传通过以太本机；文件暂存于传输设置所选目录（默认 `/data/cache/transfer`），需要足够磁盘空间，正常结束清理暂存，异常退出的遗留文件不会自动续传。

源和目标不能相同或互相包含；本地路径解析真实路径，远端同账户使用目录 ID 检查。不保证能识别不同凭据但实际映射到同一后端的服务别名，请自行避免此类配置。

名称黑名单剪枝不取消重叠保护。本地沿用真实路径预检；OpenList/WebDAV等路径型存储计入各池根目录比较；115同账号只读查询另一个备份根的祖先ID（`limit=1`，本次执行复用），不递归读取被排除分支，存在包含关系或无法核验时停止。其余仅有不透明ID且尚无可核验祖先接口的同账号云盘范围，在遇到排除目录而无法证明不重叠时停止，不猜测关系或直接发布文件。

本地覆盖使用临时文件原子发布，云端复用已有上传确认与替换流程。失败前已完成的文件会保留，不提供整批事务回滚；云端异常可能留下临时或旧版本文件，应查看“文件与备份”日志并刷新目录。保留策略按名称跳过，不比较文件内容；外部写入可能造成冲突，任务会报错而不是覆盖后冒称成功。

停止是协作取消；已提交的云端操作可能仍由上游完成。真实云账号及容器 FUSE 的互通需部署后验证。
