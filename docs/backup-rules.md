# 目录备份规则

入口：传输中心 > 备份规则（不是辅助工具的配置备份）。规则定义保存于 `/config/transfer/backup.json`，执行状态、计数和时间保存于 `/data/runtime/state.json`；配置带完整性校验，可随配置备份导出和导入。

## 配置与执行

- 编辑窗口按基本设置、备份规则、扫描规则、筛选规则分组。每条规则最多16个源目录和16个目标目录，可以直接选存储根目录；每个源复制到每个目标。
- 单源保留原相对目录结构，不额外添加源目录名称；多源各加一层源目录名，重复名称加数字后缀，存储根目录使用存储名称。空目录保留。
- 同名文件默认跳过，也可选择覆盖；同名文件与文件夹冲突时停止，不强制删除。
- 筛选支持名称（关键词或通配符）、扩展名、Go正则、大小（B/KB/MB/GB，1024进位），最多32条。黑名单优先；同类条目存在白名单时须至少命中一条。名称/正则可用于目录或文件，目录不通过时其内容不复制；扩展名/大小不阻断目录。旧扩展名/关键词/字节范围设置仍保留并与新筛选同时生效。最大大小0表示不限。
- Cron 留空且自动扫描间隔0时仅手动执行；间隔可设置60秒至一年。Cron与间隔同时配置时取下次更早的时间。扫描均为完整遍历，不依赖不可靠的云端修改时间；停用不触发计划，手动执行也要求启用。
- 卡片及执行详情展示扫描、复制、跳过和进度；扫描总数未知时不虚构百分比，完成扫描后按目标复制项计进度。支持停止、编辑、复制和删除；复制的规则默认停用。运行中不可修改或删除，重启标记中断，不自动续跑。

## 数据保护与边界

这是参考 Nestify 多源布局、分组规则、筛选及调度行为的独立实现，不是其完整规则引擎。不包含文件系统监听、增量扫描、源文件清理、镜像删除、资源队列或拖拽排序；不会删除源文件或目标多余文件。完整扫描后才写任何目标，后续源不可访问时不会只复制前面的源。

一次仅执行一个备份，最长 24 小时、扫描最多 100000 项、128 层，单文件最大 100GiB。先完整扫描并检查重叠，再逐项复制。云盘读取与上传通过以太本机；每次暂存一个文件于 `/data/cache/backup`，需要足够磁盘空间，正常结束清理暂存，异常退出的遗留文件不会自动续传。

源和目标不能相同或互相包含；本地路径解析真实路径，远端同账户使用目录 ID 检查。不保证能识别不同凭据但实际映射到同一后端的服务别名，请自行避免此类配置。

本地覆盖使用临时文件原子发布，云端复用已有上传确认与替换流程。失败前已完成的文件会保留，不提供整批事务回滚；云端异常可能留下临时或旧版本文件，应查看“文件与备份”日志并刷新目录。保留策略按名称跳过，不比较文件内容；外部写入可能造成冲突，任务会报错而不是覆盖后冒称成功。

停止是协作取消；已提交的云端操作可能仍由上游完成。真实云账号及容器 FUSE 的互通需部署后验证。
