# 我的媒体与追剧日历

探索发现依次提供资源推荐、媒体订阅、追剧日历、我的媒体。我的媒体包含媒体面板、内容排行、缺集管理、控制中心。

## 服务与展示范围

直接复用以太链接的卡片、顺序和授权，包括未启用反代的卡片，不另存第二套密码。控制中心可获取每个服务可访问的媒体库并勾选展示范围；未选择时展示配置入口，不默认扫描全部媒体库。保存失败保留勾选并允许重试。

当前服务和缺集管理所选Emby分别记录在服务端`mediaDisplay.selected`、`missingSelected`，展示范围记录在`mediaDisplay.libraries`。配置随主配置事务、完整性校验和备份保存，换浏览器也可读取。删除以链后该服务不再出现，失效的选择回退到首项。

## 面板与排行

面板最多使用五个最近入库项目作为横幅，右下角白条可悬浮、聚焦或点击切换，不自动轮播，也不增加左右箭头；下方为最近入库竖海报。Emby及兼容接口的飞牛影视显示影片、剧集、总集数；Audiobookshelf使用书封、作者/播讲、音频条目、音轨、总时长和体积。

横幅右侧显示展示范围内的当前播放用户、作品、暂停状态和实际进度。可见页面每五秒刷新播放状态，后台停止轮询。面板缓存一分钟，手动刷新重新读取；更改服务、授权或展示范围不复用旧范围缓存。海报经受保护的本机图片接口读取，页面不含上游密钥；图片请求不跟随带凭据的重定向，限制格式和8MiB大小。

内容排行按接口实际返回的用户播放次数汇总，剧集按作品归并；Audiobookshelf按收听时长汇总。最多显示前100项，每页20项。上游不提供播放次数或授权不足时显示错误，不用入库时间或虚构数据代替排行。飞牛影视复用现有登录换票流程，其具体版本是否完整兼容统计接口仍取决于上游。

视频质量统计需点击“扫描”才执行，读取所选媒体库技术信息，汇总分辨率、编码和已返回的体积。未返回的信息标为未知，体积同时标注已知项数，不推测未返回的数据。

## 缺集管理

目前仅允许选择Emby。点击扫描后按展示范围读取剧集、TMDB标识及本地季集号，与TMDB已公布且已播出的剧集日期比较；未来集不计缺集，日期或标识不完整的作品计入待核对。多集文件按返回的结束集号识别。

海报列表每页20项，搜索重置页码，跳转输入回正到1至最大页。悬浮或键盘聚焦海报显示缺集蒙版，点击可查看完整说明，手机不依赖悬浮。顶栏左侧为扫描，右侧依次是数量和搜索。

扫描不修改媒体服务器或网盘文件。每服务最多同时一个扫描、全局最多两个，单轮20分钟；每份完整媒体列表上限10万条，缺集上限1万部剧集及10万集核对预算。重复启动拒绝，支持停止。分页不完整、取消或展示范围改变时保留原结果；仅完整读取且范围仍匹配的新结果才保存。结果存于独立运行态`mediaMissing`、`mediaQuality`，重启可恢复，不混入配置导出。

## 追剧日历

读取媒体订阅已保存的剧集和季号，复用TMDB授权、代理、语言、节流及缓存。按月份显示周一至周日播出安排，可切换上月、下月、本月及刷新；点击日期查看当天列表，点击作品进入资源推荐详情。日期以TMDB公布为准，失败有说明，空安排不伪造剧集。此页不启动资源站点搜索或转存调度。

接口参考[Audiobookshelf官方API](https://api.audiobookshelf.org/)及[Emby会话接口](https://dev.emby.media/reference/RestAPI/SessionsService/getSessions.html)。本机HTTP夹具与浏览器模拟验证不代表真实媒体服务器或实体设备已经验收。
